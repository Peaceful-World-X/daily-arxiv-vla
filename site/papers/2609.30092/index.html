Card 02 论文概述

论文概述

  • 核心解决Vision-Language-Action（VLA）模型的记忆性缺陷：其对测试时因硬件磨损、校准误差导致的硬件偏移极度脆弱，难以在无需现场重新校准的情况下适应部署环境变化，是大规模真实机器人部署的关键瓶颈
  • 提出Self-Adaptive VLA，一种新型后训练方案，让策略能够利用自身部署时的失败rollout作为上下文，迭代适应硬件偏移，且无额外推理开销
  • 目标是实现无需人工校准的鲁棒机器人部署，降低大规模机器人部署和运维成本
Card 03 核心贡献

核心贡献

  • 提出Self-Adaptive VLA后训练方案，使无记忆的VLA模型能够利用自身的次优部署rollout作为上下文，迭代适应测试时硬件偏移
  • 设计自动化数据构造流水线，将训练基础策略的标准人类专家演示转化为硬件偏移条件专家数据，无需额外人工数据采集
  • 设计轻量级即插即用上下文编码器，将多模态上下文（视觉、本体感知、动作）压缩为单个上下文token，通过自适应层归一化（AdaLN）注入基础策略，推理时无额外计算开销
  • 提出上下文token集成策略，利用多试验上下文的简单求和实现策略的逐步自我纠正，适配复杂硬件偏移
  • 在4个精密双手/灵巧操作任务、多种机器人本体上验证方法有效性，实现对未知硬件偏移新工作站的鲁棒部署
Card 04 方法描述

方法描述

  • 基础策略采用基于Flow Matching的VLA架构，包含VLM骨干网络和Diffusion Transformer（DiT）动作去噪器，输入语言指令、图像观测、本体感知，输出动作块
  • 创新点1：上下文化专家数据自动构造：首先在注入的已知硬件偏移下rollout冻结的基础策略，收集次优轨迹作为上下文；随后将原始专家演示的动作预补偿对应偏移、变换proprioception（针对传感器类偏移），生成硬件偏移条件专家数据，严格保证专家数据质量不依赖次优rollout本身
  • 创新点2：轻量上下文编码器：输入15秒上下文窗口内的多视角视频、本体感知、动作序列，用ViT提取视觉token、MLP投影本体和动作token，添加模态类型嵌入后经两个带1D RoPE的自注意力块融合，再通过可学习查询注意力池化压缩为单个与DiT时间步conditioning维度匹配的上下文token；训练时冻结VLM骨干，用与基础策略一致的conditional flow matching损失优化，推理时仅需执行一次编码器生成静态token，通过AdaLN注入策略，闭环控制阶段无额外开销
  • 创新点3：迭代上下文集成：不同试验的上下文token直接求和即可实现集成，利用上下文token潜在空间的结构性（硬件偏移自由度作为主要正交轴），让策略逐步隔离和纠正复杂硬件偏移，避免重复失败
Card 05 数据集与资源

数据集与资源

  • 数据集：基础策略训练采用人工遥操作收集的专家演示数据集；实验覆盖4个精密操作任务：Transport Corn、Insert Tube、Cap Marker（使用6-DoF Piper/Piper-X机械臂）、Assemble Ring（使用2个7-DoF Marvin机械臂+20-DoF Wuji Hand），所有机器人配备1个ego相机和2个腕部相机
  • 模型规模：基础VLA的VLM采用Qwen-3.5-0.8B，动作去噪器为8层DiT，参数量340M；上下文编码器采用预训练DINO v3作为视觉骨干，为轻量级模块

Card 06 评估与结果

评估与结果

  • 评估环境：4个精密操作任务，每个任务测试20轮次未知硬件偏移场景，每轮次最多允许6次试验，场景在试验间完全重置；额外测试2个未知硬件偏移的新工作站跨部署场景
  • 评估指标：成功率（success rate，最多6次试验内完成任务的轮次占比）、性能恢复比（公式为$\rho=\frac{s-s_{\mathrm{base,misaligned}}}{s_{\mathrm{base,nominal}}-s_{\mathrm{base,misaligned}}}$，衡量策略恢复基础策略标称性能的比例）
  • 关键实验结果：

- 基础策略在标称环境下成功率接近100%，但遭遇硬件偏移后骤降至接近0%，仅微调加入偏移rollout数据的变体仍无法有效恢复性能，Gated Memory Policy（GMP）基线也受限于固定注意力窗口，无法持续利用多试验上下文

- Self-Adaptive VLA单次试验即可恢复46%-49%的基线性能，集成最多6次试验后可恢复80%-84%的性能，推理阶段无额外计算开销，显著优于所有基线方法

- 在Insert Tube任务中，单次试验后成功率从0%恢复到20%-25%，集成6次后提升至50%；在Transport Corn任务中完全恢复到100%的标称成功率

- 消融实验显示：本体感知对两种硬件偏移都有增益，尤其对执行器偏置更关键（本体感知差异能强烈提示硬件偏移）；使用密集patch token相比单帧CLS token无显著性能提升，证明轻量编码器设计的有效性

- 跨工作站部署测试中，基础策略在新工作站成功率从95%降至70%和10%，Self-Adaptive VLA仅需最多2次试验的上下文即可将成功率恢复到90%和50%，验证实际部署的鲁棒性

- 潜在空间分析显示学习的上下文token处于高度结构化空间，硬件偏移的自由度作为主要正交轴，解释了简单求和集成策略的有效性
