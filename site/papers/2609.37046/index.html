Card 02 论文概述

论文概述

  • 研究自动驾驶中视觉语言模型（VLMs）对动态状态（特别是速度）的感知与表征能力，通过控制性诊断任务分离编码、语言表达和时序推理三个层面的问题
  • 指出即使模型能输出看似合理的规划结果，并不保证其真正恢复或可靠利用了底层的动态状态信息
  • 通过周围车辆速度估计、当前自车速度检测和未来自车速度预测三个任务，系统揭示了 VLMs 在速度感知上的盲点与失败模式
Card 03 核心贡献

核心贡献

  • 提出一套受控评估协议，针对三个速度相关任务（T1 周围车辆速度、T2 当前自车速度、T3 未来自车速度），测试单帧、多帧、真假 ego 速度提示等多种输入条件，并提供基线比较
  • 结合线性探针、查询条件解码和时序扰动，发现自车速度在隐藏层中比语言输出中明显更易解码（探针 MAE 4.7–5.8 km/h vs 语言输出 10.2–16.8 km/h），而周围车辆速度编码较弱；模型对帧顺序利用有限，多帧输入收益不一致
  • 通过 QLoRA 任务特定微调，证明可改善自车速度的语言读取（如 Qwen3-VL 宏 F1 从 40.4% 提升至 90.1%），但未来速度预测的时序基础仍然有限，且驾驶专用模型 Alpamayo-1.5 同样存在表示-语言表达鸿沟
Card 04 方法描述

方法描述

  • 在 nuScenes 数据集上定义三个分类/回归任务，使用封闭式问答范式，变化视觉上下文（单帧/多帧）和是否提供 ego 速度提示，并引入反事实提示检验视觉验证能力
  • 对多个开源 VLM（如 Cosmos-Reason、Qwen-VL、InternVL2.5 等）进行零样本评估，并通过确定性 JSON 解析和贪心解码保证可复现性
  • 利用线性探针从各层隐藏状态解码速度类别，使用回归探针估计连续速度值，并通过时序打乱实验检验模型对帧顺序的敏感性
  • 对 Qwen3-VL 进行 QLoRA 微调，研究任务特定适应对表示和语言输出的影响
Card 05 数据集与资源

数据集与资源

  • 使用 nuScenes 数据集官方训练/验证拆分，验证集约 5419 样本用于 T2，4429 样本用于 T1，4519 样本用于 T3；探针训练用 6000 样本，QLoRA 适应用完整训练集 20,275 样本
  • 评估模型规模自 4B 至 10B 参数不等的 VLM，如 Cosmos-Reason2-8B、Qwen3-VL-8B、Alpamayo-1.5-10B 等
  • 零样本推理和特征提取使用单块 NVIDIA A40 (48 GB) 或 A100-SXM4 (80 GB) GPU
Card 06 评估与结果

评估与结果

  • 评估指标包括宏 F1（分类）、MAE/RMSE/Spearman ρ（回归），并与随机基线、最优常数预测、以及当前状态持续性（T3 MAE 4.1 km/h）等比较
  • 关键结果：零样本最佳 T2 多帧宏 F1 仅 44.9%（Qwen3-VL 40.9%），最优连续 MAE 10.2 km/h；T3 最佳 VLM MAE 10.6 km/h 远差于持续性基线；反事实 ego 提示使性能跌至随机水平以下；帧打乱后性能常与有序情况相当，表明模型更多依赖“帧袋”而非时序顺序
  • 探针分析显示 T2/T3 的隐藏表示能显著优于语言输出，T2 探针宏 F1 可达 82.3%（Cosmos-R1 5F），T3 探针宏 F1 66.2%；QLoRA 微调后自车速度读取大幅提升，但连续周围车辆速度估计改善有限，多数未来速度增益在帧打乱下仍能保持，表明时序基础未明显增强
