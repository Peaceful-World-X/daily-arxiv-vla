Card 02 论文概述

论文概述

  • 论文提出FOCAL-VLA框架，基于π₀.₅视觉-语言-动作模型，通过子任务引导的几何蒸馏与隐式世界建模，解决传统VLA模型空间与时序理解不足、现有增强方法引入无关场景信息的问题，提升精确与长时序机器人操作性能
  • 现有几何增强、未来预测类VLA方法通常对全场景进行监督，包含与当前操作无关的区域，且未随子任务切换调整监督对象，会干扰模型学习当前交互所需的几何与动态信息
  • 核心目标是让VLA模型聚焦当前子任务相关的空间结构与未来交互动态，无需增加推理时开销即可提升操作成功率
Card 03 核心贡献

核心贡献

  • 提出子任务引导的几何蒸馏方法，将冻结VGGT的几何知识蒸馏到VLA模型，仅对齐当前子任务涉及实体对应的图像区域特征，且随子任务切换的交互实体动态调整监督区域
  • 提出隐式世界建模方法，通过未来运动隐变量实现，利用冻结Track4World提取当前与未来演示帧的特征，仅聚合当前子任务相关区域的特征作为监督目标，建模当前交互的未来3D演化
  • 设计的几何隐变量与未来运动隐变量可联合为动作专家提供条件，推理时无需运行教师模型、使用未来帧或子任务标注
  • 在LIBERO、RoboCasa仿真基准与4项真实世界机器人操作任务上验证方法有效性，消融实验证明了各组件与设计选择的优势
Card 04 方法描述

方法描述

  • 基座采用π₀.₅VLA模型，在原有PaliGemma视觉-语言骨干的输入中新增两组各8个可学习查询：几何查询组$Q_g$与未来运动查询组$Q_m$，其输出隐状态分别形成几何隐变量$Z_g$与未来运动隐变量$Z_m$
  • 子任务引导几何蒸馏：冻结VGGT处理当前多视角观测，通过离线标注的子任务相关实体掩码，聚合对应区域的VGGT特征作为几何监督目标，通过掩码均方误差对齐$Z_g$与目标
  • 隐式世界建模：冻结Track4World处理当前帧与未来动作 horizon 内的演示帧，提取含时序上下文的三维流特征，通过当前子任务掩码聚合对应区域的特征作为运动监督目标，通过平滑L1损失对齐$Z_m$与目标
  • 动作生成与训练：几何、未来运动查询组独立 attend 上下文 tokens，动作专家同时接收上下文、$Z_g$、$Z_m$作为条件生成动作；额外增加原生语言建模分支，通过预测子任务文本提供语义引导，整体损失结合动作损失、几何蒸馏损失、语义损失与运动蒸馏损失
  • 核心创新点在于将几何与未来运动的监督范围限制在当前子任务相关的实体区域，避免无关场景信息的干扰，且两种表示互补覆盖当前空间配置与未来交互演化
Card 05 数据集与资源

数据集与资源

  • 仿真数据集：LIBERO（包含Spatial、Object、Goal、Long四个套件，每个套件10项操作任务，采用机械臂与腕部双视角观测）、RoboCasa（Atomic-24任务集，Human-50设置下每任务50条演示，采用左腕、左/右机械臂三视角观测）
  • 真实世界数据集：Franka Emika Panda机器人平台，包含双水果重排、抽屉打开、抽屉存储、关闭微波炉4项操作任务，共350条10Hz采集的640×480 RGB演示，每任务50-150条成功演示
  • 模型规模：基座为π₀.₅，基于PaliGemma视觉-语言骨干，新增2组各8个可学习查询，几何监督目标维度为2048，运动监督目标维度为256
  • 训练资源：8张NVIDIA A100 80GB GPU，AdamW优化器；LIBERO训练30,000步、batch size 256；RoboCasa训练30,000步、batch size 128；真实世界任务训练16,000步、batch size 256
Card 06 评估与结果

评估与结果

  • 评估环境与基准：仿真环境下评估LIBERO与RoboCasa基准，真实环境下评估Franka Panda平台的4项操作任务，对比基线包括OpenVLA、π₀、π₀.₅、OpenVLA-OFT、GR00T N1.7、SpatialVLA、DreamVLA、GeoPredict、Track4Action等
  • 主要评估指标：任务成功率（%），LIBERO报告各套件成功率与无权重平均值，RoboCasa报告任务平均成功率，真实世界报告每任务与整体成功率
  • 关键实验结果：LIBERO上平均成功率达97.9%，较π₀.₅提升1个百分点，Spatial任务达到100%成功率；RoboCasa上平均成功率达63.4%，较π₀.₅提升8.2个百分点，优于所有对比基线；真实世界任务整体成功率从π₀.₅的47.5%提升至63.8%，4项任务均有提升，其中双水果重排任务提升幅度最大（从25%到50%）
  • 消融实验验证：单独移除几何或未来运动分支均会降低性能；子任务级区域监督优于任务级实体监督与全图像监督；将学习到的隐变量直接条件化动作专家，比仅作为训练辅助信号的效果高4.9个百分点
