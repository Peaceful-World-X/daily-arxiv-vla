Card 02 论文概述

论文概述

  • 提出 Multi-View Unified Camera Fields (MVUCF)，一个仅训练时使用的框架，为多相机视觉-语言-动作（VLA）策略构建共享的面向动作的潜在场。
  • 解决现有多相机 VLA 策略中动作表示在度量深度和跨相机一致性方面的不足，尤其是在接触密集任务中，简单的视图拼接无法有效利用多相机几何信息。
  • 通过训练时注入几何先验，使策略在部署时保持纯 RGB 推理，无需额外传感器或模块，旨在提升多相机机器人操作任务的性能与鲁棒性。
Card 03 核心贡献

核心贡献

  • 对原生多相机 VLA 表示进行 token 级诊断，发现其度量深度可恢复性和跨视图对应能力弱，且深度外部几何特征无法保证动作定位所需的精确 token 身份。
  • 提出 MVUCF 框架，通过坐标查询深度目标和预处理感知的跨视图对应目标，将连续度量深度可恢复性和同世界点一致性联合注入到动作模块所使用的隐藏状态中。
  • 在 LIBERO、LIBERO-Plus 和 RoboTwin 等基准上，通过受控实验（包括表示探针、匹配策略对比、组件消融和真实世界人形机器人试验）证明，联合几何塑造的表示显著提升多相机操作性能，且无需推理时使用几何信息。
Card 04 方法描述

方法描述

  • 基于 GR00T-N1.6 架构，在动作训练前进行几何注入，冻结底层视觉编码器，仅更新 VLM 的第 8-15 层和两个辅助头。
  • 坐标查询深度头：在连续网格坐标上采样特征，结合局部差异和子像素相位，通过 MLP 预测度量深度和不确定性，使用尺度不变对数、逆深度、梯度、接缝及不确定性损失进行监督。
  • 跨视图对应头：通过共享投影器将 token 映射为归一化嵌入，计算匹配对数，并利用软交叉熵、硬负样本 InfoNCE 和边际损失，以高斯分布目标监督空间邻域，确保同一物理点的 token 在不同视图下对齐。
  • 关键创新：采用预处理感知的坐标映射，将原始相机像素经过完整的图像预处理流水线（如 letterbox、resize、crop、patchify 等）映射到 token 网格，避免直接缩放带来的坐标偏差；两个目标互补，共同塑造动作模块的输入表示。
Card 05 数据集与资源

数据集与资源

  • 使用的数据集：LIBERO（含 Spatial、Object、Goal、Long 四个子集）、LIBERO-Plus（七种扰动类型）、RoboTwin（六个任务，涵盖 Touch、Move/Place、Contact 三种动作家族）、真实世界人形机器人任务（双蛋糕放置和杯子嵌套）。
  • 模型规模与参数量：基于 GR00T-N1.6，具体参数量未在节选中明确给出，但该模型是一个大型 VLA 模型。
  • 训练资源：几何注入阶段使用全局批量大小 128，训练 50k 步，约需 18 小时；LIBERO 实验使用 2 块 NVIDIA H100 GPU，RoboTwin 实验使用 4 块 NVIDIA H100 GPU；动作训练步数分别为 60k（LIBERO）和 180k（RoboTwin 联合训练）。
Card 06 评估与结果

评估与结果

  • 评估环境：仿真环境（LIBERO 系列、RoboTwin）和真实世界 Agibot Expedition A2 人形机器人平台。
  • 主要评估指标：任务成功率（SR）、深度平均绝对误差（MAE）、跨视图检索命中率（Hit@1）、检索排名、Cohen's 效应量等。
  • 关键实验结果：

- LIBERO：MVUCF 平均成功率 98.9%（基础 GR00T-N1.6 为 97.4%），尤其在长时序 LIBERO-10 上提升最大（+4.1 点）。

- LIBERO-Plus：在七种扰动下平均成功率提升 22.4 点（从 42.8% 到 65.2%），所有类别均有改善。

- RoboTwin：六任务平均成功率从 38.6% 提升至 61.9%（+23.3 点），Move/Place 和 Contact 家族收益尤为显著。

- 真实世界：成功率从 66.7% 提升至 81.7%（49/60 试验），在两个任务上均表现出正向提升。

- 表示诊断：深度 MAE 从 4.9 cm 降至 0.44 cm，跨视图 Hit@1 从 0.4% 提升至 64%，表明几何注入有效塑造了内部表示。

- 消融：深度目标单独带来 +1.12 点，跨视图单独带来 +1.33 点，联合使用带来 +4.12 点（LIBERO-10），验证了两者的互补性。
