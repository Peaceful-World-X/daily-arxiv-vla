Card 02 论文概述

论文概述

  • 提出一种名为 Urgency-Aware Denoising (UAD) 的推理时框架，用于加速流匹配（flow-matching）视觉-语言-动作（VLA）策略的实时控制。
  • 核心观察：动作块被联合生成却顺序消费，导致不同动作的执行紧急性天然不同。现有方法将动作块视为统一计算单元，忽略了这一非对称性。
  • 旨在解决扩散/流匹配 VLA 策略因迭代去噪导致的推理延迟瓶颈，通过按紧迫性分配去噪计算来减少动作可用等待时间，同时保持任务成功率。
Card 03 核心贡献

核心贡献

  • 紧迫感知推理范式：提出根据动作的执行时间紧迫性非均匀分配去噪计算，而非对整个动作块平均分配，从而大幅降低紧急动作的可用延迟。
  • 实用的系统设计：设计 Urgency-Aware Early Release (UAER) 实现紧急动作提前释放；Trajectory Reconciliation (TR) 在零额外模型评估下恢复联合状态一致性；Ghost Action Correction (GAC) 利用幽灵动作动态补偿提前释放误差。
  • 全面的实证评估：在多个 VLA 架构（SmolVLA, π₀.₅）、模拟基准（LIBERO-Plus, Meta-World+）和真实机器人操作任务上验证，UAD 在保持成功率的同时实现最高 1.89× 的加速。
Card 04 方法描述

方法描述

  • Urgency-Aware Early Release (UAER)：将动作分为紧急动作和尾部动作，紧急动作使用较少去噪步数（K 步）提前释放，尾部动作保留完整的去噪步数（N*步），并让尾部去噪与物理执行重叠。
  • Trajectory Reconciliation (TR)：利用已计算的速度场，按标准步长重新积分紧急动作的状态，在不增加额外 DiT 评估的情况下恢复联合状态一致性，消除轨迹不一致。
  • Ghost Action Correction (GAC)：通过未执行的幽灵动作（完全去噪后的紧急动作对应的状态）估计累积的提前释放误差，并将该误差均匀补偿到剩余的可执行尾部动作中（仅针对加性维度，如笛卡尔平移）。
Card 05 数据集与资源

数据集与资源

  • 评估模型：SmolVLA（在 LIBERO-Plus 和 Meta-World+ 上）和 π₀.₅（在 Meta-World+ 上）
  • 模拟基准：LIBERO-Plus 和 Meta-World+
  • 真实机器人：Dobot Nova2 机械臂，使用微调的 π₀.₅ 检查点，涉及 5 个操作任务
  • 推理硬件：NVIDIA H20 GPU
  • 模型规模：π₀.₅ 为 460M 参数的 DiT 骨干；SmolVLA 为更轻量的 VLA 模型（具体参数量未明确列出，但一般远小于 π₀.₅）
Card 06 评估与结果

评估与结果

  • 评估指标：成功率 (Success Rate) 和 平均动作可用延迟 (Average Action Availability Latency, AAL)
  • 模拟结果：

- 在 SmolVLA + LIBERO-Plus 上，UAD 加速 1.89×，成功率变化 +1.2 个百分点

- 在 SmolVLA + Meta-World+ 上，加速 1.30×，成功率变化 -2.9 个百分点

- 在 π₀.₅ + Meta-World+ 上，加速 1.32×，成功率变化 -1.3 个百分点

- 与最强基线（Vanilla N*, D3P, BAC, RTC）相比，UAD 在成功率和延迟之间取得最佳平衡

  • 真实世界结果：

- AAL 从 34.3 ms 降至 15.2 ms，实现 2.26× 加速，同时成功率保持 84%（与 Vanilla N=10 相同）

- Vanilla N=1 成功率降至 71%，AAL 为 14.9 ms

  • 消融实验验证了 TR 和 GAC 对恢复成功率的有效性，且不增加暴露延迟
