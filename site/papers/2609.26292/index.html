Card 03 核心贡献

核心贡献

  • 建立了 RoboTwin-Phys 基准：首次将物理条件多样性作为机器人操作评估的显式维度，引入了 13 个连续采样且任务相关的物理属性。
  • 发布了带物理标注的训练数据集：提供了超过 5,000 个专家演示，每个演示都标注了 13 维的真实物理参数，可用于物理属性估计和条件感知策略训练。
  • 揭示并量化了物理鲁棒性差距：通过系统评估发现，在标准视觉和布局随机化下表现良好的模型，在物理条件变化时成功率大幅下降，暴露了现有基准未衡量的关键性能维度。
Card 04 方法描述

方法描述

  • 基准构建：基于 RoboTwin-2.0 的 50 个双手操作任务，在场景初始化时对 13 个物理属性（如质量、质心、摩擦系数、关节阻尼、桌面倾斜度等）进行独立的连续随机采样。
  • 任务感知的物理有效性：为部分对物理参数敏感的任务设定了专属的、经过校准的有效值范围，以排除不合理的参数组合，确保评估的是物理稳健性而非人为制造的失败。
  • 可行性验证：在生成评估实例和专家数据时，会预先运行专家规划器，只有专家能够成功完成任务的物理条件组合才会被保留，保证评估环境存在可行解。

数据集与资源

  • 数据集名称：RoboTwin-Phys Training Set v1
  • 数据规模：超过 5,000 个专家演示轨迹
  • 数据内容：包含 HDF5 格式的轨迹数据、MP4 视频以及记录了 13 个物理参数真值的 JSON 元数据文件。
  • 模型评估：对 Fast-WAM、Motus、FACT、π0.5 和 Galaxea-VLA 等代表性模型进行了评估。

Card 06 评估与结果

评估与结果

  • 评估环境：在 RoboTwin-Phys 基准上进行，包含三种设置：Clean（无随机化）、Official Random（仅视觉和布局随机化）和 Physical Random（视觉、布局和物理属性同时随机化）。
  • 主要评估指标：任务成功率。
  • 关键实验结果：

- 所有评估模型在加入物理随机化后性能均出现大幅下降。例如，Galaxea-VLA 的成功率从 Clean 条件下的 93.70% 和 Official Random 条件下的 92.80%，急剧下降到 Physical Random 条件下的 37.82%。

- 性能下降在不同模型间表现出一致性趋势，表明物理鲁棒性是一个普遍且独立的挑战维度。

- 任务级分析显示，对接触动力学、物体稳定性或关节运动敏感的任务（如 beat_block_hammer、pick_diverse_bottles）在物理变化下往往具有更低的成功率。
