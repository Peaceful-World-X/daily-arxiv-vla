Explore, Execute, Evolve: A Skill Acquisition and Reuse Loop for Embodied Agents

Card 02 论文概述

论文概述

  • 提出了 RoboSkill 框架，一个通过 “探索、执行、进化” (Explore, Execute, Evolve) 循环将技能获取与重用相连接的具身智能体系统。
  • 旨在解决通用多模态智能体在机器人任务中每次执行都需从零开始推理和探索物理世界，导致执行成本高昂的问题。
  • 通过将成功的执行记录转化为可复用的技能，引导后续任务的探索和执行，从而提升任务完成的成功率和效率。
Card 03 核心贡献

核心贡献

  • 形式化了“探索-执行-进化”循环，将物理交互与技能构建和重用连接起来，使执行获得的技能能够指导后续的探索和执行。
  • 提出了 RoboSkill 框架，通过构建、检索、适应和更新共享技能库来实现该循环，并引入触觉反馈辅助物理交互，以及可执行代码补充文本指导。
  • 在模拟环境 (LIBERO-10) 和真实机器人上进行了大量实验验证，涵盖任务性能、跨任务迁移、跨智能体重用和技能迭代更新等方面，证明了该框架的有效性。
Card 04 方法描述

方法描述

  • “探索、执行、进化”闭环框架：智能体在探索阶段获取任务所需信息，在执行阶段根据反馈生成并运行代码完成任务，最后在进化阶段将执行记录整合为可复用的技能，用于指导下一次循环。
  • 触觉反馈与可执行代码：在闭环执行中，通过引入压力、力/扭矩等触觉信号补充视觉观察，以降低物理交互的不确定性。同时，技能不仅包含文本指导，还包含可执行代码，以保留可跨场景和任务适应的程序性知识。
  • 技能构建与重用：技能包括文本指导、可执行代码和支持性记录。智能体通过检索元数据选择相关的技能包，将其中的指导和代码应用于新任务的探索和执行。
Card 05 数据集与资源

数据集与资源

  • 模拟环境: LIBERO-10 基准测试的10个任务。
  • 真实机器人: 5个并行工作站，每个配备 Piper 机械臂、夹爪触觉传感器、腕部摄像头和外部俯视摄像头，共执行12个任务（6个简单，6个困难）。
  • 评估模型: GPT-6 Astra, GPT-5.6 Sol, Fable 5.1, Opus 5, Kimi K3 等多个通用多模态智能体。
  • 论文未明确提及模型参数量和具体训练资源（GPU/TPU），因为该方法属于与模型无关的智能体框架。
Card 06 评估与结果

评估与结果

  • 模拟环境 (LIBERO-10): RoboSkill 使4个智能体的首次尝试成功率提高了 12.5 至 25.0 个百分点，平均运行时间降低了 7.6% 至 72.4%。尤其对 Opus 5 提升显著，30分钟内成功率从17.5%提升至82.5%，平均运行时间从80.9分钟降至22.3分钟。
  • 真实机器人: 使用 GPT-6 Astra 时，简单任务成功率从91.7%提高到100%，困难任务从80.0%提高到88.3%，成功试验的平均运行时间至少减少了 14.4%。
  • 跨任务与跨智能体迁移: 技能可在不同任务甚至不同智能体间有效迁移。例如，将 GPT-6 Astra 生成的技能迁移给 GPT-5.6 Sol，使其在真实机器人简单任务上的成功率从13.3%提升至70.0%。
  • 消融实验: 保留可执行代码的技能相比纯文本技能，在大多数智能体上均提升了首次成功率或降低了运行时间。引入触觉输入进行探索，在仿真和真实机器人上均提升了执行效率（如真实机器人上平均成功执行时间从33.6分钟降至20.0分钟）。
