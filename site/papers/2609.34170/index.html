Card 02 论文概述

论文概述

  • 提出 RAVEL，一个面向流式视觉-语言-动作模型的异步滚动推理框架，旨在解决现有流式 VLA 模型中 VLM 编码 与 多步动作生成 带来的高延迟瓶颈

  • 在保持甚至提升基础模型操作能力的同时，显著降低观察-指令响应延迟，并生成更平滑的运动轨迹
Card 03 核心贡献

核心贡献

  • 提出 RAVEL 异步推理框架，首次将 VLM 上下文编码与动作生成解耦，使动作专家可持续运行，无需等待 VLM 编码完成
  • 设计 偏移感知的滚动流去噪机制，通过滚动动作缓冲和时间偏移条件化，让近期动作经一次去噪即可执行，并补偿推理延迟
  • 引入 轻量级快速观察通路，将当前视觉与本体感受特征直接注入动作专家，使下一步动作能对最新观察做出及时响应
  • 在仿真与真实世界实验中，证明 RAVEL 在静态、动态操作和球拍击球等任务中，大幅降低响应延迟，提升成功率与动作平滑度
Card 04 方法描述

方法描述

  • 维护一个 包含不同噪声水平的滚动动作缓冲，每一步将缓冲区整体去噪一步，释放第一个清洁动作，并追加新噪声动作，使得每个动作在执行前经过 K 步渐进细化
  • 异步上下文更新：VLM 编码慢于单步动作去噪，因此将其放在独立进程中异步更新，动作专家始终使用最新可用的 VLM 上下文；同时将上下文年龄编码为归一化时间偏移，作为动作专家的额外条件
  • 快速观察通路：通过轻量图像编码器和本体状态投影，生成当前时刻的特征，经门控交叉注意力注入动作专家层，使动作预测融合最新的视觉信息
  • 训练阶段模拟推理时的偏移分布，使用与滚动缓冲一致的噪声调度和偏移条件进行流式对齐训练
Card 05 数据集与资源

数据集与资源

  • 使用的数据集：LIBERO、RoboTwin 2.0、Dynamic Object Manipulation 基准
  • 基础模型：π₀.₅ 和 X-VLA，保持视觉-语言骨干冻结，只微调动作专家及相关模块
  • 缓冲区长度 K=10，总动作地平线 H=Kh
  • 训练与推理资源：NVIDIA RTX 4090 和 RTX 5090 GPU
Card 06 评估与结果

评估与结果

  • 同步仿真评测：在 LIBERO 和 RoboTwin 2.0 上，RAVEL 维持或轻微提升任务成功率；首个动作延迟降低 2.59–2.92 倍
  • 异步仿真评测：在动态对象操作基准上，RAVEL 任务成功率达 44.06%，添加 FOP 后提升至 46.94%，且任务完成时间最短
  • 真实世界评测：乒乓球回球任务成功率达 90%，观察年龄中位数仅 121.76 ms；网球抓取任务保持成功率的同时，高频轨迹振荡和加加速度明显低于所有基线
  • 消融分析：验证了滚动去噪、偏移条件化和 FOP 各自的重要性，以及时间偏移偏置对补偿真实机器人执行延迟的有效性
