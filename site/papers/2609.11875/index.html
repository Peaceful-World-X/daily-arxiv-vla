Card 02 论文概述

论文概述

  • 针对视觉-语言-动作（VLA）模型中的 transition realizability gap（过渡可实现性差距），提出统一记忆-预测-动作模型 UniMPA
  • 解决三个核心问题：(1) 过渡模糊性，相似观测对应不同操作阶段；(2) 预测-执行不匹配，视觉上合理的未来不一定物理可执行；(3) 经验-实现不匹配，历史可执行动作模式需适应当前场景
  • 通过动作接地过渡接口，将预期过渡、历史经验与动作生成统一为“预测-接地-优化”闭环流程
Card 03 核心贡献

核心贡献

  • 首次将过渡可实现性差距分解为三个可操作的子问题，并设计对应的统一解决方案
  • 提出 Persistent-Selective Future Prediction，结合持续潜在监督和选择性触发像素预测，解决过渡模糊性
  • 构建双向 Visual-Action 与 Action-Visual Memory Banks，利用过渡对齐的检索储存与模拟训练，为预测过渡提供可执行历史依据
  • 设计 Prototype-Biased Flow，从历史动作流形中检索原型并通过流偏移进行场景自适应优化，避免直接复用历史动作
  • 在多个模拟与真实世界基准上以 25-50% 的训练 epoch 达到或超越基线性能，验证高效且可泛化的操控能力
Card 04 方法描述

方法描述

  • 采用 三系统 Transformer 架构：VLM 主干进行视觉-语言理解，World Expert 建模过渡状态，Action Expert 通过 Flow Matching 生成连续动作
  • 过渡对齐双向记忆预训练：利用状态 Mamba 编码时序动态，通过交叉注意力注入视觉-动作双向上下文，并用未来重建与检索模拟损失联合优化键值空间
  • 持续选择性未来预测：在过渡 Token 上施加潜在未来监督，并由 Transition-Critical Trigger Gate 在接触/释放等关键帧触发像素解码，为动作生成提供过渡信息
  • 动作接地原型优化：未来监督的过渡表征查询视觉-动作记忆以检索可执行经验，动作记忆返回视觉接地动作原型，通过 Prototype-Biased Flow 将动作生成流偏向历史可执行流形并适应当前状态
  • 预训练冻结记忆库后，仅去除显式解码头，世界专家与过渡 Token 在推理时继续影响动作生成
Card 05 数据集与资源

数据集与资源

  • 模拟基准：LIBERO、LIBERO-Plus、RoboTwin 2.0、VLABench
  • 真实世界任务：基于 GALAXEA R1 Lite 和 AgileX Cobot Magic 平台的多任务套件，包括动态与长程操作
  • 模型基于 π0.5 基线，使用 VLM 主干，详细参数量未列出（附录见配置说明）
  • 训练资源未明确给出 GPU 类型，但强调仅需基线 25-50% 的训练 epoch
Card 06 评估与结果

评估与结果

  • 评估环境：模拟器与双真实机器人平台，任务涵盖单/双臂、动态与长程操作
  • 主要指标：成功率（%）
  • 模拟结果：LIBERO 98.6% (π0.5: 96.9%)，LIBERO-Plus 85.3% (π0.5: 73.6%)，RoboTwin 2.0 Hard 提升 18.5 个百分点
  • 真实世界结果：综合 12 项真实任务，平均成功率比 π0.5 高 12.6 个百分点
  • 消融实验：验证了 Persistent-Selective 预测、双向记忆预训练、未来导向重建与原型优化的各自贡献，均显著优于去除对应组件的变体
  • 定性分析展示过渡 Token 跨越相机的时间对齐、可执行动作原型的空间一致性，以及像素级未来预测对接触状态的可视化
