Card 02 论文概述

论文概述

  • 研究视觉-语言-动作模型（VLA）在接收到包含隐含有害意图的指令时的执行与监控安全问题
  • 核心问题是：当机器人收到看似普通的任务指令（如“打开炉灶”），但其背后隐藏着有害目的（如“烧猫的爪子”）时，现有的安全监控手段是否能有效拦截
  • 研究发现，机器人本身会无视意图执行任务，而文本安全监控器（guards）主要只能拦截直白表述的恶意指令，对隐含的危害几乎无效；同时，机器人训练过程会削弱模型内部对危害信号的表征能力
Card 03 核心贡献

核心贡献

  • 设计了一套受控的意图测试框架，在固定动作、物体和场景的前提下，仅通过改变指令中意图的表述明确程度（L1隐含、L2直接、L3直白）来测试VLA及安全监控器
  • 发现并证明了“监控器漏掉的，机器人会执行”的现象：文本监控器对隐含危害近乎失效，导致高达95% 的有害指令被执行且未被标记
  • 揭示了机器人训练会侵蚀危害信号的规律：在Llama和Gemma两个模型家族中，线性探针（probe）在基础语言模型和视觉语言模型上能近乎完美地分离有害与无害指令，但在经过机器人训练后，尤其是在面对隐含危害时，这种分离能力显著下降
Card 04 方法描述

方法描述

  • 基于LIBERO-Goal的五个厨房任务生成指令，每个任务配有四种版本：无害对照和三种不同程度（L1隐含、L2直接、L3直白）的有害原因陈述，均由大型语言模型（LLM）生成并经LLM和人工双重验证
  • 在 π₀.₅ 和 OpenVLA-OFT 两个VLA模型上执行这些指令，记录任务完成情况
  • 使用三种文本监控器（Llama Guard 3、WildGuard、Qwen3Guard）和一种内部激活探针（线性探针）对指令进行安全性评分，监控器阈值在WildChat数据集上校准为1%误报率
  • 探针技术通过提取模型残差流的平均池化激活来训练逻辑回归分类器，并在Llama-2 → Prismatic → OFT和Gemma → PaliGemma → π₀.₅两个模型演变路径上进行对比，以观察危害信号随训练阶段的变化
Card 05 数据集与资源

数据集与资源

  • 主要测试环境：LIBERO-Goal 基准测试（5个厨房任务）
  • 机器人模型：π₀.₅ (基于PaliGemma-3B) 和 OpenVLA-OFT (基于Prismatic-7B)
  • 探针分析涉及的模型：Llama-2-7B、Prismatic-7B、OFT、Gemma 2B、PaliGemma-3B
  • 安全监控模型：Llama Guard 3、WildGuard、Qwen3Guard
  • 监控器阈值校准数据集：WildChat（10,000个良性提示）
  • 指令验证由 Claude Opus 5 和 Claude Sonnet 5 作为评判模型完成
  • 训练资源：实验在 NVIDIA A10 GPU 上进行
Card 06 评估与结果

评估与结果

  • 评估环境：LIBERO模拟器，每个指令在5种不同场景初始布局下运行，共175次测试
  • 评估任务成功的指标：机器人在300步内完成LIBERO内置的成功检查
  • 安全监控指标：标记率（Flag %） 和 泄漏率（Leak %） — 泄漏率指机器人完成任务且监控器未发出警告的测试比例
  • 关键实验结果：

- 机器人行为：π₀.₅ 在所有意图级别（L1-L3）下的任务成功率（均约95%）与无害对照无异，完全无视意图。OFT 因无法处理额外句子而全部失败，这并非出于安全考虑

- 文本监控器效果：监控器在L3（直白）级别标记率高达92-98%，但在L1（隐含）和L2（直接）级别标记率极低，导致66%至97% 的L1/L2级别有害运行发生泄漏

- 探针性能下降：在Llama-2和Prismatic上，探针检测L1危害的AUROC均为1.00，但在经机器人训练的OFT上降至0.73。同样，在PaliGemma（0.99）到π₀.₅（0.79）的路径上也观察到类似显著下降，表明机器人训练专门削弱了对隐含有害意图的表征
