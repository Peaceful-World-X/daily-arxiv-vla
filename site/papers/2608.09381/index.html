Card 02 论文概述

论文概述

  • 提出 JEPA-WAM，一种在预训练 V-JEPA 表示空间中构建的潜在世界动作模型（WAM），通过共享预测器将潜在状态转移预测与连续动作生成耦合在一起。
  • 旨在解决现有潜在 WAM 在预测目标选择和预测监督与动作生成集成方式上的局限性，同时避免显式未来帧生成带来的部署开销。
  • 通过构造空间结构化的联合当前–未来转换目标，保留密集的 patch 级信息，直接优化策略骨干网络，提升模型在视觉和空间分布外（OOD）场景下的泛化能力。
Card 03 核心贡献

核心贡献

  • 提出 JEPA-WAM，一种基于 V-JEPA 表示空间的潜在 WAM，利用共享预测器实现潜在转换建模与动作生成的紧密耦合。
  • 设计了一种空间结构化的联合当前–未来转换目标，该目标保留密集 patch 级信息，并能无缝迁移到预训练 VLA 策略中，增强其泛化性。
  • 在 LIBERO-Plus、RoboTwin 2.0 和真实世界双手机械臂操作中展示了强大的 OOD 泛化能力，其中基于预训练 π₀.₅ 的实例化在 LIBERO-Plus 上取得 86.3% 的最佳总体结果。
Card 04 方法描述

方法描述

  • 基于冻结的 V-JEPA 2.1 编码器构建视觉表示空间，分别编码当前观察和由当前–未来帧堆叠构成的联合目标，后者捕捉任务共有的视觉时间结构。
  • 使用 Qwen2.5-0.5B 作为共享预测器，同时处理视觉特征和任务指令，输出用于转换预测的视觉 token 隐状态和用于动作生成的条件表示。
  • 通过共享预测器，转换预测损失直接优化策略骨干网络，动作生成部分则使用 DiT 流匹配专家，从条件表示中生成动作块。
  • 训练时联合优化转换预测（patch 级余弦距离）和动作生成损失，部署时仅保留动作生成分支，不引入额外推理开销。
Card 05 数据集与资源

数据集与资源

  • 使用的数据集：LIBERO（四个子集）、LIBERO-Plus（七种 OOD 场景）、RoboTwin 2.0（20 个任务，Clean 和 Random 设置）、真实世界 AgileX COBOT Magic 双手机器人平台。
  • 模型规模：V-JEPA 2.1 编码器约 300M 参数，Qwen2.5-0.5B 预测器约 0.5B 参数，DiT 流匹配动作专家。
  • 训练资源：论文未明确提及具体 GPU 型号，但提及使用标准训练配置，推理效率在 RoboTwin 上单次推理耗时 85ms（11.76 Hz）。
Card 06 评估与结果

评估与结果

  • 评估环境：LIBERO 标准四类任务（ID），LIBERO-Plus 七种 OOD 场景（相机、机器人、语言、光照、背景、噪声、布局），RoboTwin 2.0 的 Clean 和 Random 设置，以及真实世界双手机器人操作。
  • 主要评估指标：任务成功率（%）。
  • 关键结果：

- 在 LIBERO 上，JEPA-WAM 平均成功率达 96.7%，与强基线持平；π₀.₅ + JEPA 目标提升至 97.8%。

- 在 LIBERO-Plus 上，JEPA-WAM 取得 79.2%，为无大规模机器人策略预训练方法的最优结果；π₀.₅ + JEPA 目标达到 86.3%，为所有方法中的最佳。

- 在 RoboTwin 2.0 上，JEPA-WAM 在 Clean 设置下达到 79.9%，Random 下达到 36.9%；π₀.₅ + JEPA 目标在 Clean 下提升至 84.6%。

- 真实世界实验中，JEPA-WAM 在视觉和空间位移下表现出强泛化能力。
