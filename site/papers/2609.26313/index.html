Card 03 核心贡献

核心贡献

  • 提出 非侵入式双速率安全包装器，在不修改冻结 VLA 参数的前提下，通过外部危险预测与回滚实现主动安全防护
  • 设计 四输出风险预测器，从机载视觉和本体感觉预测身体级和物体级危险的 概率 与 时间-到-危险 (TTH)
  • 提出 基于强化学习的三动作安全决策器，结合安全航点记忆与回滚，并通过不对称演员-评论家训练和规则教师热启动实现有效学习
  • 在 3 个不同 VLA 骨干（Pi-0、OpenVLA-OFT、Pi-0.5） 上进行仿真验证，并在 3 个真实机器人任务 上完成仿真到现实的直接迁移，无需真实世界强化学习
Card 04 方法描述

方法描述

  • 数据收集与标注：从策略执行轨迹中标注身体级碰撞/卡死和物体级掉落/倾覆，构建危险标签
  • 风险预测器：基于冻结的 Qwen2.5-VL-3B 骨干，使用多帧视觉、本体感觉和指令，训练预测四个值（身体危险概率、身体 TTH、物体危险概率、物体 TTH），损失由二元交叉熵和 L1 组成
  • 安全决策器：低频元策略（MLP） 以最近关节状态和风险向量为输入，选择 noop / record / rollback；采用 PPO + 衰减的行为克隆（BC） 训练，利用仿真特权信息构建不对称评论家，并用规则教师进行热启动
  • 部署时：预测器异步运行，决策器每 20 步干预一次，rollback 通过运动规划返回到保存的安全航点，清空危险局部最小值，触发随机基础策略重新生成动作
Card 05 数据集与资源

数据集与资源

  • 评价基准：LIBERO（Object、Goal、Spatial、10、90），共 24 个任务；真实机器人任务（叠衣服、叠杯子、放玩具抽屉）
  • 模型规模：风险预测器使用 Qwen2.5-VL-3B 骨干加轻量头部；决策器为 128 维 MLP
  • 训练数据：从仿真滚动收集的轨迹，仿真中用规则检测器标注危险，真实机器人数据用于微调预测器
Card 06 评估与结果

评估与结果

  • 评估指标：成功率、各类型危险率（Haz-Body / Haz-Obj）、每千步危险事件数（Events/1k）
  • 仿真结果（24 任务，16 随机种子）：SafeLoop 在 OpenVLA-OFT 上将身体危险率从 22.9% 降至 5.7%，物体危险和事件数同样显著降低，成功率（67.7%→68.2%）基本持平；在 Pi-0 上事件数从 1.21 降至 0.22
  • 对比基线：SafeLoop 在 Pi-0 上优于 SAFE + stop、SAFE + backtrack 和纯 RL 安全策略，获得最高成功率和最低物体危险、事件数
  • 消融研究：取消视觉（No Image）或仅使用单帧上下文（H=1）会显著降低安全与成功；回滚 优于原地重采样动作，因为它能脱离局部危险区域；学习决策器 优于固定阈值规则教师
  • 真实机器人迁移：在 3 个物理任务上，仅微调风险预测器，SafeLoop 将危险事件减少约 78%，成功率和基础策略控制速率几乎不变
