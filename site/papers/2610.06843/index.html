Card 02 论文概述

论文概述

  • 针对 LLM 智能体文本记忆无法记录任务执行细节 的问题，提出利用演示视频提供视觉上下文学习
  • 解决 演示视频直接插入上下文导致的三大问题：视频过长拖慢推理、少量关键帧丢失接触细节、智能体在不同执行阶段需要不同片段的信息

Card 03 核心贡献

核心贡献

  • 首次将 视频上下文学习 引入工具驱动的机器人智能体，将演示作为可查询的环境而非一次性前缀
  • 提出 递归视频上下文学习 (RV-ICL) 方法，将演示视频构建为基于子事件分割的四层层次结构，并支持智能体递归访问
  • 在 LIBERO-PRO 上将 HarnessVLA 成功率从 92.6% 提升至 96.5%，在 LIBERO-Plus 上从 86.7% 提升至 95.8%
  • 通过消融实验证明 递归按需访问 优于在上下文中放置关键帧或完整视频
  • 方法无需训练、无需更改 VLA 策略，且可跨规划器迁移
Card 04 方法描述

方法描述

  • 将单个演示视频根据 子事件（抓取、释放、关节动作） 离线分割为四层层次结构：

- L₀: 任务关键帧（事件驱动采样，含第三视角和腕部视角）

- L₁: 阶段（相邻子事件之间的文本描述，记录持续时间、末端执行器运动、达成结果）

- L₂: 时刻（每个子事件周围的文本索引）

- L₃: 片段（阶段或时刻的短视频片段，任意摄像头可选）

  • 智能体通过三个只读工具（view_task_video、view_task_map、view_demo_clip）递归访问层次：

- 规划前：读取 L₀–L₂ 获取任务全局结构和子目标

- 执行中：每当需要更多细节时（如抓取前、步骤失败后），智能体调用 view_demo_clip 加载当前子目标对应的 L₃ 片段，仅将该片段添加上下文

  • 通过 观察预算 限制同一阶段或时刻的重复查看，防止无限递归
  • 创新点：将演示转化为可导航的索引，让智能体根据自身进度动态决定何时查看哪一部分，符合具身智能体信息需求随时间变化的特点
Card 05 数据集与资源

数据集与资源

  • 数据集：LIBERO（包含 Spatial、Object、Goal、LIBERO-10 四个子集），在 LIBERO-PRO (分布偏移: 指令重定向与位置交换) 和 LIBERO-Plus (7种扰动) 上评估
  • VLA 模型：π₀.₅ 经 RLinf 微调，作为接触步骤的冻结策略
  • LLM 规划器：GPT-6 Astra (低推理强度)，运行于 Codex CLI；也在 Claude Code + Opus-4.7 上验证了可迁移性
  • 感知：SAM 3 分割 + 反投影获取 3D 点
  • 训练资源：无需训练，推理成本依赖 LLM API 调用
Card 06 评估与结果

评估与结果

  • 主要评估基准：

- LIBERO-PRO：8个分布偏移单元格 (每格 50 次试验，共 400 次)

- LIBERO-Plus：7类扰动下 120 个分层抽样变体

  • 评估指标：任务成功率（模拟器内置目标检查）
  • 关键结果：

- LIBERO-PRO 总体：RV-ICL 提升 3.9 个百分点 (92.6% → 96.5%)，在长序任务 LIBERO-10 上增益最大 (L10-T: +5.0%, L10-S: +12.0%)

- LIBERO-Plus 总体：提升 9.1 个百分点 (86.7% → 95.8%)，在光照变化下增益最显著 (+17.6%)

- 消融实验：仅关键帧或完整视频效果有限，递归访问层次在 LIBERO-10 上实现最高成功率 (L10-T: 90.0%, L10-S: 84.0%)，且代理在 97% 的回合中执行了重新进入，平均每回合加载 4.8 个片段

- 代理行为分析：代理主要在抓取或释放前以及步骤失败后重新进入层次，片段查看集中在接触动作（40% 抓取时刻, 30% 释放时刻）
