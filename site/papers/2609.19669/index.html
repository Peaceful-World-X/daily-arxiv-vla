Card 02 论文概述

论文概述

  • 核心研究 Vision-Language-Action (VLA) 策略 上对抗补丁的移除后持续性效应，现有对抗评估仅关注持续攻击下的任务表现，未分离补丁移除后的恢复能力
  • 研究目标是引入精确的状态恢复协议，测量补丁移除后的恢复率，区分对抗特有效应与视觉遮挡、动作误差幅度等替代解释
  • 同时评估 proof-of-concept 恢复适配器的效果，分析干预延迟对恢复能力的影响
Card 03 核心贡献

核心贡献

  • 引入状态恢复协议与四类匹配控制组，揭示无法用遮挡、动作误差幅度、方向持续性解释的持续性对抗效应
  • 识别并修正 LIBERO 仿真器的三处状态恢复保真度问题，提供重放一致性检查，确保恢复执行的精确复现
  • 证明恢复适配器的效果 strongly 依赖干预延迟，说明 VLA 防御需联合评估鲁棒性与响应时间
Card 04 方法描述

方法描述

  • 采用 状态恢复协议：在匹配的动作块边界移除对抗补丁，恢复仿真器状态后用相同策略和剩余步长预算执行，测量任务恢复率
  • 定义攻击起始点为对抗补丁的动作偏差连续两次超过匹配随机补丁的95分位，避免普通遮挡导致的虚假起始点
  • 设计扩展检查点保存序列化物理状态、控制器变量、任务/渲染变量、边界观察，通过重放一致性验证精确恢复
  • 恢复适配器基于 LoRA 训练，最小化带补丁输入与干净输入的策略输出差异，同时保留干净样本的 nominal 行为，干预延迟由激活边界独立控制
Card 05 数据集与资源

数据集与资源

  • 使用仿真数据集 LIBERO-Long 与 LIBERO-Goal，均基于 robosuite 实现，各包含10个机器人操作任务
  • 评估模型为官方 OpenVLA-OFT 检查点与 base OpenVLA，OpenVLA-OFT 以20Hz预测8步连续动作块
  • 攻击采用 EDPA 对抗补丁，尺寸为50×50像素（占图像面积5%），同时应用到第三人称与腕部相机视角
  • 恢复适配器训练使用 LoRA rank 32，优化器为 AdamW，学习率5×10⁻⁵，余弦衰减，梯度裁剪阈值1.0
Card 06 评估与结果

评估与结果

  • 评估环境为 robosuite 中的 LIBERO 任务套件，主要指标为恢复成功率、对抗过量（adversarial excess，单位百分比点pp）、95%配对bootstrap置信区间
  • 持续攻击下 EDPA 将 LIBERO-Long 任务成功率从91.0%降至9.0%，LIBERO-Goal 从94.0%降至20.0%，证明补丁的有效性
  • 补丁移除5个动作块后，LIBERO-Long 对抗诱导状态恢复率仅36.2%，远低于固定方向控制组（87.0%）、偏差匹配控制组（89.9%）与随机补丁控制组（95.7%），对抗过量最高达59.4pp
  • base OpenVLA 上同样观察到正的遮挡参考对抗过量，5个块后达39.4pp，证明效应不依赖于连续动作块解码机制
  • 恢复适配器在1个块干预延迟时将恢复率从7.7%提升至47.4%，但延迟至5个块时降至20.5%，LIBERO-Goal 上从88.1%降至39.3%，干预延迟的影响远大于不同训练策略的差异
