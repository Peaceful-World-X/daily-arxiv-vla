研究单位

Card 02 论文概述

论文概述

  • 提出 ROS2SmolVLA，一个将 Hugging Face 的轻量级视觉-语言-动作模型 SmolVLA 与工业级轻量机器人（如 Universal Robots）通过 ROS 2 集成的开源框架
  • 解决当前 VLA 模型在工业环境中部署面临的计算资源限制、合规性挑战以及实验室硬件与真实工业硬件之间的差距问题
  • 验证 SmolVLA 在 Universal Robots UR10e 上执行拾取放置任务的可行性，并提供部署指导
Card 03 核心贡献

核心贡献

  • 开发并开源了 ROS2SmolVLA 框架，实现了 SmolVLA 与 ROS 2 的接口，使其能够直接控制工业级轻量机器人
  • 实现了基于 Cartesian 坐标的跨实施例控制方法，无需直接关节控制，提高了模型在不同机器人平台间的可移植性
  • 提供了完整的容器化推理与仿真环境，支持在消费者级硬件（Nvidia RTX 4080）上进行推理，并支持通过 Gazebo 进行数字孪生验证
  • 在工业级硬件 UR10e 上进行了系统的验证，覆盖了分布内/外、颜色、位置、形状等多种测试场景，并总结了部署经验教训
Card 04 方法描述

方法描述

  • 基于 Hugging Face 的 LeRobot 框架 和 Cartesian Motion Controller 构建系统架构，采用分布式边缘到工作站范式
  • 使用 Cartesian 坐标空间（TwistStamped 消息）控制末端执行器，替代直接关节控制，实现跨机器人平台泛化
  • 实现多模态数据采集，通过 lerobot-roscam 包同步摄取多个相机（静态相机和腕部相机）的视觉数据，并结合机器人本体感知状态
  • 采用 Docker 容器化整个推理环境，隔离 CUDA 运行时和 PyTorch 扩展，确保从开发机到边缘设备的可重复性
  • 模型微调使用 SmolVLA 的 450M 参数预训练基础模型，基于 349 个遥操作记录的序列进行训练，输出 Cartesian 速度指令
Card 05 数据集与资源

数据集与资源

  • 自建数据集：ROS2SmolVLA_ur10e，包含 349 个拾取和放置任务序列，通过 Hugging Face 发布
  • 硬件配置：Universal Robots UR10e 机器人 + Robotiq Hand-E 夹爪，配有两个 Microsoft Azure Kinect 相机和一个末端执行器相机
  • 计算资源：边缘设备为 Nvidia Jetson AGX Orin，推理工作站为 Nvidia RTX 4080 (16GB VRAM)，模型训练使用 Nvidia L40S GPU 服务器
  • 基础模型：SmolVLA (450M 参数)
Card 06 评估与结果

评估与结果

  • 评估环境：真实 UR10e 机器人拾取放置任务，涵盖 9 个结构化测试场景（T1-T9），包括位置、颜色、形状、初始配置的变化
  • 评估指标：分为拾取成功率和放置成功率，并针对颜色提示遵循度、目标箱发现率等进行了专项评估
  • 关键实验结果：

- 分布内任务：拾取成功率 78.33%，放置成功率 72.50%（成功拾取后放置成功率 92.47%）

- 分布外任务：拾取成功率 76.56%，放置成功率 46.88%（成功拾取后放置成功率 61.22%），显示模型具备一定的泛化能力，但放置动作受颜色偏见影响显著

- 模型表现出对绿色和蓝色的强烈视觉偏见，在颜色选择和放置触发上尤为明显

- 验证了 SmolVLA 在工业级硬件上的基本可行性，但成功率目前尚不足以支持实际部署，主要受限于训练数据量不足
