Card 02 论文概述

论文概述

  • 针对现有安全过滤器依赖固定约束规格、无法适应运行时变化的安全需求问题，提出语言条件化安全过滤框架，将 Hamilton-Jacobi (HJ) 可达性安全过滤扩展为条件于自然语言约束的形式
  • 使用单一学习到的安全过滤器处理多种语言指定的安全约束，而非为每个约束单独训练过滤器，从而支持通用机器人策略的灵活安全部署
  • 在基于视觉的机器人操作任务（Safe Grab、Safe Wipe、Stack Blocks）中评估该框架在约束满足、分布外泛化及安全-任务成功权衡方面的能力
Card 03 核心贡献

核心贡献

  • 提出语言条件化安全过滤的数学公式，将 HJ 可达性安全过滤从固定约束扩展到自然语言条件化约束，支持单一过滤器对多种约束的表示与执行
  • 在 Safe Grab、Safe Wipe 和 Stack Blocks 三个操作任务上系统评估语言条件化安全过滤器，研究其约束满足能力和干预率
  • 证明单一通用（General）语言条件化过滤器的性能可与针对每个约束单独训练的Single过滤器相竞争，且在部分任务中碰撞率更低、干预率更小
  • 评估十一个视觉-语言模型（VLM）作为机器人操作失败函数的表现，分析其作为运行时安全推理预言的能力与局限
  • 发布包含 5,000 条 LIBERO 风格操作轨迹的数据集（约 88.6% 包含至少一次安全违规），用于支持安全关键机器人学习研究
Card 04 方法描述

方法描述

  • 采用语言条件化的 HJ 安全评论家-演员架构，评论家 $Q_\theta(z_t, a_t)$ 基于潜表征 $z_t = \phi(o_t, c)$ 评估候选动作的安全性，其中 $c$ 为自然语言约束
  • 使用 $\pi_{0.5}$ 的 VLM 骨干网络联合编码多视角视觉观察、语言约束和机器人本体感知信息，通过 mean pooling 聚合 token 序列生成固定维度表征 $z_t$
  • 运行时安全过滤机制：若名义动作的安全值 $Q_\theta(z_t, a_t^{\text{nom}}) < \epsilon$，则切换至 HJ 演员策略；通过采样名义动作的高斯扰动和演员动作候选，选择最接近名义动作且满足安全约束的动作
  • 使用 SAC（Soft Actor-Critic） 训练 HJ 评论家和随机演员以最大化安全性，损失函数基于 HJ 可达性 Bellman 方程
  • 探索两种观察模态：Ground Truth（GT）（特权模拟器状态与多热约束编码）和 Vision-Language（VL）（原始 RGB 图像、语言约束与本体感知）
Card 05 数据集与资源

数据集与资源

  • 数据集：5,000 条 LIBERO 风格安全关键操作轨迹（约 88.6% 包含至少一次安全违规）；任务环境基于 RoboSuite
  • 模型规模：VLM 骨干使用 $\pi_{0.5}$，token 维度 $D=2048$；评估的 VLM 包括 Gemini Robotics-ER 1.6、GPT-5.5、RoboBrain2.0-32B、Qwen3-VL-32B、Cosmos v3 Super 等十一个模型
  • 动作空间：Safe Grab 和 Stack Blocks 使用 7 维动作（末端执行器平移、轴角旋转、夹爪命令）；Safe Wipe 使用 3 维纯平移动作，所有动作空间归一化至 $[-1, 1]$
  • 观察模态：Ground Truth（GT）（特权模拟器状态）和 Vision-Language（VL）（第三人称与腕部 RGB 视角、语言约束、本体感知）
Card 06 评估与结果

评估与结果

  • 评估环境：三个 RoboSuite 操作环境（Safe Grab、Safe Wipe、Stack Blocks-3/4），涵盖碰撞避免和顺序操作两类语言约束
  • 评估指标：成功率（SR）、碰撞率（CR）、顺序正确性（OC）、干预率（IR）
  • 关键实验结果：

- 语言条件化安全过滤器显著降低碰撞率：General 过滤器在 Safe Grab VL 设置下 CR 降至 46%，低于 Single 过滤器的 56%；且干预率更低（8.80% vs 17.71%）

- General 过滤器在 Stack Blocks 中顺序正确性（OC）达到 80% 以上，且在未见过的颜色/形状约束下表现出部分泛化能力（Color-Only 设置下 OC 保持 82%）

- 过滤器能尊重指定约束而非保守规避所有物体：在 Safe Grab 中，机器人接触 benign 物体（74%）的频率远高于接触指定 obstacle（26%）

- 当前 VLM 作为运行时失败预言仍不可靠：Gemini Robotics-ER 1.6 检测失败准确率仅 56.4%，且多数模型存在严重类别偏差（如 RoboBrain2.5-8B 对 non-failure 准确率 100%，但对 failure 仅 1.6%）
