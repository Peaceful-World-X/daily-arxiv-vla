Card 02 论文概述

论文概述

  • 本文针对视觉-语言-动作（VLA）模型在机器人操作任务中的Token压缩需求，指出现有压缩方法（如KV缓存复用、Token剪枝）通常基于视觉相似性、注意力得分等间接信号判定Token可压缩性，未直接考虑压缩对下游机器人动作的影响，在激进压缩场景下动作保持性不足
  • 研究目标是提出Action-JND（动作可察觉差异）建模范式，将VLA的Token压缩转化为动作条件的容忍度建模问题，以机器人动作偏差作为压缩安全的直接判定标准
  • 核心解决的问题是：如何量化单个视觉Token的表示变化对VLA策略动作预测的影响，实现既降低推理成本、又保证闭环控制下机器人动作可靠性的Token压缩
Card 03 核心贡献

核心贡献

  • 提出Action-JND概念，将经典JND理论从人类感知、通用机器感知进一步扩展到具身感知场景，重新定义Token压缩的“可察觉性”为语言条件机器人动作的偏差，而非图像保真度或通用任务性能
  • 在深度视觉特征空间中实例化Action-JND，设计轻量级的Token级JND估计器，通过对抗式训练学习每个Token可容忍的最大扰动，并将扰动幅度转换为动作容忍度排序信号
  • 将Action-JND作为即插即用模块集成到KV缓存复用、Token剪枝两类主流VLA压缩范式，分别用于排序可复用Token和优先移除高容忍度Token，无需修改原有压缩框架的核心逻辑
  • 在LIBERO机器人操作基准上的实验表明，所提方法在多种压缩比下均能提升压缩可靠性，尤其在激进压缩场景下增益显著，同时适配离散动作（OpenVLA）和连续动作（OpenVLA-OFT）两种VLA策略
Card 04 方法描述

方法描述

  • 核心创新是提出动作条件的JND边界定义：对于VLA策略，单个视觉Token的表示变化是可接受的，当且仅当该变化导致的策略动作预测偏差不超过预设阈值，突破了传统压缩方法依赖间接代理信号的局限
  • 关键技术包括：

1. 轻量级空间结构保留的JND估计器架构：单视图场景下将256个视觉Token重塑为16×16空间特征图，通过空间卷积、多组残差块提取特征，预测每个Token的逐元素扰动，保留视觉Token的空间拓扑结构；双视图场景下采用两个独立参数的同构估计器分别处理主视角、手腕视角Token，输出拼接得到最终JND图

2. 仅优化估计器的训练框架：训练时冻结预训练VLA策略，损失函数联合最大化预测扰动幅度、最小化清洁特征与扰动特征对应的动作偏差（离散动作用动作Token分布的KL散度，连续动作用加权L1回归距离），通过平衡两项权重学习通用的动作容忍度映射

3. 即插即用的压缩集成方案：推理时将预测的扰动转换为绝对/相对JND分数，相对分数用于KV缓存复用（降低Token特征尺度的影响），绝对分数用于Token剪枝，作为排序信号接入现有压缩框架的候选Token池，优先保留动作敏感Token、压缩动作 tolerant Token
