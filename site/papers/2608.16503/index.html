Card 02 论文概述

论文概述

  • 提出 NebulaVLA，一种异步双频视觉-语言-动作（VLA）模型，旨在解决真实机器人部署中的效率-性能权衡、跨具身泛化和执行平滑性三大瓶颈
  • 通过解耦高级语义推理（System 2，~10Hz VLM）与低级动作控制（System 1，~20Hz DiT生成器），优化计算资源分配与模块化部署
  • 引入 GESTURE-7 统一动作表示和 Guide Action 算法，分别解决跨机器人动作语义鸿沟和动作块边界抖动问题
Card 03 核心贡献

核心贡献

  • 异构双频架构：借鉴快-慢认知范式，将 deliberative reasoning（System 2，10Hz）与 reactive control（System 1，20Hz）解耦，显式分离计算负载，支持分布式部署并最小化交互延迟
  • GESTURE-7 统一表示：提出7D连续末端执行器向量（[x,y,z,r,p,w,gesture]），通过自然语言关键词（如"grasp"）统一不同具身（机械手、夹爪）的动作语义，原生支持强化学习训练
  • Guide Action 机制：借鉴图像外推（Image Outpainting）思想，在扩散去噪过程中通过二进制掩码强制保留已知动作锚点，确保相邻动作块的无缝边界过渡，消除传统后处理平滑需求
  • 三阶段训练流程：Stage 1（S2 SFT）→ Stage 2（GRPO-based RL）→ Stage 3（S1 SFT），渐进式优化语义规划与动作执行能力，严格对齐训练-推理频率
Card 04 方法描述

方法描述

  • System 2：基于 Qwen3-VL 的视觉语言骨干网络，以可学习token提取隐藏层特征，输出抽象动作引导（~10Hz）
  • System 1：采用 Q-Former 压缩S2引导信息与高频视觉输入，通过扩散Transformer（DiT）以20Hz频率生成执行动作；引入预训练 DINOv2 的对比微调以改善视觉-本体感受对齐
  • Guide Action 技术细节：将下一动作块的生成条件于前一块中未执行的引导动作点（随机采样0-3个），通过掩码M强制执行 $A_{full}^{t-1}=M\odot A_{prior}^{(t-1)}+(1-M)\odot A_{noisy}^{t-1}$，其中M[1..k]=1严格保留锚点区域，M[k+1..T]=0为模型生成区域
Card 05 数据集与资源

数据集与资源

  • 仿真数据集：LIBERO-Plus（大规模具身操纵基准，包含10,030个程序生成任务，覆盖5个难度级别L1-L5，7个扰动维度共21个子维度）
  • 真实世界平台：AgiBot A2 双臂机器人，配备立体RGB相机
  • 训练资源：单节点配备 8×H800 GPU，batch size为96
  • 部署硬件：NVIDIA RTX 4070 GPU
Card 06 评估与结果

评估与结果

  • 评估指标：Success Rate（SR）、Inference Latency（推理延迟）、Joint Jerk（关节加加速度/平滑度）
  • 仿真结果：在LIBERO-Plus上达到85.5%平均成功率，超越InternVLA-M1（81.3%）4.2%，动作生成加速约2.7倍
  • 真实世界结果：在Pick-and-Place任务达到92.08% SR，Packaging Line Feeding任务达到92.5% SR，均优于InternVLA-M1（77.91%和72.5%）；异构架构将平均推理延迟从115ms降至42ms
  • 平滑度改进：Guide Action机制使关节jerk平均降低25.6%（关节12降低41.2%，关节13降低45.1%），有效抑制异步执行导致的边界抖动
  • 消融验证：三阶段训练策略相比仅SFT基线提升2.5%总成功率，GESTURE-7在Layout维度提升6.2%；但Camera扰动维度因固定视觉-空间映射假设存在性能退化
