Card 05 方法描述

方法描述

  • 采用 System-2-to-System-1-to-System-0 分层推理-执行架构：首先通过多模态 VLA Backbone 生成结构化 Reasoning（），随后通过 Reasoning-Conditioned Action Decoder 生成任务级动作（），最终由机器人特定 Low-level Controller 执行
  • 多模态推理骨干网络：基于 NaVILA 初始化的 LLaVA 风格架构，输入包括 RGB 图像、深度图、点云和语言指令，通过 Modality-specific Encoders 和 Projection Layers 映射至统一隐空间，并由 backbone 自回归生成结构化推理序列
  • Reasoning-Conditioned Action Decoder：引入可学习的 Locomotion 和 Behavior 查询，通过 Cross-Attention 聚合观察与推理上下文，分别预测连续运动指令（$V_x, V_y, \omega$）和离散行为原语 $\alpha \in \mathcal{A}_{\text{beh}}$，实现可学习的推理到物理动作映射
  • 两阶段训练流程：第一阶段通过监督 Fine-tuning（SFT）在 MobileVLA-CoT 上进行 CoT 对齐与动作预测对齐；第二阶段采用 GRPO（Group Relative Policy Optimization） 强化学习，基于运动奖励、行为奖励和格式奖励优化推理-动作一致性，同时通过 KL 正则化约束与冻结参考策略的偏离

Card 07 评估与结果

评估与结果

  • 评估环境与基准：

- 仿真导航：VLN-CE 协议下的 R2R-CE 与 RxR-CE Val-Unseen 分割

- 真实世界部署：Unitree Go2 四足机器人（导航与交互）和 Unitree G1 人形机器人（移动操作，包括物体搜索、导航、接近、抓取、搬运、放置等长视野任务）

  • 主要评估指标：

- VLN-CE：NE（Navigation Error，越低越好）、OS（Oracle Success）、SR（Success Rate）、SPL（Success weighted by Path Length）、nDTW

- 机器人控制：全任务成功率（Full-task Success）、端到端延迟、故障模式分解

  • 关键实验结果：
