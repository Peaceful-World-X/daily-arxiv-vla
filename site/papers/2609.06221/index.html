Card 02 论文概述

论文概述

  • 论文解决语言引导机器人操作中的 identity switch 问题：在杂乱场景中，机器人可能对语义兼容但物理上不正确的对象执行几何上有效的动作
  • 指称对象由三个耦合的潜在变量共同决定：target（目标）、anchor（锚点）和 reference frame（参考帧）
  • RefGuard 通过维护这三个变量的联合后验来延迟承诺，构建 frame-conditioned object-centric scene graph，并通过决策策略执行、澄清、重新观察或中止
Card 03 核心贡献

核心贡献

  • 将 identity switches 表征为语言引导机器人操作中的一种故障模式，将其形式化为对三个耦合变量（target instance、anchor instance、reference frame）的联合推理
  • 引入 RefGuard，一个基于两层场景图的 grounding 框架，将 frame-independent geometry 与 directional relations 分离，结合联合 target-anchor-frame 后验推理
  • 在 UF850 真实机器人平台上和 3,200 集程序化套件上进行评估，显示 RefGuard 在无 identity switch 的情况下正确执行 90% 的模糊试验
Card 04 方法描述

方法描述

  • 使用 SAM 3 进行感知，构建 frame-conditioned two-layer scene graph（分离 frame-independent geometry 的 E_pos 层和 frame-dependent directional relations 的 E_dir^f 层）
  • 语言解析使用 OpenAI GPT-4o 将指令分解为 primitive queries
  • 维护 Joint Hypothesis Table 对 target-anchor-frame 进行联合推理，每行 h=(i, j_1, ..., j_m, f, s_h, w_h) 代表一个完整解释
  • 决策策略：根据后验集中度决定 execute / clarify / reobserve / abort
  • 后验感知规划和验证：执行前检查目标/锚点是否可见、姿态是否匹配、空间约束是否仍成立
Card 05 数据集与资源

数据集与资源

  • 真实机器人平台：UF850 arm
  • 感知硬件：两个 Intel RealSense D435i RGB-D cameras
  • 语言模型：OpenAI GPT-4o
  • 基准测试：3,200 episodes 的程序化 LIBERO-style 套件，涵盖 20 object categories，每场景 5-20 objects
  • 与 GR00T 和 π_0.5 两个 VLA 基线进行比较
Card 06 评估与结果

评估与结果

  • 评估环境：真实 UF850 机器人平台（6 个设置的身份切换压力套件）和程序化 LIBERO-style 套件（3,200 episodes）
  • 主要评估指标：Task Success (TS)、Identity-Switch Rate (ISR)、Correct Execution (CE)、Execution Coverage (Cov)、Deferral Rate (DR
  • S1（干净场景）：RefGuard 达到 93.3% 任务成功率（28/30）
  • S2-S4（身份感知 grounding）：在 90 个模糊试验中 0 次 identity switch，正确执行 90.0%（81/90），而 GR00T 和 π_0.5 的 ISR 分别为 52.0%/40.0% 和 42.3%/36.0%
  • S5（扰动恢复）：RefGuard 达到 86.7% 恢复率（26/30）
  • S6（硬否定）：RefGuard 达到 100% 正确 defer 率（30/30）
  • 程序化套件（3,200 episodes）：RefGuard 将可解指令的正确执行率从 56.6% 提高到 80.5%，同时 deferral rate 更低（19.5% vs 43.4%）
