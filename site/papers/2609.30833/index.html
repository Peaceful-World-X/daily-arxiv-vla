研究单位

  • MARS Lab, Nanyang Technological University（南洋理工大学 MARS 实验室）
  • 作者包括 Chuanliang Xie, Boyu Ma, Gen Li, Yizhou Liu, Houwang Chen, Xinyu Zhou, Jianfei Yang
Card 02 论文概述

论文概述

  • 研究分层视觉-语言-动作（VLA）系统中高层规划器与低层执行器之间的接口问题，提出两个核心要求：规划生成必须足够快以满足实时控制频率（R1），且生成的规划必须真正对动作生成产生实质影响（R2）
  • 以 π₀.₅ 为基础构建了 Waypoint Token-AR 分层 baseline，发现其使用 token 级自回归解码生成 7 个 waypoint 需要 57 次 VLM 前向传播，且删除规划中的空间端点对任务成功率几乎无影响（U=0.0），暴露了规划-执行之间的严重错位
  • 针对 R1 提出 Block-AR（waypoint-aligned block-autoregressive）解码将最大串行前向传播次数从 57 降至 8；针对 R2 提出 NGM（Normalized Goal Modulation）通过分层目标路径与防快捷方式训练，使执行器真正依赖 waypoint 规划
Card 03 核心贡献

核心贡献

  • 对基于 π₀.₅ 的 waypoint 分层系统进行可控干预研究，发现标准后缀词元条件（suffix-token conditioning）使空间目标端点几乎失效：端点删除仅导致 0.6% 的动作变化，且任务成功率无下降（U=0.0 pp）
  • 提出 Block-AR 解码方式，将最大串行规划深度从 57 次降至 8 次，在真实机器人上将规划延迟从 1094 ms 降至 125 ms（8.7× 加速），机械臂运动时间占比从 29% 提升至 66%，并支持可学习的 d=0 计划终止标记
  • 识别出 displacement-integrator shortcut（位移积分快捷方式）问题：直接注入目标位移会导致模型依赖计划而忽略视觉信息；设计 NGM 通过相位门控、条件噪声和 dropout 约束分层目标路径，在保持视觉响应（82% 保留率）的同时将端点敏感度从 0.6% 提升至 42.6%，使 LIBERO-Long 成功率从 91.0% 提升至 96.2%
Card 04 方法描述

方法描述

  • 基础架构基于 π₀.₅：PaliGemma 骨干网络（SigLIP 视觉编码器 + Gemma-2B 语言模型，共约 3.66B 参数）作为高层规划器，300M 参数的 flow-matching 动作专家作为低层执行器，两者通过 LoRA（rank 16）适配，可训练参数仅 46.4M–49.6M（占总参数的 1.27–1.35%）
  • Waypoint 表示与提取：每个 waypoint 包含目标配置 q、夹爪状态 g 和持续时间 d，通过 Automatic Waypoint Extraction (AWE) 算法从演示数据中离线提取，使用 338 个专用 token ID（6 维关节配置 + 夹爪 + 34 个 duration code + 结构 token）编码，支持 d=0 作为计划终止标志
  • Block-AR 解码：将每个 waypoint 视为一个 block，块内注意力采用双向掩码、块间保持因果注意力，输入按 block 而非 token 移位，每个 block 通过一次 backbone 前向传播生成，并通过三次 LM-head 调用读取配置、夹爪和持续时间，使 LIBERO 上最大前向传播次数从 57 降至 8，16 自由度机器人上从 120 降至 8
  • NGM 归一化目标调制：将目标位移归一化为 $\widehat{\Delta} = (q_i - s_i) / \sigma_\Delta$ 后与夹爪嵌入拼接，经零初始化输出投影的 MLP 生成残差 r，经相位门 $g(t) = \text{clip}((t-0.2)/0.3, 0, 1)$ 后添加到每层的 AdaRMS 条件中；训练时对端点添加高斯噪声（σ_c=0.7）并以 15% 概率替换为 null embedding，防止 displacement-integrator shortcut
Card 05 数据集与资源

数据集与资源

  • 仿真数据集：LIBERO 四个 suites（Spatial, Object, Goal, Long），联合训练使用 1,693 个演示片段，评估遵循 OpenPI 官方协议（每 suite 10 任务 × 50 初始状态 = 500 回合，步数预算 220/280/300/520）
  • 真实机器人数据集：Rokae AR5-5 双臂机器人（配 Robotiq 2F-85 夹爪），配备腕部摄像头和外部摄像头，三个双手任务：pepper-banana 放置、pepper 交换、color-matched shelf 放置，共收集 154 个演示（120 个用于训练，15 验证，15 测试）
  • 模型规模：PaliGemma 2B 参数 + 300M flow expert，LoRA 适配后总可训练参数约 46.4M–49.6M
  • 训练配置：global batch size 包含 80 个 planner 窗口和 80 个 action-expert 片段，知识隔离（knowledge insulation）权重 λ=1.7，使用 LoRA rank 16 适配所有线性层
Card 06 评估与结果

评估与结果

  • 评估环境与基准：LIBERO 仿真四套件（500 episodes/suite）及真实双臂机器人（3 任务 × 20 trials/方法），与 π₀.₅ 官方结果及 Token-AR baseline 对比
  • 主要评估指标：任务成功率（Success Rate）、规划延迟（Plan Latency）、请求往返时间、运动占空比（Motion Duty Cycle）、动作敏感度（S）、任务效用（U）
  • 关键实验结果：

- Block-AR 在 LIBERO 四套件平均成功率 95.85%，加入 NGM 后提升至 98.45%（较 Token-AR +1.75，较 π₀.₅ +1.60），其中 LIBERO-Long 从 91.0% 提升至 96.2%

- 真实机器人上 Block-AR 规划延迟从 1094 ms 降至 125 ms（8.7×），请求往返时间从 1266 ms 降至 293 ms，运动占空比从 28.7% 提升至 65.6%

- 真实机器人成功率：Token-AR 48/60，Block-AR 46/60，Block-AR + NGM 51/60

- NGM 使端点敏感度从 0.6% 升至 42.6%，端点删除导致成功率下降 7.4 pp（vs suffix-only 的 0.0 pp），证明 waypoint 真正 Faithful
