Card 02 论文概述

论文概述

  • 提出 WorldAuditBench，一个面向三维交互式世界的审计基准，包含 213 个异常任务，覆盖 13 个由 Unreal Engine 5 和 Three.js 构建的环境
  • 研究多模态智能体如何将 动作（导航、交互） 与 视觉推理 相耦合，以自主识别模拟环境中的物理、空间、时间和语义异常
  • 当前最先进的视觉-语言模型（VLM）和视觉-语言-动作模型（VLA）在该任务上的性能远低于人类，揭示了系统探索与证据收集的瓶颈
Card 03 核心贡献

核心贡献

  • 构建了首个综合性 3D 世界审计基准 WorldAuditBench，包含 213 个任务、13 种环境和覆盖 5 大异常家族的 15 个细分类别
  • 定义了完整的异常分类体系（静态物理、交互物理、空间一致性、时间一致性、语义一致性），并提供了需要交互或对比观测才能检测的异常案例
  • 系统比较了 VLM-only 代理（交互式探索 + 在线推理）与 VLA–VLM 两阶段代理（固定轨迹分析），论证了动作与推理耦合的重要性
  • 通过广泛的消融实验分析了起始距离、探索预算、任务指引、多异常共存等因素对审计性能的影响
  • 揭示了现有模型在异常暴露（能否找到异常区域）和异常识别（暴露后能否正确识别）之间的差距，以及记忆工具对证据收集的作用
Card 04 方法描述

方法描述

  • 场景与任务构建：基于公开可用的 UE5 和 Three.js 场景，人工植入各类物理、时空或语义异常，经多轮人工验证确保任务质量
  • 审计范式 1（VLM-only）：单一 VLM 代理通过环境动作（移动、转向、交互）、记忆工具（检索历史帧、笔记）和异常报告工具进行在线探索与推理，在 40 步动作预算内提交最终报告
  • 审计范式 2（VLA–VLM）：先由 VLA 模型 Open-P2P 1.2B 进行 60 秒无推理探索，生成固定轨迹；再由 VLM 离线分析轨迹并生成异常报告
  • 评估机制：使用 GPT-6 Astra 作为自动裁判（VLM-as-a-judge），对照每个任务预定义的评估准则判断报告是否正确
Card 05 数据集与资源

数据集与资源

  • WorldAuditBench 数据集：213 个任务，13 个环境（UE5 占 126 个，Three.js 占 87 个），涵盖室内、城市、历史、工业、自然 5 种场景
  • 评估模型：GPT-6 Astra、Claude Opus 5、Gemini 3.8 Flash、Muse Spark 1.3、Qwen 3.8 Flash（均为 API 调用）；VLA 模型为 Open-P2P 1.2B
  • 计算资源：主要依赖商业 API 调用，未进行本地训练或微调；人类基线由约 10 位计算机科学博士生参与
Card 06 评估与结果

评估与结果

  • 评估环境：基于 UE5 和 Three.js 的交互式 3D 环境，代理通过 API 访问环境动作和观测
  • 主要指标：成功率（SR），即报告准确识别目标异常的任务比例
  • 关键结果：

- VLM-only 代理最高成功率：GPT-6 Astra 42.3%，Gemini 3.8 Flash 32.4%，Claude Opus 5 28.2%；VLA–VLM 代理最高仅 17.4%（Gemini 3.8 Flash）

- 人类成功率为 83.4%，远高于所有模型

- 时间一致性异常对模型最具挑战（SR ≤ 12.5%），静态物理和语义异常相对容易

- 缩短起始距离、增加探索预算可显著提升成功率；移除异常类型提示导致 VLM 代理成功率下降 17.5 个百分点

- 在多异常场景下，代理识别所有异常的比率极低（两异常：7.1%，三异常：4.8%），但锚定异常的成功率保持稳定

- VLM 代理在异常暴露（几何覆盖 91.1% vs 47.4%）和暴露后识别成功率（62.1% vs 47.3%）上均大幅优于 VLA–VLM 范式
