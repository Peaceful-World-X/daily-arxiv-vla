Card 02 论文概述

论文概述

  • 提出ARCHITECT（Agentic Robot Code with Human In ThE loop CorrecTions）框架，将机器人策略获取定义为交互式程序合成任务，无需任何机器人特定训练数据
  • 解决现有 Vision-Language-Action（VLA）黑盒策略不可解释、难以修正、微调成本高，以及传统模块化方法存在自然语言指令与执行之间的specification gap的核心问题
  • 通过人类在环的自然语言修正与持久化技能库，实现可 steerable 的机器人策略生成与跨任务知识迁移，在真实机器人复杂操作任务上验证有效性
Card 03 核心贡献

核心贡献

  • 首次提出将人类在环自然语言修正与程序合成结合的机器人策略学习框架ARCHITECT，无需机器人演示数据即可生成可执行策略
  • 设计基于程序执行trace的故障定位机制，可将人类自然语言修正精准 grounding 到代码层面，实现非专家用户也可使用的策略迭代优化
  • 构建持久化Skill Library机制，将单次修正转化为可复用的技能，实现长期上下文学习与跨任务知识迁移，摊销人类操作成本
  • 开发包含控制、感知、本体感知三类工具的工具套件，支持LLM智能体合成覆盖多类复杂操作任务的模块化机器人策略
  • 在Franka Panda机器人8个真实操作任务上的实验表明，该方法在成功率、鲁棒性上均显著优于SOTA VLA模型与程序合成基线
Card 04 方法描述

方法描述

  • 采用Claude Opus 4.6大语言模型作为编排智能体，自动生成调用工具套件的可执行机器人策略代码，完成从自然语言指令到机器人动作的映射
  • 当策略执行失败时，结合程序执行trace精准定位故障对应的代码行或工具调用，接收人类自然语言修正后重新生成策略，无需专家代码编辑或奖励函数调优
  • 将人类修正蒸馏为结构化技能存入持久化技能库，后续任务生成策略时自动加载技能库内容，复用历史修正经验避免重复故障
  • 创新点：通过程序执行trace实现故障的细粒度定位，打破端到端黑盒策略的不可解释性；自然语言修正机制大幅降低非专家的交互门槛；技能库实现跨任务的经验复用，无需重新收集数据或微调模型
Card 05 数据集与资源

数据集与资源

  • 实验平台：Franka Panda机械臂，配置Robotiq 2F-85夹爪、腕部ZED-mini立体相机、场景ZED 2i相机，采用DROID机器人操作标准配置
  • 模型与组件：编排LLM为Claude Opus 4.6，底层运动规划采用cuRobo实现碰撞free最小急动度轨迹生成，感知模块采用现成开放词汇检测器、抓取生成器、VQA模型等开源组件
  • 训练资源：无需机器人特定训练数据，无需针对任务微调模型，仅需调用现有开源模型与API，无额外GPU/TPU训练成本
Card 06 评估与结果

评估与结果

  • 评估环境：真实世界Franka Panda机器人平台，共设计8个复杂操作任务，涵盖拾取放置、铰接物体操作、可变形物体操作、长程多步任务等6类挑战场景
  • 对比基线：传统程序合成方法Code As Policies (CaP)，VLA模型π₀、π₀.5，以及VLM修正变体ARCHITECT-VLM，附录额外对比Inner Monologue、ProgPrompt、MolmoAct2、GR00T N1.7等基线
  • 评估指标：成功率（SR）、目标条件召回率（GCR）、标准化任务进展（NTP），人类评估额外统计每轮次人类查询次数、跨任务成功率
  • 关键实验结果：

- ARCHITECT在所有8个任务上的SR、GCR、NTP均显著高于所有基线，例如长程任务「布下取香蕉放入盘子」的SR达0.8，而π₀仅0.1、CaP为0

- 技能库可大幅摊销人类成本：后续任务的平均每轮次人类查询次数从4.67次降至0.83次（Δ=3.83, p=0.036），3/6的参与者无需任何额外修正即可完成任务

- 技能库支持跨任务迁移：Task 2无技能库时成功率为0，加载Task 1的技能库后成功率升至4/6，证明历史修正经验可复用于新场景/新物体

- 人类修正可解决VLM无法感知的故障模式：如深度估计误差导致的抓取/放置高度偏差、物体物理属性相关的操作要求（如「慢速闭合夹爪避免棒球滑落」）
