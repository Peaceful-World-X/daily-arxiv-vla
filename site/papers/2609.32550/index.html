Card 02 论文概述

论文概述

  • 研究了视觉-语言-动作（VLA）模型对单步观测扰动（one-step perturbations）的鲁棒性，揭示了 momentarily observation corruption（短暂观测损坏）这一被忽视的安全威胁
  • 通过系统实验发现，单步扰动在关键时间步施加时会导致现有VLA模型性能严重下降，且影响程度取决于动作块执行长度（action execution length）
  • 提出了 CARE（Consistency-Aware Robust Execution length selection）方法，通过动态调整执行长度来平衡鲁棒性与任务性能，无需额外训练或推理成本
Card 03 核心贡献

核心贡献

  • 首次对VLA模型在单步扰动下的鲁棒性进行了系统性研究，揭示了多种VLA模型在临界时刻遭受严重性能下降的问题
  • 分析发现更长的动作块执行长度会放大单步扰动的影响，因为一次错误的预测会导致连续多步执行错误动作
  • 提出CARE方法，基于当前动作块与前一预测未执行部分的一致性来动态选择执行长度，在检测到不稳定时自动缩短执行长度
  • 该方法无需额外训练、无需额外策略推理、无需修改模型架构，具有广泛适用性
Card 04 方法描述

方法描述

  • 一致性检测框架：在每一步推理时，将当前预测的动作块 $\mathbf{A}_t^{1:H}$ 与前一动作块的未执行部分 $\mathbf{A}_{t-H_{\text{prev}}}^{H_{\text{prev}}+1:H_{\text{prev}}+H}$ 进行比较
  • 差异函数设计：使用归一化欧氏距离计算每步动作差异 $r_i$，并通过折扣累积和 $D(\mathbf{A}_t^{1:H}, \hat{\mathbf{A}}^{1:H}) = \sum_{i=0}^{H-1} \gamma^i r_i$ 衡量整体差异，其中折扣因子 $\gamma=0.85$
  • 自适应执行长度选择：当差异超过阈值 $\tau$ 时选择较短的执行长度，否则选择最大允许长度 $H_{\text{max}} = \lfloor K/2 \rfloor$，从而在清洁观测下保持高性能，在扰动下限制错误传播
Card 05 数据集与资源

数据集与资源

  • 基准数据集：LIBERO（40个任务，涵盖四个任务套件）和 Meta-World 基准
  • 评估模型：$\pi_0$、$\pi_0$-FAST、$\pi_{0.5}$、SmolVLA、X-VLA 五种VLA模型
  • 扰动类型：8种单步扰动，分为三类：

- 图像输入扰动：过曝（Overexposure）、黑屏（Blackout）、运动模糊（Motion blur）、丢包（Packet loss）

- 状态输入扰动：零填充（Zero fill）、状态尖峰（State spike）、随机状态（Random state）

- 图像+状态扰动：数据丢失（Data loss）

Card 06 评估与结果

评估与结果

  • 评估指标：采用 Bottom10%-SR（最低10%干预步骤的平均成功率）来评估最脆弱时刻的性能，以及清洁环境下的任务成功率
  • 关键发现：

- 每个评估模型在至少一种扰动下，Bottom10%-SR 相比清洁成功率下降超过 50个百分点

- $\pi_0$-FAST 和 SmolVLA 对图像扰动特别敏感，而 $\pi_0$ 和 X-VLA 对状态扰动尤其脆弱

- 执行长度 $H$ 越大，清洁性能与扰动下性能的差距越明显，验证了执行长度放大扰动效应的假设

  • CARE效果：在LIBERO基准上，CARE显著提升了所有模型在扰动下的Bottom10%-SR（如$\pi_0$在Data loss下从7.4%提升至53.5%），同时基本保持了清洁任务性能，且计算开销极低
