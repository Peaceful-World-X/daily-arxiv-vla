Card 02 论文概述

论文概述

  • 针对现有Vision-Language-Action（VLA）模型在动态环境（含移动目标、环境突变）中性能骤降的核心问题，明确瓶颈为大规模动态操作数据集稀缺，且主流VLA依赖单帧观测缺乏时空推理能力
  • 提出大规模动态操作数据集与基准DOMINO，以及动态感知VLA架构PUMA，旨在实现通用的动态环境机器人操作
  • 通过系统性实验验证动态数据训练的时空表示具备泛化性，可迁移至静态操作任务，PUMA相比基线实现6.3%的绝对成功率提升
Card 03 核心贡献

核心贡献

  • 系统分析动态机器人操作的独特时空挑战，区分其与静态操作范式的差异，明确推进动态具身智能研究的必要性
  • 提出DOMINO可扩展的动态操作数据集生成与闭环评估流水线，支持多机器人本体、通过动力学系数实现分层难度缩放、配套多维评估指标
  • 提出PUMA动态感知VLA架构，通过融合历史运动线索与目标中心运动预测，隐式推断移动物体未来状态，相比基线性能提升6.3%
  • 验证动态数据训练的鲁棒时空表示可迁移至静态操作任务，拓展了动态数据的应用价值
Card 04 方法描述

方法描述

  • 基础架构：基于Qwen3-VL构建的统一VLA架构，共享骨干网络同时优化动作策略与辅助未来特征预测器，辅助预测器仅在训练阶段启用，推理阶段无额外计算开销，单次前向传播可输出长度为K的动作块
  • 场景中心时空动力学编码：输入包含长期语言指令、当前多视角观测、历史动态上下文，对采样的历史第三人称帧计算光流图替代原始帧堆叠，与当前视觉输入共同送入视觉编码器，提供显式密集运动线索以捕捉场景历史动态
  • 目标中心动态表示：训练阶段采样未来帧，通过GroundedDINO+SAM2分割操作目标，用冻结的DINO编码器提取目标区域未来特征作为监督信号，引入可学习世界查询聚合时空上下文，隐式预测目标未来隐状态，通过余弦相似度损失优化
  • 训练策略：端到端采用监督行为克隆训练，总损失为动作回归L1损失与世界预测余弦距离损失的加权和，平衡动作学习与动态感知能力
Card 05 数据集与资源

数据集与资源

  • 数据集名称：DOMINO（Dynamic Object Manipulation Operations Benchmark），基于RoboTwin 2.0框架与SAPIEN仿真引擎构建，包含35个动态操作任务，覆盖5类机器人本体（从单臂操作到复杂双臂协作），包含超过11万条专家轨迹，支持规范设置与域随机化设置采集；任务分三级动态复杂度（Level 1低阶可预测动力学、Level 2高阶可预测动力学、Level 3随机突变动力学），通过动力学系数α控制最大目标速度（α=0对应静态场景）
  • 模型规模：PUMA基于Qwen3-VL构建，未公开具体参数量
  • 训练资源：VLA模型训练采用NVIDIA A100 GPU，数据生成与评估采用NVIDIA RTX GPU
  • 公开资源：项目页面与代码已公开，地址为https://H-EmbodVis.github.io/DOMINO/ 和 https://github.com/H-EmbodVis/DOMINO
Card 06 评估与结果

评估与结果

  • 评估环境与基准：主要评估基于DOMINO@0.1（Level 1动态，动力学系数α=0.1）仿真基准，补充静态场景RoboTwin 2.0基准与真实机器人实验；基线包括ACT、OpenVLA、OpenVLA-OFT、RDT、π₀、π₀.5、π₀-FAST、VLA-Adapter、InternVLA-M1、基于Qwen3-VL的VLA等，所有基线均已在DOMINO数据集上完成微调（ACT按任务单独微调，其余跨任务微调）
  • 评估指标：静态场景采用成功率（SR）；动态场景除SR外，引入操作分数（MS），包含路径完成度（RC）与安全惩罚因子（目标离开安全区或碰撞环境时降低分数）
  • 关键实验结果：

- 现有SOTA VLA模型在动态环境性能大幅下降，例如ACT模型在静态Adjust Bottle任务成功率97%，零样本迁移到动态环境仅37%，微调后提升至65%

- PUMA相比所有基线达到最优性能，绝对成功率提升6.3%

- 动态数据训练的模型时空表示可迁移至静态任务，泛化性优于仅静态训练的策略

- 消融实验验证了历史光流编码、世界查询预测模块的有效性，模型推理延迟满足实时控制需求
