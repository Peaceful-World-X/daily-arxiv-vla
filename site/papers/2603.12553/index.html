Card 02 论文概述

论文概述

  • 现有基于世界模型的视觉-语言-动作（VLA）机器人操作框架存在两类核心缺陷：密集未来预测会引入视觉冗余并累积误差导致长程规划漂移，现有稀疏方法（语义子目标/隐式表示）缺乏显式运动学 grounding，无法与低层动作执行对齐。
  • 论文提出StructVLA框架，将生成式世界模型重构为显式的、物理 grounded 的结构化规划器，通过预测基于运动学线索的稀疏结构化帧作为中层视觉子目标，解决长程操作的误差累积和物理对齐问题。
  • 研究目标是在仿真和真实机器人场景中实现可靠的长程操作，同时验证方法的泛化性和鲁棒性，覆盖基础操作和复杂长程任务。
Card 03 核心贡献

核心贡献

  • 物理grounded的结构化规划目标：设计自动化数据整理流水线，从机器人运动学线索（夹爪状态切换、运动学转向点）自动提取结构化帧，无需语义子任务人工标注，提供稀疏且具有机械意义的任务进度锚点。
  • 统一的StructVLA框架：提出两阶段训练范式，第一阶段训练自回归世界模型预测结构化帧作为中层视觉子目标，第二阶段在共享视觉-语言-动作离散词表下将结构化规划能力迁移到低层动作生成，桥接高层视觉规划与低层运动控制的gap。
  • 强实证性能：在SimplerEnv-WidowX基准上达到75.0%平均成功率，在LIBERO基准上达到94.8%平均成功率；真实场景部署在基础抓取放置和复杂长程任务上均展现出可靠的泛化性和鲁棒性。
Card 04 方法描述

方法描述

  • 核心方法为两阶段统一训练框架，所有模态（视觉、语言、动作）共享同一离散词表：采用Emu3 VQ tokenizer对视觉和语言输入离散化，采用FAST tokenizer对连续动作离散化并映射到共享词表的动作专属token区间。
  • 第一阶段（结构化规划器训练）：初始化自UniVLA的预训练世界模型，训练自回归Transformer以指令和历史观测为条件，预测基于运动学线索提取的结构化帧，仅对视觉token计算交叉熵损失，同时采用滑动窗口增强 densify 监督信号，提升训练效率。
  • 第二阶段（动作策略迁移）：在预训练结构化规划器基础上微调，输入为交错的“语言指令+历史观测-动作token”序列，监督信号仅针对动作token，让模型将结构化视觉预测能力转化为低层动作控制能力。
  • 关键创新点1：基于运动学线索的自动化结构化帧提取流水线，通过夹爪状态切换窗口、运动学转向点检测、最小时间间隔约束和动作L2变化填充得到候选帧，再用GPT-5.2离线过滤冗余/无关帧，完全无需人工标注，推理阶段无需额外VLM辅助。
  • 关键创新点2：采用LoRA（秩32）进行参数高效微调，在保留预训练模型视觉预测能力的前提下，以极低计算成本实现高质量的结构化预测和动作控制。
Card 05 数据集与资源

数据集与资源

  • 使用数据集：BridgeData V2（SimplerEnv基准训练用）、LIBERO基准的四个任务套件（SPATIAL、OBJECT、GOAL、LONG，共40个任务，每任务50条专家演示）、真实场景自有数据集（包含4个抓取放置任务的1152条轨迹、1个长程整理任务的648条轨迹）。
  • 模型规模：基于8.5B参数的自回归Transformer架构，初始化自UniVLA的预训练世界模型权重。
  • 训练资源：未明确公开具体GPU/TPU硬件型号，采用LoRA（秩32）进行参数高效微调以降低计算开销；不同场景训练配置为：SimplerEnv（规划器30k步、策略20k步，batch size 32/128）、LIBERO（规划器10k步、策略4k步，batch size 32/196）、真实场景（规划器2k步、策略2k步，batch size 32）。
Card 06 评估与结果

评估与结果

  • 评估环境：仿真基准包括SimplerEnv-WidowX（评估分布偏移下的策略泛化性）、LIBERO四个任务套件（评估多任务和长程一致性）；真实场景部署在Franka机械臂上，包含4个基础抓取放置任务、1个带干扰物的长程整理任务，同时评估零样本泛化（新颜色/几何形状物体）和动态扰动（人类干预）场景。
  • 主要评估指标：任务成功率、抓取成功率、训练收敛步数、不同历史上下文长度下的性能表现。
  • 关键实验结果：

- SimplerEnv-WidowX平均成功率为75.0%，超越所有对比基线，在需要精确空间执行的堆叠任务上表现尤为突出。

- LIBERO平均成功率为94.8%，在长程任务套件LIBERO-Long上显著优于基线，验证了结构化规划对长程误差累积的抑制效果。

- 真实场景基础抓取放置任务平均成功率为87.5%，比基线UniVLA高20.0%；长程整理任务完成8/10次试验，远高于UniVLA的4/10次和SpatialVLA的2/10次。

- 零样本泛化到新物体成功率达80.0%，动态扰动下成功率保持80.0%，均显著优于UniVLA的30.0%和40.0%。

- 训练效率显著更高，仅需10k步即可达到66.7%的精度，优于UniVLA的12k步和RoboVLMs的50k步；且性能随历史上下文长度增加持续提升，而UniVLA性能随上下文增长下降，证明结构化规划器能有效利用长时序信息减少长程漂移。
