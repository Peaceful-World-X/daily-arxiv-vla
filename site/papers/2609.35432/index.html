Card 02 论文概述

论文概述

  • 指出当前视觉-语言-动作（VLA）模型将观测和指令直接映射为动作，导致对指令不敏感、泛化能力差，且长周期任务中的状态跟踪、约束检查与错误恢复难以实现
  • 提出 Physical Coding 范式，将物理世界状态表达为可执行程序（Code as World），将任务规划与执行过程表达为可执行程序（Code as Policy），使智能体能如软件编码代理般观察、行动、验证并不断改进
  • 构建了 HexaAnything 物理编码代理，通过在仿真和真实机器人上的实验，验证其在长周期操作、科学实验以及自进化层面的有效性
Card 03 核心贡献

核心贡献

  • 形式化了 Physical Coding，引入 Code as World 和 Code as Policy 作为物理世界的可执行接口，将任务状态、约束、进展与执行过程统一表示为代码
  • 开发了 HexaAnything 系统，整合语言模型、状态观察、验证器与动作工具，形成从感知到执行与反馈的闭环代理
  • 在 RoboCasa365、自建的 PhyBench 模拟实验室以及真实 双机械臂AgileX机器人 上进行了实验，证明 Harness 层面的改进、数据与模型的进化以及工具自动修正的效果
  • 提出了四目标物理自演化框架（Harness、模型、数据与环境、硬件与计算基座），并给出基于独立验证的版本准入与变更管理机制
Card 04 方法描述

方法描述

  • 将机器人任务的状态与知识记录为 Code as World（包含对象、关系、约束和进度谓词），将任务分解、工具调用、验证、恢复逻辑编排为 Code as Policy
  • 代理通过感知工具生成世界代码，执行策略程序调用底层技能（包括通用机器人工具和预训练的 VLA/WAM 策略），每步动作后由独立验证器根据世界程序中的谓词检查结果
  • 成功执行的轨迹经独立验证后可转化为新的训练数据，用于更新模型参数（HexaModel），或用于修订工具、工作流与谓词
  • 整个演化遵循“生成-评估-选择”循环，所有候选修改需通过静态检查、回归测试和保留集评估后方可被采纳
Card 05 数据集与资源

数据集与资源

  • RoboCasa365：大规模长周期家居操作仿真基准
  • PhyBench：自建的模拟物理实验室，包含胡克定律测弹簧刚度、单摆测重力加速、耦合振荡器识别模态频率等科学实验任务
  • 真实机器人：双机械臂AgileX
  • 基础模型使用通用大语言模型（如 Qwen 系列），实验部分训练了专门的 HexaModel，具体参数量未明确给出

Card 06 评估与结果

评估与结果

  • 在 RoboCasa365 上，HexaAnything 在 Composite-Unseen 与总体成功率上超越 XR-1 VLA 基线；利用 Harness 生成的轨迹训练的 HexaModel 在所有任务分割上均优于原模型
  • 在 PhyBench 中，代理自主完成了三项物理实验的设计、执行与数据分析，误差在可接受范围内
  • 在真实双机械臂平台上，实现了工具的自演化（编程代理自动修正工具代码）并完成了多数桌面操作任务
  • 实验展示了 Harness、工具、数据驱动模型更新的初步自演化能力，其中工具修正使成功率从 18% 提升至 67%
