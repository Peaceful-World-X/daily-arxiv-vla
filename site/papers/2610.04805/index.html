论文概述

  • 提出 ExStereo，一种立体视觉模块，为预训练的 2D 视觉-语言-动作（VLA）模型赋予 3D 空间感知能力

Card 03 核心贡献

核心贡献

  • 提出 ExStereo 模块，可无缝集成到任何预训练 2D VLA 中，实现快速的 3D 适应，无需重新预训练基础策略
  • 证明显式的立体表示（基于多视图渲染和点云重建）比隐式立体表示（如直接使用 cost-volume 特征）在下游操作任务中更有效
  • 设计 action-stereo cross-attention 机制，使动作 token 能选择性关注立体 token，避免修改 VLM 的原有权重
  • 引入 mid-training 阶段，利用大规模立体数据和掩码自编码器（MAE）目标学习鲁棒的 3D 表示，并在 post-training 时冻结立体模块以防止过拟合
  • 在仿真（RoboTwin 10 项任务）和真实世界（bimanual PiPER 平台 3 项任务）中，VLA 搭载 ExStereo 后性能大幅超越基线
Card 04 方法描述

方法描述

  • 使用预训练的 Fast-FoundationStereo 模型从立体图像对计算视差图，并转换为度量深度图和 3D 点云
  • 将点云对齐到世界坐标系（检测桌面平面并旋转对齐），从四个正交视角（Top, Front, Left, Right）渲染为多视图观察（128×512×5）
  • 用 Vision Transformer (ViT) 编码多视图观察得到立体 token
  • 提出 action-stereo cross-attention：将 VLA 产生的动作 token 作为 query，立体 token 作为 key 和 value，通过单层多头交叉注意力注入 3D 几何信息
  • 训练分两阶段：mid-training 使用大规模立体数据和 MAE 目标同时学习动作生成和掩码重建；post-training 冻结立体模块，仅用少量任务演示进行 LoRA 微调
Card 05 数据集与资源

数据集与资源

  • 仿真数据集：RoboTwin 基准，mid-training 使用 7 个任务共 500 episode/task（带域随机化），post-training 和评估使用 10 个不同任务各 100 episode
  • 真实世界数据集：从互联网收集的 11 个贡献者、20 个数据集、共 3469 个片段 的 AgileX PiPER 数据，通过 StereoEngine 从单目生成立体对；post-training 使用自采集的 teleoperation 数据（每个任务 20–200 个演示）
  • 模型：π₀.₅ 和 SmolVLA 两个开源 VLA
  • 硬件：AgileX PiPER 双臂机器人，ZED Mini 2 立体相机，训练使用未明确说明的 GPU 资源
Card 06 评估与结果

评估与结果

  • 仿真环境：RoboTwin 10 项双手操作任务，每任务 25 个未见 episode，带域随机化，取 3 个随机种子平均值
  • 主要指标：成功率（%）
  • 关键结果：

- π₀.₅-ExStereo 平均成功率 76.4%（基线 π₀.₅ 为 51.2%，提升 25.2%）

- SmolVLA-ExStereo 平均成功率 42.0%（基线 SmolVLA 为 18.7%，提升 23.3%）

- 真实世界：π₀.₅-ExStereo 在 3 项任务总成功 50/60（83.3%），基线仅 16/60（26.7%）；StereoVLA（隐式立体）仅 11/60（18.3%）

- 消融实验显示 action-stereo cross-attention 优于 VLM 缩合隐式立体特征，mid-training with MAE 进一步提升性能
