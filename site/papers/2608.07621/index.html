Card 02 论文概述

论文概述

  • 针对现有Vision-Language-Action（VLA）模型仅支持单智能体自动驾驶、缺乏协同感知/推理/规划能力的问题，提出Cooperative Multi-agent Unified Driving with Reasoning (CMU-Drive)闭-loop端到端协同多智能体驾驶基准与Vehicle-to-Vehicle Vision-Language-Action (V2V-VLA)协同驾驶模型
  • CMU-Drive解决了现有协同驾驶基准连通自动驾驶车辆（CAV）数量少、场景复杂度不足、评估资源要求高的问题，支持多车在安全关键场景中与背景交通参与者交互
  • 旨在建立多智能体闭loop端到端协同自动驾驶的研究基础，推动 reasoning-guided 的协同驾驶技术发展，相关代码、基准和模型 checkpoint 将公开释放
Card 03 核心贡献

核心贡献

  • 构建CMU-Drive协同驾驶基准：继承Bench2Drive的44类安全关键城市场景，扩展为每路线2-16辆CAV的协同设置，仅需1张GPU即可完成闭loop评估，大幅提升了场景复杂度和评估规模
  • 定义多智能体协同驾驶评估指标：将单智能体的路线完成率、违章分数等指标扩展为协同场景，包含路线级、整体的驾驶得分（DS）和成功率（SR），适配多车联合评估需求
  • 提出V2V-VLA协同VLA模型：单次前向推理即可联合生成驾驶动作、未来路径点、语言推理和通信策略，无需多轮LLM协商，可自主学习是否需要发起车车通信以及选择通信目标车辆
  • 实验验证V2V-VLA的有效性：在CMU-Drive基准上，V2V-VLA的驾驶得分和成功率均显著优于单智能体基线方法
Card 04 方法描述

方法描述

  • CMU-Drive基准构建：基于Bench2Drive扩展，将其单智能体模拟评估协议改造为多智能体协同设置，保留原有背景车辆、行人、骑行者等交通参与者；额外CAV的起止点根据道路拓扑自动生成，避免干扰原Bench2Drive的安全关键事件触发逻辑，保证场景交互的合理性
  • V2V-VLA模型架构：

- 输入包含三部分：语言输入（驾驶任务提示+其他协同车辆相对位置）、动作输入（ego车目标路径点，经MLP编码）、视觉输入（ego车前摄像头图像+合并的鸟瞰图 Occupancy Map）

- 视觉输入中的合并 Occupancy Map 由ego车和通信车的独立 Occupancy Map 经坐标变换对齐后，通过元素或操作合并生成， Occupancy Map 由UniAD生成，视觉编码器采用InternViT

- 核心模型采用Qwen2作为LLM，联合处理三类输入，输出语言推理、驾驶动作、通信策略和未来等距/等时路径点，路径点经PID控制器转换为油门、刹车、转向控制信号

  • 创新点：首次实现单次前向推理完成协同驾驶的全流程决策（感知、推理、规划、通信），无需多轮交互协商；通过监督信号让模型自主学习通信目标选择逻辑，仅在需要互补观测时发起通信
Card 05 数据集与资源

数据集与资源

  • 数据集：CMU-Drive基准包含220条评估路线，覆盖44类安全关键驾驶场景，每种场景配置5种不同天气/光照条件，每路线包含2-16辆CAV与背景交通参与者
  • 模型规模：V2V-VLA基于Simlingo和UniAD初始化权重，LLM采用Qwen2，仅对LLM的LoRA部分进行微调，UniAD部分参数冻结
  • 训练资源：训练过程使用8块NVIDIA H100-80GB GPU，总训练时长48小时；闭loop评估仅需1块GPU即可完成最多16辆CAV的协同评估
  • 训练数据：共采集180K条监督微调样本，由PDM-lite专家模型生成未来路径点标注，规则方法生成动作和推理标注，额外添加通信伙伴监督信号
Card 06 评估与结果

评估与结果

  • 评估环境与基准：在CMU-Drive的220条闭loop评估路线上测试，对比基线为单智能体VLA模型Simlingo
  • 主要评估指标：驾驶得分（DS，路线完成率与违章分数的乘积）、成功率（SR，驾驶得分100%时记为1否则为0）、路线完成率（RC）、违章分数（IS）
  • 关键实验结果：

- 定量结果：V2V-VLA的驾驶得分达63.67，较Simlingo的56.32提升7.35；成功率达34.55%，较Simlingo的30.91%提升3.64%，在多车协同场景下性能显著优于单智能体基线

- 定性结果：展示了ego车在雨天视野受阻、无法清晰识别前方自行车的场景下，通过V2V通信获取前方CAV的共享感知信息，成功识别风险并减速避免碰撞，验证了V2V通信机制的有效性

- 场景分析：部分安全关键场景（如无信号路口左转进入车流）的平均驾驶得分仍较低，是未来研究的重点方向
