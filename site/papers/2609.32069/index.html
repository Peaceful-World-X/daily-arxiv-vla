Card 02 论文概述

论文概述

  • 现有Vision-Language-Action（VLA）模型多为冻结部署，无法从自身失败中学习，而真实世界强化学习（RL）又面临手动重置环境、人工标注任务成功标签的核心瓶颈，限制了机器人的持续自主改进。
  • 本文提出FIND智能体驱动真实世界RL框架，将自主练习重定义为场景条件、性能感知的任务选择问题：无需手动重置工作空间，而是将上一轮rollout产生的场景状态作为下一轮练习的起点，由智能体自主判断当前场景下可执行的任务。
  • 框架实现场景理解、弱点感知练习、自我评估与策略改进的完全闭环，目标是让VLA模型能够在真实持久工作空间中自主提升性能，大幅降低人工干预需求。
Card 03 核心贡献

核心贡献

  • 提出FIND框架，在持久工作空间中实现自主练习的全闭环，无需反复手动重置场景，解决了真实世界RL长期依赖人工重置的痛点。
  • 将自主练习形式化为场景条件、性能感知的任务选择问题：通过VLM识别当前场景可行任务，结合基于近期成功率的性能感知课程优先分配练习资源，同时采用配对图像自我评估同时为策略学习和任务分配提供监督信号，无需人工标注奖励。
  • 在8个真实世界操作任务上的实验验证了框架有效性：独立人类评估的任务成功率从55%提升至71.9%，代表性6小时自主运行仅需30次场景恢复干预，无任何人工提供的奖励标签。
Card 04 方法描述

方法描述

  • FIND由三个核心智能体组件构成：①场景条件任务选择：VLM分析当前工作空间观察，从预定义任务库中筛选出当前场景下可行的任务，无需恢复预设初始场景；②性能感知课程：为每个任务维护长度为K=20的近期成功率滚动历史，优先采样近期成功率更低的任务，引导练习集中在策略当前薄弱环节；③配对图像自我评估：执行前后分别采集工作空间图像，VLM结合任务指令判断执行是否成功，同时为策略学习提供稀疏奖励、为课程分配更新性能统计。
  • 策略改进模块采用残差off-policy强化学习：冻结预训练的π₀.₅ VLA作为基础策略，训练轻量残差策略输出有界修正动作，采用10头集成REDQ critic提升价值估计鲁棒性；引入critic门控机制，仅当残差动作的估计优势超过阈值δ时才执行修正动作，否则回退到基础VLA的动作，避免不可靠的残差修正破坏原有策略。
  • 训练流程采用异步并行设计：rollout收集与RL优化在不同线程独立执行，通过有序FIFO队列传递经验，最新参数队列保证收集器使用最新策略，同时将策略滞后限制在2000个环境步以内，提升真实世界训练效率。
Card 05 数据集与资源

数据集与资源

  • 使用的数据集为8个可逆操作任务的离线演示数据集，每个任务包含50集演示轨迹，总过渡数覆盖6k~16k不等，存储在LeRobot格式，既用于微调基础VLA，也用于初始化离线经验回放池。
  • 基础模型为冻结的π₀.₅ VLA，残差策略为轻量小型网络，critic采用10头集成的REDQ结构；智能体监督组件采用GPT-5.6 Terra多模态大模型。
  • 硬件资源为搭载NVIDIA RTX 4090 GPU、Intel Core i9-14900K CPU、64GB RAM的工作站；感知系统采用两个ZED X Mini相机（一个第三人称视角、一个腕部挂载视角），输入图像resize至224×224分辨率。
Card 06 评估与结果

评估与结果

  • 评估环境为真实桌面场景，采用7自由度Franka Emika Panda机械臂搭载平行夹爪，工作空间包含2个方块、1个碗、1个抽屉、1个杯子和1个杯子架，共8个语言条件操作任务，分为4对可逆任务对，保证上一轮任务的场景可自然转化为下一轮任务的初始条件。
  • 主要评估指标包括独立人类评估的多任务平均成功率、在线VLM评估的滚动成功率、人工干预率、连续自主运行时长。
  • 关键实验结果：①独立人类评估的成功率从微调后基础VLA的55%提升至最终的71.9%，在线VLM评估的滚动成功率最终达到(70.4±4.6)%，且随训练持续上升；②代表性6小时自主运行共完成456集，其中426集无人工干预，仅需30次手动场景恢复，人工干预率为6.58%，最长连续自主运行时长达48分钟；③消融实验表明，移除性能感知课程或critic门控均会导致性能明显下降，证明二者对稳定自主改进的必要性；④VLM组件评估中GPT-5.6 Terra的任务选择准确率达96%，配对图像成功评估准确率达100%，同时具有最低的响应延迟。
