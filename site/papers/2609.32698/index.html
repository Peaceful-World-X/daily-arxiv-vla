Card 02 论文概述

论文概述

  • 论文提出了一种名为 SEES (Self-Evolving Embodied System) 的框架，旨在让机器人从长时域任务执行的失败经验中自主学习，无需额外的专家演示即可改进其 VLA 策略
  • 核心解决的问题是：现有的 VLA 模型在长时域任务上表现不可靠，因为一个微弱的原子技能就可能导致多个多阶段任务失败，而传统的改进方法依赖昂贵的人工诊断和数据收集
  • SEES 通过自动识别经常导致失败的原子技能瓶颈，并为这些瓶颈在模拟环境中构建针对性的强化学习任务，通过在线 RL 更新共享的技能家族适配器，实现策略的自我进化
Card 03 核心贡献

核心贡献

  • 提出一个与不同 VLA 主干兼容的自我进化具身系统 SEES，它能够自动识别原子技能瓶颈，并构建针对性的模拟 RL 任务以改进策略，无需额外专家演示
  • 开发了一种基于失败的家族级进化机制，该机制依据长时域任务的执行失败来选择并联合训练相关的瓶颈技能，使共享的家族适配器得到更新，从而惠及整个技能家族
  • 在 RoboCasa365 和 LIBERO 等多个基准上，使用多种 VLA 主干进行了广泛实验，证明了策略性能的逐步提升及其向未见过任务的泛化能力，并通过消融实验验证了失败归因、瓶颈选择和家族级适应等设计的有效性
Card 04 方法描述

方法描述

  • 任务分解与执行：使用冻结的 VLM 规划器将长时域指令分解为原子任务序列，并由共享同一家族适配器的 VLA 策略执行。通过一个训练好的终止头来判断原子任务是否完成，并监控执行结果
  • 瓶颈识别：在多轮执行中，收集每个原子任务的成功与失败统计。任务失败归因于第一个阻止流程继续的原子阶段，并选择失败频率最高的原子任务作为当前轮的进化瓶颈
  • 瓶颈目标 RL 任务构造：对于每个选定的瓶颈任务，系统恢复先前执行中遇到的状态作为初始状态，并利用 LLM 根据任务指令和模拟器 API 生成成功检查函数，以此定义稀疏奖励，从而在模拟器中构建出针对性的 RL 任务
  • 家族级策略进化：同一技能家族的瓶颈任务联合训练一个共享的 LoRA 适配器。使用 PPO 算法进行在线 RL 更新，并根据在瓶颈任务上的验证增益选择最佳检查点用于后续执行，实现能力的跨任务迁移与累积提升
Card 05 数据集与资源

数据集与资源

  • 使用的主要基准包括 RoboCasa365（65 个原子任务和 300 个复合任务）和 LIBERO（四大套件：Object, Spatial, Goal, Long，每套件 10 个任务）
  • 评估的 VLA 模型主干包括 GR00T N1.5（基于扩散变换器）和 RLDX-1（基于多流动作变换器）
  • 训练资源：每个进化轮次为每个活跃家族分配 40 步 PPO 训练步骤，更新的是低秩适配器（LoRA），而非完整的 VLA 模型
Card 06 评估与结果

评估与结果

  • 评估环境：在 RoboCasa365 和 LIBERO 模拟器上进行，评估指标为任务成功率
  • RoboCasa365 结果：经过三轮进化，与基策略相比，GR00T N1.5 的原子任务成功率从 47.2% 提升至 55.7%，复合已见任务成功率从 10.2% 提升至 13.1%；RLDX-1 的原子任务成功率从 66.4% 提升至 70.3%，复合已见任务成功率从 20.4% 提升至 21.8%
  • 泛化能力：在两个 VLA 主干的 复合未见任务 上，成功率均有提升（GR00T N1.5: 3.5% -> 6.1%; RLDX-1: 6.0% -> 7.1%），证明了进化策略的泛化性
  • LIBERO 结果：三轮进化后，所有四个套件的平均成功率从 53.10% 提升至 65.40%。受益的不仅是选为瓶颈的任务，未被选中进行 RL 训练的兄弟任务的成功率也普遍提高，证明了家族级共享适配器的正迁移效应
  • 消融研究：与随机选择和选择最可靠阶段相比，基于失败频率的瓶颈选择策略在固定训练预算下，对完整复合任务成功率的提升最为显著（64% vs. 28% vs. 34%）
