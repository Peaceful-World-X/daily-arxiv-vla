Card 02 论文概述

论文概述

  • 现有视觉-语言-动作（VLA）模型在多阶段操作中难以区分视觉相似但执行历史不同的状态，简单添加历史帧无法可靠捕获近期的物理变化，导致长程任务中错误累积
  • 本文提出 TemporalFlow-VLA，通过物理 grounded 的时间监督学习紧凑的执行历史表示，使用机器人-表面时序流（robot-surface temporal flow）作为仅训练时的监督目标
  • 该方法基于记录的机器人状态、URDF 几何模型和相机标定参数构建时序流，监督两个执行对齐的时间查询（Q₈ 和 Q₁₅），为动作专家提供结构化历史信息，且在部署时不评估几何监督路径
Card 03 核心贡献

核心贡献

  • 提出运动学 grounded 的机器人-表面时序流，将机器人运动投影到策略 RGB 平面，提供可解释的监督信号，无需物体标注或部署时传感器
  • 设计两个分块对齐的时间查询（Q₈ 和 Q₁₅），其物理内容由区间特定的流重建定义，通过联合掩码注意力机制形成紧凑的监督接口，历史图像块无法直接到达动作专家
  • 引入异步历史特征缓存，将历史视觉编码与动作执行重叠，显著降低时间条件推理的开销
  • 在仿真和真实机器人上进行了广泛验证，证明方法的有效性和实用性
Card 04 方法描述

方法描述

  • 在预训练的 π₀.₅ VLA 策略上并行添加一个轻量级时间模块，保留原始动作生成路径，额外接收 t-15、t-8 和当前时刻 t 的头部相机观测
  • 时序流构建：利用机器人关节配置、正向运动学变换（T_B^l）和基座到相机变换（T_{C←B}），将机器人表面点从源时刻投影到目标时刻，通过最近邻像素查找（3D 残差 ≤5mm）建立对应关系，将位移归一化到 224×224 图像平面，再通过 14×14 非重叠区域的掩码算术平均聚合为 16×16×2 的流目标
  • 分层时间查询与联合注意力：Q₈ 和 Q₁₅ 作为可学习 token 添加到 π₀.₅ 前缀，通过定向掩码建立 Q₈→Q₁₅ 的层次结构；Q₈ 仅能访问语言 token、t-8 观测、当前观测和自身，Q₁₅ 可额外访问 t-15 观测和 Q₈；动作 token 仅通过这两个查询获取历史视觉信息，使用 FiLM 调制（γ_ρ, β_ρ）和区间特定的点wise MLP 解码器预测流
  • 异步缓存机制：将历史观测写入带时间戳的环形缓冲区，后台进程异步提取并存储视觉特征；重规划时直接从缓存获取 t-15 和 t-8 的特征，仅当前帧同步编码，将推理延迟从 3T_vision + T_joint + T_action 降低到约 T_vision + T_joint + T_action
Card 05 数据集与资源

数据集与资源

  • LIBERO 基准（Spatial、Object、Goal、Long 四个套件）
  • RoboTwin 2.0 数据集（12 个任务，每任务 50 条干净示范和 500 条随机化示范）
  • 模型基于 π₀.₅，时间查询维度为 2048，VLM 空间 patch 状态维度为 16×16×2048
  • 训练资源：8 块 NVIDIA H100 GPU，每 GPU batch size 为 32；LIBERO 训练 30k 步，RoboTwin 2.0 训练 60k 步；添加时间模块和辅助流解码器使训练时间增加约 20%
Card 06 评估与结果

评估与结果

  • 评估环境：LIBERO 仿真基准（500 次 rollout/套件/种子）和 RoboTwin 2.0 仿真（100 次 rollout/任务），以及真实机器人实验
  • 评估指标：任务成功率（%）
  • 关键结果：

- LIBERO 平均成功率为 97.63±0.26%，其中 Long 套件达到 96.60±0.87%

- RoboTwin 2.0 整体平均成功率为 85.5%（Clean）和 84.2%（Randomized），在长程多阶段任务（H3 组）上优势最明显，如 Stack Blocks Three 达到 97%/95%（Clean/Rand.），Blocks Ranking RGB 达到 97%/98%

- 消融实验表明动作预测依赖于历史内容及其时间顺序，移除历史会使流匹配损失增加约 4.6%，而打乱历史顺序损失几乎不变

- 真实机器人验证证实了方法的实际可行性，异步缓存保持单帧级别的采样延迟，无额外历史编码开销
