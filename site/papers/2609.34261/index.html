Card 03 核心贡献

核心贡献

  • 构建机器人原生的上下文学习框架，演示上下文和交互记忆采用共享的观察-动作-收据-观察语法，无需机器人特定微调
  • 设计最小化、可审计的控制接口：仅暴露一个连续动作块函数工具，不使用外部技能库或通用代码代理运行时
  • 显著缩小 GPT-6 Astra 在 RoboDojo 高精度和长序列类别中的性能差距，在记忆和开放类别领先，30 任务总分大幅超越最强基线
  • 在真实机器人单臂操作中验证了框架有效性，少样本演示即可带来显著提升
  • 提出基于有界锚定记忆与缓存前缀复用的效率优化方法，并探索了 Jev 门控动作复用降低推理调用次数
Card 04 方法描述

方法描述

  • 共享交互语法：每个交互记录包含起始观察、动作块、执行收据（演示采用合成收据）和结果观察，演示与交互记忆用相同格式呈现
  • 有界锚定记忆：从演示中均匀采样非重叠动作块保留多阶段信息；交互记忆保留首个、固定间隔及最新完成交互，插入 避免观测误读
  • 效率感知设计：任务指令、演示和固定标定组成稳定前缀以支持 KV 缓存复用；根据任务步骤限制自适应设置动作预测和学习执行horizon
  • 控制实现：动作块为世界坐标系下的增量平移、旋转向量和归一化抓手目标，经确定性验证和逆运动学求解后执行，RoboDojo 中动作维度 14（双臂）
Card 05 数据集与资源

数据集与资源

  • RoboDojo 模拟基准：30 个任务（记忆、精度、长序列、开放四个类别），含公开布局和原生评分
  • 真实机器人实验：单臂机器人平台，自定义抓取和放置任务，使用头、腕相机的 RGB 观测
  • 模型：固定参数的 GPT-6 Astra 视觉语言模型，未提供参数量，通过 API 调用
  • 训练资源：无微调阶段，仅需推理 API 访问
Card 06 评估与结果

评估与结果

  • 模拟评估：RoboDojo 官方评分标准，进度分数 0-100；开放类用零样本，其余用单样本；比较了官方零样本基线、VLA/WAM 方法及 GPT-as-Policy
  • 主要结果：

- 在记忆和开放类别领先，精度类别与最强基线 Liber-0 Preview 相当，长序列类别排第三

- 30 任务总分 50.64，比最强基线 33.68 高出 16.96 分

- 十任务子集上 RoboICL（单样本） 得分 60.60，接近 π0.5 + GPT-6 Astra 混合方案（62.60）

  • 真实机器人：零样本平均进度 14.45，单样本 63.33，三样本 78.89
  • 效率分析：KV 缓存命中率随锚点固定提高；Jev 门控动作重用在两个开发任务上降低 33-48% 的模型调用次数
