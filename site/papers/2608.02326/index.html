Card 02 论文概述

论文概述

  • 针对长期机器人操作任务，提出 ChainVLA，一种通过统一执行状态链接连续视觉-语言-动作（VLA）查询的 1.2B 参数策略。
  • 核心要解决的问题是：现有 VLA 策略在每次查询时重新规划，导致跨查询的任务进度和未完成动作信息丢失，造成决策模糊和动作不连续。
  • 通过将任务进度（Progress Context）和动作延续（Motion Tail）组合成一个可修订的执行状态，实现跨查询的连贯推理与动作生成。
Card 03 核心贡献

核心贡献

  • 识别出任务进度和未完成动作是跨查询执行状态的两个互补组成部分，并通过消融实验揭示了二者的不对称性，表明动作连续性有助于维持任务进度所需的观测信息流。
  • 提出 ChainVLA，一种 1.2B 参数的策略，通过联合且可修订的执行状态（Progress Context 和 Motion Tail）链接查询，并在每次查询时基于最新观测重新生成动作序列。
  • 在 RMBench（记忆依赖操作基准）和四个 LIBERO 套件上验证了 ChainVLA 的有效性，并展示了移除状态组件或使用现有替代方案（如观测历史、时序集成、后解码平滑）均会导致性能大幅下降。
Card 04 方法描述

方法描述

  • 设计了一个统一的执行状态，包含 Progress Context（结合递归工作状态和稀疏事件记忆，携带观测衍生的任务进度）和 Motion Tail（携带前一次预测中未执行的动作后缀）。
  • 在每次查询时，读取、更新并传递该执行状态，使其作为条件输入到条件流解码器，解码器在最新观测下重新生成整个动作序列，从而实现状态的可修订性。
  • 训练时，采用与推理一致的查询顺序展开，并利用动作重叠一致性正则化项来促进 Motion Tail 的平滑交接，同时监督任务阶段估计（若标注可用）。
Card 05 数据集与资源

数据集与资源

  • 主要基准：RMBench（5 个记忆依赖操作任务）和 LIBERO（Spatial、Object、Goal、Long 四个套件）。
  • 模型规模：1.2B 参数，所有内部训练模型共享 Florence-2-large 视觉编码器和条件流解码器。
  • 训练资源：每个任务使用 50 个演示，优化 20,000 步，批次大小为 4，其他硬件细节未在摘要中提及。
Card 06 评估与结果

评估与结果

  • 评估环境：在 RMBench 上每个任务评估 100 次，LIBERO 上每个任务评估 50 次，主要指标为任务成功率。
  • 主要结果：ChainVLA 在 RMBench 上达到 62.8% 平均成功率（优于所有完整覆盖的方法），在 LIBERO 四个套件上平均达到 98.8%。
  • 关键消融：移除 Motion Tail 或 Progress Context 分别导致 RMBench 成功率降至 11.2% 和 3.0%，而同时移除两者降至 1.6%；使用观测历史加时序集成的替代方案仅达 35.6%，表明状态链接的必要性。
  • 边界分析：在配对场景中，完整的 ChainVLA 相比无 Motion Tail 的变体，在位置命令不连续性、朝向不连续性、边界二阶差分和计划重叠误差等指标上均有显著降低，验证了动作延续对维持连贯执行的作用。
