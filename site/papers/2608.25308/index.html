Card 02 论文概述

论文概述

  • 核心解决双系统视觉语言动作（VLA）模型中VL-to-A（视觉语言到动作）特征转移的视觉表示可及性瓶颈：仅转移VLM最终层特征会导致动作专家难以获取精细操作所需的3D几何与2D语义信息，制约性能。
  • 研究目标是提出V-Link表示恢复框架，在VLM内学习互补的空间与语义查询，并非对称注入动作专家（Action DiT），恢复丢失的视觉表示，提升操作性能且无推理时额外开销。
  • 通过仿真基准与真实人形机器人任务验证框架有效性，实现性能显著提升且推理延迟几乎无增加。
Card 03 核心贡献

核心贡献

  • 首次揭示双系统VLA中VL-to-A特征转移的视觉表示可及性瓶颈：仅转移VLM最终层特征会导致动作专家可及的3D几何、2D语义信息不足，是精细操作性能受限的核心原因。
  • 提出V-Link表示恢复框架：在VLM内引入可学习的空间查询（负责3D几何）与语义查询（负责2D语义），通过因果注意力掩码独立提取两类感知线索，训练时用轻量深度、分割头监督查询专业化，推理时完全移除辅助模块。
  • 设计非对称查询注入机制：语义查询通过并行交叉注意力补充原始VLM图像token，空间查询提供专属几何条件，避免动作专家依赖语义捷径，使两类感知信息在动作生成时可直接访问。
  • 在三个仿真基准（LIBERO、LIBERO-Plus、RoboTwin 2.0）与两个真实人形任务上实现一致性能提升，相较基座GR00T N1.6平均成功率分别提升+1.9%、+31.2%、+18.8%，真实任务提升+20%、+24%，仅增加1.58ms推理延迟。
Card 04 方法描述

方法描述

  • 基座模型为GR00T N1.6，方法包含两个核心模块：① VLM表示解耦：在VLM输入注入可学习的空间查询与语义查询，通过因果注意力掩码隔离两组查询，使其独立 attend 到VLM的图像、文本token，逐步聚合几何、语义感知线索；训练时添加轻量深度估计头（监督空间查询提取深度信息）与语义分割头（监督语义查询提取语义信息），推理时移除辅助头。② Action DiT视觉表示恢复：在Action DiT的图像交叉注意力层，以机器人状态、 noisy action token 为query，分别与VLM图像token、语义查询做并行交叉注意力，输出融合后残差加到输入，再与空间查询做交叉注意力提供专属几何条件，最后过FFN输出。
  • 创新点与关键技术：① 针对VL-to-A转移瓶颈设计的查询注入机制，专门恢复3D几何与2D语义两类关键视觉表示；② 非对称注入设计，区分语义补充与几何 conditioning 的功能，避免动作专家利用语义捷径；③ 训练时先对VLM LoRA、两组查询及任务头做warm up，再联合优化所有可训练组件，稳定随机初始化的查询的训练，推理时无任何额外开销，效率友好。
Card 05 数据集与资源

数据集与资源

  • 使用的数据集：仿真基准包括LIBERO、LIBERO-Plus、RoboTwin 2.0，真实机器人任务使用AGIBOT A3 Ultra人形机器人的自主开机、关机两个任务。
  • 模型规模：基座为GR00T N1.6 3B，深度估计头参数量约2.3M；查询token规模：LIBERO上空间、语义查询各为2×5×5，RoboTwin 2.0上各为3×5×5。
  • 训练资源：4张NVIDIA H100 GPU，BF16精度，使用DeepSpeed ZeRO-2优化，通过rank=128的LoRA适配VLM参数，训练时冻结VLM的视觉、语言 backbone。
Card 06 评估与结果

评估与结果

  • 评估环境：仿真在LIBERO、LIBERO-Plus、RoboTwin 2.0三个基准上测试，真实任务在AGIBOT A3 Ultra人形机器人上进行50次连续试验。
  • 主要评估指标：操作成功率（仿真每个任务50/100次试验，真实每个任务50次），诊断任务用深度MAE、语义分割mIoU衡量视觉表示可及性。
  • 关键实验结果：① LIBERO基准上平均成功率99.3%，相较基座GR00T N1.6提升+1.9%， surpass 所有2D/3D SOTA VLA方法；② LIBERO-Plus分布偏移测试上平均成功率75.0%，相较基座提升+31.2%，在噪声、语言、光照偏移下增益尤为显著；③ RoboTwin 2.0上平均成功率56.8%，相较基座提升+18.8%，所有任务均一致提升；④ 真实任务训练时用Lingbot-Depth补全传感器丢包、反射表面导致的RGB-D缺失深度，用GroundingDINO和SAM3生成关键对象分割伪GT，推理时无需辅助标注，V-Link实现开机/关机成功率98%/94%，相较基座的78%/70%提升+20%/+24%；⑤ 诊断实验显示V-Link的Action DiT深度MAE从基座的0.071显著降低，分割mIoU从0.290显著提升，验证视觉表示恢复的有效性，仅增加1.58ms推理延迟。
