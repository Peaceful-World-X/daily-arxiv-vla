Card 03 核心贡献

核心贡献

  • 提出 SimForcing 框架，通过潜在运动蒸馏将仿真中的运动先验迁移到真实域的视频生成中，从时序差分角度监督而避免外观差异干扰
  • 设计多模块仿真条件注入与条件丢弃机制，结合潜在损坏策略，让模型能利用仿真预测同时避免过度依赖其准确性
  • 提出仿真条件分类器自由引导 (Simulation-conditioning CFG) 方案，在推理时灵活平衡模型自身运动知识与显式仿真引导
  • 联合训练后单个学生模型可同时生成仿真引导和真实域视频，无需额外世界模型，在 Bridge 和 InternData-A1 数据集上取得最优重建与感知指标
Card 04 方法描述

方法描述

  • 仿真世界模型训练: 基于混合Transformer架构，在合成rollout上使用流匹配学习动作条件运动，并对轨迹进行扰动增强以提升多样性
  • 潜在运动蒸馏: 冻结仿真教师模型，让学生模型在时序变化的潜在差异上对齐教师，而非直接匹配潜在值，以此内部化运动先验
  • 多模块丢弃条件注入: 将仿真潜在变量以零初始化、多模块注入的方式加入学生各层，配合条件丢弃和潜在损坏训练，增强对不完美仿真的鲁棒性
  • 仿真条件CFG: 推理时利用模型自身生成仿真条件，通过插值有条件与无条件分支的预测，平衡利用显式引导和内部化运动知识
  • 联合训练: 学生模型同时训练真实域流匹配、仿真域流匹配以及跨域和同域的运动蒸馏损失
Card 05 数据集与资源

数据集与资源

  • 主要数据集: Bridge (评估与消融), InternData-A1 (泛化性验证), LIBERO (下游策略学习)
  • 模型规模: 采用混合专家架构，视频 DiT 基于 Wan2.2-TI2V-5B，并额外添加 1B 参数的动作 DiT
  • 训练资源: 未明确声明具体硬件配置，论文表示使用 8 块 NVIDIA A100 GPU 训练
  • 推理资源: 在 Bridge 上单样本推理时间约 4.1 秒，包含 SAM3 分割耗时仅 0.3 秒
Card 06 评估与结果

评估与结果

  • 评估基准: 与 IRASim、Cosmos-Predict2.5、Ctrl-World、EnerVerse-AC、GeniWorld 以及微调的 Wan2.2 等最新方法对比
  • 主要指标: PSNR、SSIM (重构保真度)，LPIPS (感知相似度)，FID、FVD (分布层面质量)
  • 关键结果 (Bridge): SimForcing 在无大规模具身预训练的模型中取得最优 PSNR (25.077)、SSIM (0.858)、LPIPS (0.0673) 和 FVD (137.49)
  • 泛化性: 在 InternData-A1 数据集上同样展现出优异的视频预测性能
  • 策略学习: 用预训练好的世界模型初始化视觉-语言-动作模型，在 LIBERO 上将平均成功率从 82.6% 提升至 89.2%
