Card 02 论文概述

论文概述

  • 提出了 ActiveArena 套件，这是首个专为机器人操作中主动感知（active perception）设计的综合性模拟器-基准-基线套件，包含 ActiveArena-Sim、ActiveArena-Bench 和 ActiveArena-VLA 三个核心组件
  • 针对现有基准测试在主动信息获取（active information acquisition）和主动信息维护（active information maintenance）两个关键维度上的缺失，构建了需要多轮证据采集和基于记忆推理才能完成的任务基准
  • 建立了严格的 ID（分布内）/OOD（分布外）评估协议，通过分离场景、未见过的干扰物配置和新背景来测试模型对主动感知策略的泛化能力而非依赖环境伪影
Card 03 核心贡献

核心贡献

  • 开发 ActiveArena-Sim，首个支持主动视角控制（头部和躯干关节）、180°大工作空间和交互式信息获取的机器人操作模拟器，可见场景覆盖比传统固定视角模拟器高 6.3 倍
  • 构建 ActiveArena-Bench，包含 35 个任务、2 个任务家族（Visual Search 和 Interactive Information Acquisition）和 5 个细粒度类别，提供多粒度记忆标注、标准化训练数据和 ID/OOD 评估协议
  • 提出 ActiveArena-VLA，包含 13 种模块化 VLA 配置的系统性套件，用于控制研究记忆写入策略、记忆容量、本体感觉、子任务监督和高级规划对主动感知的影响
Card 04 方法描述

方法描述

  • 模拟器设计：基于 RoboTwin 2.0 重新设计工作空间为 180° 扇形区域，集成 Astribot S1 双臂人形机器人本体，启用头部和躯干自由度控制，实现 18 维动作空间（双臂、双夹爪、躯干、头部）
  • 任务设计原则：每个任务满足四个要求——初始信息不足、信息可获取、历史依赖性和闭环决策制定，确保必须通过主动感知（视角调整或物体交互）获取隐藏信息
  • 模型架构：基于 StarVLA 框架的模块化设计，包含 VLM 分支（处理时空视觉记忆、语言和可选本体感觉序列）和三种动作头（OFT、FAST、GR00T），支持 18 维动作预测
  • 记忆机制：支持三种写入策略（subtask、motion、chunk）和两种容量（6/12 帧），并探索规划器引导的记忆管理（ActiveArena-Plan）
Card 05 数据集与资源

数据集与资源

  • ActiveArena-Bench：35 个模拟任务，训练集包含每个任务 100 条 ID 轨迹，总计 581.2k 帧（约 10.76 小时视频），模型训练 3.9 个 epoch
  • 真实世界数据集：8 个真实机器人操作任务，共收集 640 条轨迹用于训练和评估
  • 模型规模：13 种 VLA 配置变体，包括 ActiveArena-Fixed（固定视角）、ActiveArena-OFT（无规划器）、ActiveArena-Plan（带规划器）等
  • 基线模型：6 个外部基线，包括 π₀.₅、SaPaVe（VLA 模型）、HiF-VLA、MemoryVLA、MemER（记忆增强模型）和 Fast-WAM（世界动作模型）
Card 06 评估与结果

评估与结果

  • 评估环境：模拟环境使用 ID 场景（受限干扰物池）和 OOD 场景（完整干扰物池、新背景、更密集杂乱），真实环境使用 Astribot S1 机器人平台
  • 主要指标：任务成功率（%），分为 ID 和 OOD 两种设置，额外进行失败状态分解（Discovery Miss、Context Omission、Context Retained）
  • 关键实验结果：

- 无记忆模型（如 FAST-WAM、π₀.₅）在 OOD 上表现极差（平均成功率分别仅 2.06% 和 1.71%），而带记忆模型显著改善泛化

- ActiveArena-OFT 取得最佳平均性能（ID 62.97%，OOD 47.60%），ActiveArena-Plan 以稀疏记忆接近最优性能（ID 60.97%，OOD 45.54%）

- 均匀时间采样（chunk）在 OOD 上优于事件触发写入（subtask/motion），且记忆容量并非越大越好，取决于写入策略的稳定性

- 本体感觉输入和辅助子任务监督提供额外性能增益

- 真实世界实验验证了模拟结果的迁移性，ActiveArena-OFT 在真实任务上平均成功率达 55.6%，显著优于其他基线
