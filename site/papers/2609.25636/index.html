RoboFollow: Unveiling the Instruction Following Mirage in Embodied Agents

Card 02 论文概述

论文概述

  • 指出现代具身智能体在基准测试中取得高成功率，但其实际指令遵循能力被严重高估，因为许多标准测试中视觉场景本身已暗示了唯一可行的任务，语言指令成为冗余。
  • 引入 RoboFollow 诊断基准，旨在揭示并评估具身智能体是否真正利用语言来选择和执行预期行为，而非依赖视觉捷径。
  • 核心问题是解决在视觉场景存在多义性时，当前视觉-语言-动作模型（VLA）和世界动作模型（WAM）在指令理解和泛化上的关键瓶颈。
Card 03 核心贡献

核心贡献

  • 提出了一个 语言必需的诊断基准 RoboFollow，通过构建高场景熵（同一视觉配置对应多个任务分支）迫使模型依赖语言，并简化对象与动作以控制执行层面的混淆因素。
  • 设计了一套 四级分层诊断协议（L0-L3），通过逐步扰动视觉布局和语义组合，系统性地测试模型在分布内、视觉接地、语义组合以及混合扰动下的指令遵循能力。
  • 引入了 分阶段的意图分和执行力分（Intent and Execution Scores），将语义理解错误与运动执行失败分离，实现更精准的故障诊断。
  • 对 9 种代表性 VLA 和 WAM 模型进行了 系统性评估与分析，证明即使在微调后，模型在需要语言指令进行泛化的层级（L1-L3）性能急剧下降，且当前主流优化策略（如更强VLM骨干、QA联合训练等）均无法有效弥补这一差距。
Card 04 方法描述

方法描述

  • 高场景熵设计：通过设计初始视觉观察相同但语言指令指向不同有效行为的场景，量化“场景熵”，确保语言成为区分任务的必要条件。
  • 四级评估协议：L0（分布内测试）、L1（视觉接地：交换物体位置）、L2（语义组合：重组训练见到的语义属性）、L3（视觉-语义混合扰动），以隔离不同的泛化维度。
  • 分阶段评分体系：每个任务被分解为多个顺序子阶段，分别计算“意图分”（衡量是否选对了语义目标，如物体、关系、约束）和“执行力分”（衡量选对目标后是否物理完成），以此分离理解错误和执行失败。
  • 四类诊断场景：构建了覆盖外在空间关系、内在对象属性与动作选择、精细轨迹与定向约束、基础逻辑接地的场景，全面评估不同类型的指令遵循能力。
Card 05 数据集与资源

数据集与资源

  • 使用名为 RoboFollow 的自建模拟基准数据集。
  • 数据集包含 4个诊断场景家族，75个训练任务标签，这些任务被分组到 6个任务无关的初始场景配置 中。
  • 数据集具有高场景熵（3.782 bits），而对比基准 LIBERO 为 0.880 bits。
  • 代码和数据集在 GitHub 和 Hugging Face 上公开可用。
Card 06 评估与结果

评估与结果

  • 评估环境：在模拟环境中进行，并包含一项真实机器人初步验证。
  • 评估模型：评估了 PI05、PI0、GROOT N1.6、OpenVLA-OFT、XVLA、ACoT-VLA、Lingbot-VLA、MOTUS 等 9 个 VLA 和 WAM 模型。
  • 主要指标：意图分 (IS)、执行力分 (ES) 和完成率 (CR)。
  • 关键结果：

- 所有模型在 L0（分布内）级别表现尚可，但多数模型的意图分在 L1-L3 级别出现大幅下降。

- 最强的平均意图分仅为 55.7（PI05），显示出显著的理解-执行差距。

- 空语言对照组（PI05 empty language）在全部分数接近随机水平，验证了高场景熵设计成功迫使模型依赖语言。

- 尝试使用更强 VLM 骨干、QA联合训练、LangForce、无分类器引导等缓解策略，均未能有效提升模型在 L1-L3 级别的指令遵循能力，表明该问题仍是当前模型的根本性瓶颈。
