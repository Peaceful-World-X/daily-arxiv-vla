Card 02 论文概述

论文概述

  • 论文提出TrAct框架，核心是用2D视觉轨迹作为机器人控制与世界模型之间的共享中间接口，解决传统动作作为接口时存在的具身特定性强、与图像空间视觉变化对齐弱的问题
  • 研究目标是构建以视觉轨迹为桥梁的机器人决策框架，同时提升世界模型的未来视频预测精度，以及机器人在分布偏移、跨具身迁移场景下的任务泛化能力
  • 针对传统动作条件世界模型需从低维具身特定动作推断稠密视觉未来、导致预测不准、策略鲁棒性差的问题，通过轨迹提供的稠密图像空间运动引导优化控制-预测闭环
Card 03 核心贡献

核心贡献

  • 提出2D点轨迹作为机器人与世界模型之间的中间表示，同时服务于策略学习和视觉预测，提升规划与预测效果
  • 设计TrAct三阶段框架：包含联合预测动作与视觉轨迹的VLAT模型、以轨迹为条件的TWM世界模型、基于视觉语言信号的VLAC奖励模型，实现奖励引导的动作选择
  • 构建LIBERO-INTEGRAL基准，覆盖鲁棒性偏移与跨具身迁移共20个任务，为策略泛化评估提供标准化测试平台
  • 在仿真和真实Franka机械臂实验中验证方法有效性，证明轨迹条件的世界模型在视觉域偏移下仍保持鲁棒预测性能，显著提升任务成功率
Card 04 方法描述

方法描述

  • TrAct核心分为三个模块：①VLAT基于预训练流匹配VLA策略π₀.₅修改动作头，联合输出动作块与2D点轨迹，预测两类点：夹爪关键点、5×5均匀采样的背景/物体点，采用视图非对称预测策略（智能体视图仅预测夹爪点，腕部视图同时预测夹爪点与场景点），通过联合流匹配目标训练；②TWM基于Stable Video Diffusion (SVD)，引入ControlNet分支将轨迹坐标编码为空间控制图，多视图轨迹用红/蓝通道区分以实现跨视图时间一致性，对比的动作条件基线AWM通过MLP编码动作至CLIP特征空间，加入可学习相机视图嵌入后通过交叉注意力注入SVD；③推理阶段采用温度缩放重采样（TSR）生成K个多样化动作-轨迹候选，TWM滚动各候选的未来视频，由基于InternVL2的VLAC评分后选择最优动作执行
  • 关键创新点在于用视觉轨迹替代低维具身特定动作作为世界模型的条件信号，为视频生成提供稠密的图像空间运动引导，解决动作到像素映射的不确定性问题
Card 05 数据集与资源

数据集与资源

  • 预训练数据集：采用76K DROID轨迹与150K EgoDex轨迹，按1:2比例混合，附录额外验证了加入BridgeData V2的更大预训练混合组合的效果
  • 模型规模：VLAT基于预训练VLA策略π₀.₅，世界模型基于Stable Video Diffusion，奖励模型采用InternVL2
  • 训练资源：预训练与微调均使用H100 GPU，VLAT和世界模型预训练阶段使用4张H100、batch size 64训练30K步；仿真微调VLAT训练5K步（batch size 16）、世界模型25K步（batch size 16）、奖励模型5K步（batch size 16）；真实机器人微调VLAT训练50K步（batch size 32）、世界模型25K步（batch size 16）、奖励模型4K步（batch size 16）
Card 06 评估与结果

评估与结果

  • 评估环境：仿真环境使用标准LIBERO套件与提出的LIBERO-INTEGRAL基准（含10个鲁棒性任务、10个跨UR5具身迁移任务）；真实环境使用Franka Emika Panda机械臂，测试5个训练外操作任务，分别覆盖训练背景与未见过的视觉偏移背景
  • 主要评估指标：任务成功率、视频生成质量（PSNR、SSIM、LPIPS、FID、FVD）
  • 关键实验结果：①视频生成：TWM在所有指标上优于AWM，仿真智能体视图PSNR从15.12提升至24.51，LPIPS从0.438降至0.106；真实场景腕部视图LPIPS从0.372降至0.225，FVD从246降至140；②仿真任务：标准LIBERO套件TrAct平均成功率达98.3%，LIBERO-INTEGRAL上平均成功率55%，较基线π₀.₅的27%提升28个百分点，较VLAT+AWM的49%提升6个百分点，在所有偏移场景下均取得最优性能；③真实机器人任务：TrAct平均成功率76%，较π₀.₅的49%提升27个百分点，较VLAT+AWM的66%提升10个百分点，未见过的背景下仍保持70%成功率，显著优于基线在域偏移下的性能下降
