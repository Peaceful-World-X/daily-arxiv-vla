Card 02 论文概述

论文概述

  • 针对 Vision-Language-Action（VLA）自动驾驶模型部署后注意力分配固定、无法在推理时无训练引导模型关注安全关键对象（如盲区并车、斑马线行人）的痛点，研究推理时注意力引导方法的可行性
  • 以基于 Qwen3-VL 骨架的 Alpamayo-R1 为研究对象，提出向检测器定位的交通参与者视觉 token 注入有界加性预 Softmax 注意力偏置的方案，完全不修改模型权重
  • 核心研究目标是验证该干预的传播效果、作用层级和可解释性，而非直接优化驾驶性能，重点回答干预是否、在何处、以多大程度影响模型输出
Card 03 核心贡献

核心贡献

  • 首次系统开展 VLA 自动驾驶模型的推理时注意力引导研究，搭建了带逐运行验证的检测器 grounding 演员- token 注入流程
  • 提出与 Qwen3-VL 分组查询注意力、每头 QK-Norm 兼容的有界预 Softmax 偏置 formulation，以 fail-open 前向钩子实现，无权重修改
  • 设计配对种子验证方法，从比扩散采样噪声底大一个数量级的噪声中分离出厘米级引导效果，得到单调的剂量-反应关系
  • 通过逐调用注入审计纠正认知偏差：观察到的 Chain-of-Causation（CoC）文本不变是干预未触及推理路径的暴露不对称，而非架构鲁棒性，为复合多模态模型的干预研究提供审计规范
Card 04 方法描述

方法描述

  • 采用有界加性预 Softmax 注意力偏置：针对 Qwen3-VL 的分组查询注意力，在 softmax 计算前给目标交通参与者的视觉 token 对应 logit 叠加有界偏置，通过 clamp 防止过大的偏置导致生成退化，同时排除前 k 个 sink token 避免干扰初始注意力汇聚
  • 实现演员检测与 token 映射：使用 YOLO11-nano 检测器在模型输入分辨率下定位前向摄像头领航车辆，通过针孔模型估算距离与横向偏移，将检测框映射到 Qwen3-VL 的 10×18 视觉 token 网格，所有映射索引均与 tokenizer 的视频 token span 逐运行验证，避免分辨率不匹配导致的映射错误
  • 通过 register_forward_pre_hook 修改 Qwen3VLTextAttention 模块的 attention_mask 参数实现偏置注入，钩子为 fail-open 设计，异常时返回未修改输入并记录日志
  • 设计暴露审计机制：记录每次前向调用的推理阶段、掩码存在情况、注入 token 数量，明确干预的实际作用范围（仅在扩散动作解码器前向传播中生效，Chain-of-Causation 的预填充/解码阶段使用无显式掩码的融合因果内核，从未被干预）
Card 05 数据集与资源

数据集与资源

  • 使用 PhysicalAI WorldModel-Synthetic 自动驾驶场景数据集的 50 个变道场景，为 Omniverse 渲染的多摄像头视频，采用前向广角摄像头、4 个上下文帧、0.5s 步长，输入分辨率调整为 576×320
  • 实验模型为 Alpamayo-R1-10B，基于 Qwen3-VL 骨架，包含 36 层 transformer、8 个 KV 头、28 个查询头，使用 NF4 量化，显存占用约 12GB，单张 24GB GPU 即可完成所有推理实验
  • 本方法为推理时干预，无额外训练过程，轨迹预测为 64 个航点、10Hz、6.4s 预测 horizon
Card 06 评估与结果

评估与结果

  • 评估采用配对种子协议：基线与引导运行共享完全相同的种子和确定性算法配置，确保轨迹差异仅由注意力偏置导致；零偏置控制条件（head_scale=0）下配对轨迹 ADE 严格为 0，验证配对有效性
  • 主要评估指标包括：平均位移误差（ADE，64 航点轨迹 L2 距离）、最大横向偏移、Chain-of-Causation 文本变化率（精确字符串匹配）、Cliff's δ、经 Holm 校正的 Wilcoxon 符号秩检验、位移方向相对演员侧的占比
  • 关键实验结果：

- 注入验证：目标列 logit 恰好增加 +4.0，非目标列无变化，无越界索引，每次运行仅 40 次偏置注入，全部作用于扩散动作解码器前向传播

- 剂量-反应：ADE 随偏置幅度单调增长，head_scale=4 时平均 ADE≈17cm，最大横向偏移平均≈38cm，单场景最大可达≈140cm；所有非零偏置条件与零偏置控制的差异均极显著（p<<1e-10，Cliff's δ=1.0）

- 层级定位：效应集中在 late 层，前 8 层几乎无效应（ADE 2.0cm），全部 36 层 hooked 时效应最大（ADE 67.6cm，最大横向偏移≈205cm），效应随 hooked 层数增加单调累积

- 轨迹几何：引导后轨迹前 2 秒与基线接近，之后逐渐向演员侧偏移，横向偏差呈超线性增长，在 horizon 末期达到峰值

- CoC 不变性：所有配对比较中 CoC 文本完全不变，但审计证实是干预未到达 CoC 路径，属于暴露不对称而非架构鲁棒性
