Card 03 核心贡献

核心贡献

  • 提出 VLAct，一种以表示为中心的 VLA 继续预训练方案，从预训练 VLM 出发，在异构、多实施例机器人数据上进行训练
  • 识别并分析了 VLA 继续预训练中的三种失败模式：VLM 先验知识侵蚀、单动作头过度专业化、实施例特定输出空间削弱跨实施例共享
  • 通过 VLM 先验保留（浅层保护与标题混合）、多头部连续动作协同监督、部分统一的跨实施例动作布局 来塑造骨干网络表示
  • 在多个模拟和真实世界基准上验证了 VLAct 的有效性，尤其是在 数据高效 的实施例迁移和 开源数据、16-GPU 训练设置下取得强竞争力
Card 04 方法描述

方法描述

  • VLM 先验保留：冻结视觉编码器和 LLM 底层，仅更新上层 LLM 层和动作头；在训练中混合标题数据，以锚定可训练的视觉-语言表示
  • 多头部连续动作协同监督：共享骨干网络，并行使用 OFT、PI 和 GR00T 三种连续动作头进行监督，防止表示坍缩至单一头部几何形状
  • 部分统一的跨实施例动作空间：在物理意义对齐的维度（如夹爪开合）上共享动作头，对不兼容的臂部维度进行掩码，并采用 周角感知损失 处理周期性关节角度
  • 下游微调时，丢弃预训练头部，重新初始化任务特定动作头，仅复用预训练骨干网络
Card 05 数据集与资源

数据集与资源

  • 使用的数据集：DROID、InternA1、RoboCoin、MolmoAct 等开源机器人数据集，以及用于 VLM 表示保留的标题数据
  • 模型规模：基于 Qwen3-VL-4B 视觉-语言骨干网络
  • 训练资源：所有实验均在 16 个 GPU 上进行
Card 06 评估与结果

评估与结果

  • 评估基准：LIBERO-Plus、VLA-Arena、RoboTwin 2.0、DOMINO、RoboDojo、RoboCasa-GR1 以及真实世界 Franka 机械臂实验
  • 主要评估指标：任务成功率（%）、部分进度得分
  • 关键实验结果：

- LIBERO-Plus：以 82.6% 总成功率超越 ABot-M0 等强基线，比同基线 Qwen3VL-OFT 提升 7.6%

- RoboTwin 2.0：在 Base 和 Data Scaling 设置下均取得领先，VLAct-OFT 在 Clean 和 Random 场景分别达到 92.5% 和 90.8%

- RoboCasa-GR1（未见实施例）：仅用 20% 下游轨迹即达到 49.5%，超越全数据 GR00T-N1.6 基线；全数据微调达到 54.0%

- RoboDojo（ARX X5）：在 35 个策略中排名第 6（成功率）和第 8（平均分），超越所有明确标注的 WAM 模型和多个工业级系统

- 真实世界实验：在单臂短程、长程、双臂协同及 OOD 任务上均持续提升成功率，例如单臂短程任务平均成功率从 77.5% 提升至 92.5%
