Card 02 论文概述

论文概述

  • 提出 IG-VLA 框架，旨在解决现有 VLA（视觉-语言-动作）模型缺乏对未来场景演变的明确预测以及推理计算开销过大的问题
  • 通过让模型“想象未来”并将推理所得知识“内部化为要点”（Internalizing the Gist），在保持任务成功率的同时大幅提升推理效率
Card 03 核心贡献

核心贡献

  • 提出 Latent Spatiotemporal Reasoning 机制，使 VLA 模型能够在视觉表征空间直接想象任务相关的未来场景演变，无需生成像素级视频
  • 提出 Scene Gist Memory 模块，将显式未来推理得到的场景-行为关联压缩为紧凑的 Scene Gist Token，使模型在推理时可跳过显式未来推演，大幅降低延迟
  • 在 LIBERO、LIBERO-Plus 和 VLABench 三个基准上验证了 IG-VLA 的有效性与高效性，Gist 策略在保持最高成功率的同时实现高达 6.38 倍的推理加速
Card 04 方法描述

方法描述

  • 基于传统 VLA 架构，引入 Latent Spatiotemporal Reasoning 模块，在潜在空间中预测未来视觉状态变化，并通过回归和方向一致性损失进行监督
  • 设计 训练流程：先训练推理策略（含未来想象），再冻结该策略，分别训练 Gist Compressor（压缩推理信息为目标向量）和 Gist Encoder（直接从当前观察预测该向量）
  • 推理时，Gist 策略直接使用当前上下文预测 Scene Gist Token 来引导动作生成，绕过了耗时的显式未来推演过程
Card 05 数据集与资源

数据集与资源

  • 训练数据集：LIBERO
  • 评测数据集：LIBERO、LIBERO-Plus、VLABench
  • 模型骨干：基于 PaliGemma，视觉编码器用 SigLIP So400m/14，语言模型为 Gemma-2B，动作专家为 Gemma-300M
  • 训练资源：推理模块训练使用 8 张 NVIDIA H100 GPU，Gist 模块训练使用 4 张 NVIDIA A6000 GPU；推理延迟在单张 NVIDIA A6000 GPU 上测量
Card 06 评估与结果

评估与结果

  • 主要评估指标：成功率、意图分数和进展分数、推理延迟
  • 在 LIBERO 上，IG-VLA（推理策略和 Gist 策略）均取得最高的 98.9% 平均成功率，优于最强基线 ACoT-VLA 的 98.5%
  • 在 LIBERO-Plus 监督微调后，IG-VLA 以 88.5% 的平均成功率超越 ACoT-VLA 的 88.0%，尤其在语言变化子集上从 79.7% 提升至 85.6%
  • 在 VLABench 上，IG-VLA 取得最高的平均意图分数 66.68，较 ACoT-VLA 提升 3.18 分
  • 推理效率方面，基于 Scene Gist 的 Gist 策略每动作块推理延迟仅 169.5 ms，较 FastWAM-IDM（1081 ms）加速 6.38 倍，较 ImageWAM（263 ms）加速 1.55 倍，GPU 时间从 420.7 ms 显著降低至 169.5 ms
