Card 02 论文概述

论文概述

  • 现有 vision-language-action (VLA) 策略的语言指令可控性不足，视觉驱动的运动先验往往主导预测，语言仅作为隐式条件无具名运动含义，难以通过更换语言指令直接调整末端执行器运动方向
  • 本文提出 Atomic Motion Coordinate (AMC)，一种几何基础的坐标表示，用于实现可语言 steerable、可力响应的双臂操作，解决语言对运动的弱控制问题
  • 论文评估三个分离的能力：几何方向原子干预、闭环子任务语言 steer、接触 rich 任务的力适应，验证AMC在不损失闭环操作能力的前提下提升语言可控性和力适应性能
Card 03 核心贡献

核心贡献

  • 几何监督、可干预的语言-运动接口：用正向运动学（FK）固定的 per-arm 原子坐标，将13种原子语言（±三轴平移、±三轴旋转、hold）与连续动作生成绑定，暴露可检查、可干预的运动控制点
  • 同一表示下的有界非累积力更新：力反馈通过有界球面修正调整名义运动坐标，仅重新生成未执行的 horizon 后缀，从固定名义坐标重新计算避免累积漂移，不需要新的语义指令
  • 三阶段渐进式训练与全量注入机制：无视觉原子 grounding 阶段保证语言独立控制运动，全观测阶段通过零初始化的 cross-attention 残差将坐标注入全部18个动作专家块，有界球面更新允许上下文细节调整轨迹而不偏离 grounded 方向
  • 跨三个能力 regime 的验证：离线原子干预、熟悉/OOD布局的闭环子任务 steer、接触 rich 任务的力适应，全面验证AMC的性能
Card 04 方法描述

方法描述

  • 采用分层架构：上层Qwen3.5-4B规划器以1Hz频率输出子任务，仅将子任务传入低层基于π0.5的VLA策略，低层策略观察三视角RGB图像、16维双臂状态、活跃子任务，以30Hz预测50步动作
  • 原子词汇表由FK固定：每个臂拥有13维原子集合（±x/y/z、±rx/ry/z、hold），所有标注从部署URDF和0.20m TCP偏移计算的末端运动得出，不依赖文本或视觉，避免语言-视觉 correlation 干扰
  • 无视觉原子 grounding 阶段： withheld 视觉输入，仅提供原子文本和归一化机器人状态， grounding 原子代码本和运动方向，用DCT-II低频重建目标抑制30Hz动作噪声，代码本在25k更新后冻结
  • 全观测运动潜变量：原子坐标指定运动趋势，动作专家生成场景条件的轨迹实现，通过零初始化的双头 cross-attention 残差将有序的左右臂坐标对注入全部18个动作专家块，有界球面更新允许最多45°的偏移，保证上下文细节调整不偏离 grounded 方向
  • 力响应潜变量调制：力分支将腕部120Hz的六轴 wrench 和状态历史编码为30个慢 token 和10个快 token，查询名义运动坐标生成512维力修正，有界球面更新仅重新生成当前RTC偏移后的未执行动作后缀，每次更新从固定名义坐标重新计算避免累积漂移
Card 05 数据集与资源

数据集与资源

  • 数据集：统一训练语料包含2375集 episodes、307万有效30Hz训练样本，覆盖 cabinet、drawer、水果、混合操作、screwdriver、plug、vase 7个领域；实验平台为CR1 dual-arm platform，配备两个7DoF双臂、两个夹爪、1个基座相机、2个腕部相机、2个六轴力/扭矩传感器，采样率为30Hz（RGB/状态/动作）、120Hz（ wrench ）
  • 模型规模：基于3.353B参数的π0.5 backbone，部署的原子路由和力路由分别增加34.56M、12.40M参数，总参数量增加46.96M（占backbone的1.40%），DCT目标构建和B1未来 wrench 预测器为训练-only 组件
  • 训练资源：所有训练阶段采用8×H800 GPU，全局 batch size 256，cosine annealing 学习率调度，z_T/z_M 阶段峰值学习率2.5×10^-5，B1阶段峰值学习率10^-4，B2阶段峰值学习率5×10^-6
Card 06 评估与结果

评估与结果

  • 评估环境与基准：在真实CR1双臂平台评估4类任务家族：多水果分拣（熟悉布局）、OOD水果排序（ unseen 布局）、抽屉检索和plug插入、双臂vase擦拭，每个任务50次真实机器人试验；基线包括微调π0.5、LA4VLA、ForceVLA、RSS、无力的AMC、AMC+Force
  • 主要评估指标：离线原子干预采用相反原子分离率、绝对方向成功率、 vs Empty 成功率；真实任务采用平均归一化任务进度（%）；力适应采用 suffix 加权的关节/TCP RMSE
  • 关键实验结果：

- 离线原子干预：在7520次匹配干预中，AMC的相反原子分离率达到92.5%（单）/83.1%（双），远高于LA4VLA-style的39.1%/24.0%；绝对方向成功率80.2%（单）/57.9%（双）， vs Empty 成功率74.5%/39.1%

- 真实任务进度：AMC将熟悉/OOD水果任务进度从82.7%/60.5%提升到88.9%/87.8%；plug任务从59.0%提升到78.5%，vase任务从71.6%提升到75.2%（加力适应）

- 力适应 ablation：匹配力历史将plug/vase的关节RMSE从0.0581降到0.0349，TCP RMSE从21.01mm降到15.27mm，相比移位的力历史提升23.9%/21.4%，验证力修正对当前接触的依赖

- 推理速度：原子-only推理耗时117.4ms，力启用慢/快循环分别耗时118.7/45.5ms，均在333ms的10动作窗口内满足实时要求
