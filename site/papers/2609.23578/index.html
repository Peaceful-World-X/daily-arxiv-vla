Card 02 论文概述

论文概述

  • 论文提出AR-WAM，一种面向机器人操作的视觉条件、智能体兼容的世界动作模型（World Action Model），针对现有视觉-语言-动作（VLA）模型和世界动作模型依赖自然语言指令作为任务条件的缺陷，解决文本作为智能体控制接口时存在的指代模糊、空间不精确、与智能体语言能力冗余、意图与执行黑箱纠缠等问题
  • AR-WAM以两种互补条件完全替代自然语言输入：视觉定位提示（目标 bounding box） 用于无歧义指定交互对象与空间位置，可学习的原子操作token 用于指定要执行的原子技能，将“在哪里操作”和“如何操作”解耦，由智能体负责语言理解、规划、记忆与错误恢复，策略仅专注于动作生成
  • 论文在仿真基准RoboTwin 2.0、RMBench以及真实Astribot S1双臂平台上验证模型性能，证明视觉条件优于文本条件，且兼容不同类型的智能体完成长程记忆依赖任务
Card 03 核心贡献

核心贡献

  • 首次提出以视觉定位提示和可学习原子操作token完全替代自然语言作为机器人操作策略的输入条件，从接口层面解决文本作为智能体-策略交互媒介的固有缺陷
  • 设计轻量级0.5B参数的AR-WAM架构，包含共享Transformer的推理专家与世界动作专家，搭配冻结预训练DINOv3视觉编码器，无独立语言编码器，在紧凑潜变量中联合预测场景演化与动作输出
  • 提出双级前瞻对齐训练机制，通过视觉前瞻与语义前瞻两个监督信号，让动作预测与未来场景演化对齐，同时用可监督的推理信号暴露策略意图，便于故障诊断
  • 提供模型无关的智能体兼容层，封装detect、execute、query三个原语，支持本地部署VLM或在线API智能体直接驱动策略，无需了解策略内部逻辑
  • 实验验证AR-WAM在标准操作任务上平均成功率达87.2%，与最强基线持平；在记忆依赖长程任务上成功率比基线高5.9%，真实机器人任务上高36.7%，同时保持最低14.1ms的推理延迟
Card 04 方法描述

方法描述

  • 任务条件与调制：将操作任务分解为pick、place、handover等原子技能集合，每个技能对应独立可学习的嵌入向量；视觉定位提示为归一化坐标的bounding box，额外支持指定执行手臂（参与者）和交互方式（风格）的可学习嵌入，所有条件通过AdaLN条件调制注入策略网络，避免跨注意力机制带来的属性依赖偏移
  • 双专家共享架构：整体由0.2B共享Transformer和0.3B冻结DINOv3视觉编码器组成，Transformer同时服务于推理专家与世界动作专家：推理专家通过可学习的推理查询token提取当前任务理解，输出目标mask、双臂终端位姿、任务抽象三个可监督信号；世界动作专家基于流匹配框架进行多步去噪，联合预测动作块、视觉前瞻、语义前瞻三个模态
  • 双级前瞻对齐：离线预训练前瞻要点提取器，从演示序列的起止帧提取压缩的未来演化表征作为训练目标；世界动作专家的视觉前瞻对齐离线提取的前瞻要点，语义前瞻对齐推理专家从未来观测得到的推理token，通过stop-gradient避免反向传播污染观测编码路径
  • 智能体交互与容错：封装detect（智能体侧完成视觉 grounding 得到定位框）、execute（ rollout 策略直到触发事件）、query（返回执行反馈）三个模型无关原语；智能体调用由位移阈值、夹爪闭合/张开、固定时间间隔四个事件触发，长程任务记忆完全由智能体侧历史承载，策略为无内部状态的马尔可夫过程；执行失败时智能体重新生成视觉提示并重试，可区分是意图错误还是执行错误
Card 05 数据集与资源

数据集与资源

  • 仿真训练与测试数据集：RoboTwin 2.0（包含10个双臂长程操作任务，每个任务提供50条干净演示与500条随机演示）、RMBench（包含记忆依赖的长程操作任务，每个任务提供50条演示，使用Qwen3.8-27B与Kimi-K3生成任务指令）
  • 真实机器人测试平台：Astribot S1 双臂操作平台
  • 模型规模：总参数量0.5B，其中共享Transformer 0.2B，冻结预训练DINOv3视觉编码器0.3B，无独立语言编码器
  • 训练配置：联合使用RoboTwin 2.0与RMBench的演示数据训练，训练时对视觉定位提示进行随机坐标抖动增强，提升对不精确定位框的容忍度；相邻操作之间插入homing归位动作，避免操作过程遮挡目标对象
  • 推理效率：单步推理延迟最低达14.1ms
