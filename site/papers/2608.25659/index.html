Card 02 论文概述

论文概述

  • 针对 Vision-Language-Action (VLA) 策略在理解度量3D结构和短期物理演化方面的不足，提出 GaussianDream++
  • 通过将 World State Tokens 和 World Prediction Tokens 直接嵌入VLA骨干网络，在训练时提供密集的3D监督信号
  • 采用非对称训练-部署策略，推理时移除所有高斯解码和渲染组件，仅保留20个world tokens，实现高效闭环控制
Card 03 核心贡献

核心贡献

  • 紧凑的策略原生高斯世界建模：用20个（16个World State + 4个World Prediction）可学习tokens替代GaussianDream的1024-token密集VGGT/TGE前缀，直接嵌入PaliGemma骨干网络
  • 角色结构的当前与未来表示：World State Tokens重建当前世界，World Prediction Tokens预测短期演化，通过静态-动态因子分解将残差运动集中在机器人、操作对象和交互区域
  • 高效的非对称监督与鲁棒控制：高斯解码、可微渲染和辅助目标仅限于训练，推理时完全移除，无需运行时几何通路或未来展开
  • 分布偏移鲁棒性：在Camera和Layout等几何敏感偏移下显著提升性能，同时保持高成功率
Card 04 方法描述

方法描述

  • 策略原生世界表示：在PaliGemma前缀中插入16个World State Tokens（4×4粗空间组织）和4个World Prediction Tokens，与视觉、语言token联合上下文化
  • 当前世界重建：World Representation Head将World State Tokens解码为密集高斯特征场，通过几何-外观分解分别预测深度、尺度、旋转、透明度及球谐外观系数
  • 耦合未来预测：基于重建的当前世界模板，仅预测horizon-dependent的高斯中心位移，通过静态-动态门控将运动集中在动态区域
  • 世界-动作联合学习：联合优化动作生成损失（flow-matching）与当前/未来高斯监督损失，训练后移除World Representation Head、渲染器和所有辅助分支

数据集与资源

  • 仿真数据集：LIBERO（包含Spatial、Object、Goal、Long四个任务套件）和 LIBERO-Plus（包含Camera、Robot、Language、Lighting、Background、Noise、Layout七种分布偏移）

  • 模型规模：基于 PaliGemma/π₀.₅ 骨干网络，仅增加20个world tokens（16个状态 + 4个预测），参数量增量极小

Card 06 评估与结果

评估与结果

  • 评估环境：LIBERO标准任务、LIBERO-Plus零样本鲁棒性测试、真实机器人实验
  • 主要指标：任务成功率（%）
  • 关键实验结果：

- LIBERO：平均成功率 98.6%，超越GaussianDream（98.4%）和复现π₀.₅（96.9%）

- LIBERO-Plus：Overall 87.8%，超越GaussianDream（87.0%）和复现π₀.₅（85.5%）

- 几何敏感偏移：Camera从73.2%提升至80.1%（+6.9），Layout从87.7%提升至90.0%（+2.3）

- 真实机器人：平均成功率从 29.2% 提升至 52.5%，Bowl-Proximity从25.0%提升至46.7%，Eggplant-to-Pink-Plate从33.3%提升至58.3%

- 推理效率：无需运行时VGGT/TGE路径，无需在线高斯解码、渲染或未来展开，仅需处理20个world tokens
