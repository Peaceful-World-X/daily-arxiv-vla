Card 02 论文概述

论文概述

  • 提出CometVLA端到端框架，解决当前Vision-Language-Action (VLA) 模型在需要物理常识的机器人操控任务中表现脆弱的核心问题
  • 构建CometData和CometBench，首个与机器人动作数据视觉领域和具身形态严格对齐的具身物理常识VQA语料库与基准，包含100万QA对和2000个评测问题
  • 引入Global Action Prior (GAP) tokens作为信息瓶颈，隔离任务无关的运动规律，使动作头能够显式消耗物理常识而不破坏预训练VLM主干
  • 在具身数据金字塔（遥操作、仿真、第一人称视频、VQA）上进行联合训练，通过系统性分析证明VLM物理理解能力的提升确实能转化为下游动作生成的改进
Card 03 核心贡献

核心贡献

  • CometData与CometBench：首个与机器人动作数据严格对齐的具身物理常识VQA语料库与基准，覆盖5个领域16个类别，用于评估 embodied physical reasoning
  • Global Action Prior (GAP) Token：轻量级可学习瓶颈（1024维），作为自回归VLM与扩散动作专家之间唯一的通信接口，通过stop-gradient屏障实现优化稳定性
  • CometVLA训练范式：基于知识绝缘（knowledge insulation）的VLM-VLA联合预训练，结合FAST动作分词器和DiT-B流匹配动作专家，实现端到端动作生成
  • VLM-VLA相关性验证：通过大规模消融实验和相关性分析，建立VLM物理理解能力（CometBench）与VLA动作成功率之间的正相关关系（空间推理r=0.721，物理动力学r=0.645）
Card 04 方法描述

方法描述

  • 架构设计：采用预训练的Qwen3-VL-4B作为视觉-语言主干，结合FAST动作分词器处理离散动作token，以及基于DiT-B的流匹配动作专家处理连续动作生成，总损失为自回归损失、FAST损失和流匹配损失之和
  • GAP Token机制：将可学习的GAP token插入主干token序列中，通过stop-gradient屏障与扩散策略域隔离，仅允许GAP token穿越边界进行跨注意力计算，作为全局动作先验聚合高层语义和时间上下文
  • 数据构建：构建物理感知的具身数据生成流水线，通过基于动力学的关键帧提取（Hamiltonian jump、夹爪步进、功率异常三个标准）从多源具身轨迹中提取关键帧，再由16个生成器生成QA对，确保与机器人动作数据使用相同的数据构建方案
  • 两阶段训练：第一阶段为联合预训练，同时训练VLM主干（自回归损失+FAST损失）和动作专家（流匹配损失，仅更新动作头和GAP token）；第二阶段为任务特定微调
Card 05 数据集与资源

数据集与资源

  • CometData：包含100万QA对，180万+图像，从AgiBot-World-Beta（遥操作）、InternData-A1（仿真）、EgoLive、EgoDex（第一人称视频）和通用VQA数据构建
  • CometBench：包含2000个问题的保留测试集，覆盖空间推理、任务理解、物理与动力学、错误与工具、可供性5个领域，由大语言模型作为裁判进行评分
  • 模型规模：Qwen3-VL-4B主干（2560维），DiT-B动作头，GAP token维度为1024，双机械手动作空间维度为32
  • 训练资源：4个计算节点，每个节点配备8×H200 GPU，总共32块H200 GPU进行分布式训练
Card 06 评估与结果

评估与结果

  • 真实机器人实验：在AgiBot G1双臂机器人上进行化妆桌整理场景测试，bb cream（75.00%）、liquid foundation（31.25%）、lotion（37.50%）、makeup sponge（93.75%）、serum（43.75%），成功率因物体尺寸和纹理差异而变化
  • RoboTwin 2.0仿真基准：在Easy split上达到89.24%成功率，Hard split上达到88.38%成功率，显著优于π0.5（62.86%/60.30%）、RDT（34.50%/13.72%）、X-VLA（70.00%/39.00%）等强基线方法
  • 消融实验：移除物理VQA数据（w/o phys. VQA）导致最大性能下降，移除GAP token（w/o GAP）也会持续降低性能，验证了各组件对物理理解和动作生成的贡献
  • VLM-VLA相关性分析：VLM在CometBench上的性能与VLA在RoboTwin上的成功率呈正相关，空间推理领域相关性最强（Pearson r=0.721），物理与动力学次之（r=0.645），可供性最弱（r=0.552）
  • GAP Token分析：t-SNE可视化显示GAP token能学习到语义级动作表示；线性探测实验显示GAP token在夹爪状态预测上比VLM-mean高7.0%（49.8% vs 42.8%），在运动幅度预测上高3.9%（54.3% vs 50.4%），尽管维度仅为后者的2.5倍
