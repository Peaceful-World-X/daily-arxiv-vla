Card 02 论文概述

论文概述

  • 针对视觉‑语言‑动作（VLA）模型在开环规划中的 状态表示不匹配 问题，指出文本、像素和潜在空间推理均难以有效追踪动态状态变化
  • 提出 状态空间视觉推理（SSVR），通过解耦静态视觉上下文与循环潜在状态，使模型在仅给定初始观测的条件下即可可靠地生成长序列动作
  • 在 FrozenLake、Maze 和 MiniBehavior 三个规划任务上验证了方法的有效性、鲁棒性和高效性
Card 03 核心贡献

核心贡献

  • 提出 SSVR 框架，使用一次编码的静态 KV 缓存和 动作条件 GRU 更新潜在状态，实现精确的开环动作序列规划
  • 在三个规划任务上取得最优结果，显著超越文本空间、像素空间和潜在空间代表性基线，最高提升达 21.8 个 EM 百分点
  • 证明 SSVR 对提示改写、图像缩放/翻转/颜色反转具有鲁棒性，并支持跨数据集零样本迁移，同时保持通用 VQA 能力
  • 展示了静态上下文复用带来的 极高推理效率，相比 VPRL 实现最高 98.58 倍解码加速
  • 通过梯度加权归因分析揭示了状态条件化下注意力随规划步的变化，增强了模型可解释性
Card 04 方法描述

方法描述

  • 以 Qwen2.5-VL 为骨干，仅训练 LoRA 适配器和轻量 GRU 模块，冻结预训练权重
  • 初始图像和指令编码为可复用的前缀 KV 缓存，视觉特征均值经线性层和 LayerNorm 初始化潜在状态 \(z_0\)
  • 每步将当前潜在状态作为独立 token 插入解码器，通过原始 LM head 预测动作，再利用 GRUCell 根据动作嵌入更新潜在状态
  • 采用 软目标训练：对每个状态构造安全动作集与最优动作集的混合分布作为监督信号，平衡动作多样性与最优性
  • 推理时支持前缀缓存，每步仅需追加一个状态 token，极大降低计算量

数据集与资源

  • 评估数据集：FrozenLake、Maze、MiniBehavior
  • 骨干模型：Qwen2.5-VL-7B，使用 LoRA 微调
  • 训练资源未显式说明，但实验中提到使用 KV 缓存和 CUDA，主流 GPU 完成训练
Card 06 评估与结果

评估与结果

  • 评估环境：三个规划任务的开环序列预测，使用精确匹配率（EM）和进度率（PR）
  • 主要结果：

- FrozenLake：EM 99.5 / PR 99.6

- Maze：EM 96.3 / PR 98.0

- MiniBehavior：EM 83.9 / PR 90.6

- 平均 EM/PR 达 93.2/96.1，远超最强基线 VPRL（80.6/84.9）

  • 鲁棒性：提示改写、图像缩放/翻转/颜色反转下性能稳定，仅小幅下降
  • 跨数据集迁移：从 FrozenLake 到 Maze，SSVR 零样本 EM 达 33.6%，远高于 VPRL 的 6.8%
  • VQA 保留：通用 VQA（VQAv2）准确率仅下降 3.9 个百分点，且在 Maze 动作选择 VQA 上有显著提升
  • 效率：启用缓存后单步延迟 45.6 ms，一步 rollout 仅需 182.4 ms，比 LVR、Monet 和 VPRL 分别快 5.81×、38.24× 和 98.58×
