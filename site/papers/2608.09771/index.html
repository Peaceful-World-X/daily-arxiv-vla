Card 02 论文概述

论文概述

  • 提出 SLIM (Self-supervised Latent Interaction Model)，一种紧凑的 0.5B 参数潜在交互策略，用于语言条件机器人操作
  • 核心思想是分离语义条件与动作控制，通过自监督掩码轨迹预测学习动作与观测之间的双向交互关系，避免使用大型 VLM 或像素级未来预测
  • 旨在解决现有大模型策略计算冗余、像素级世界模型效率低的问题，提供低延迟、低内存占用的高效控制策略
Card 03 核心贡献

核心贡献

  • 提出 SLIM，一个仅 0.5B 参数的紧凑型潜在交互策略，将控制计算集中在动作-观测潜在交互上
  • 引入 动作驱动的掩码轨迹预测，通过互补的反向动力学（从当前和未来观测重建动作）和正向动力学（从当前观测和动作预测未来观测潜在）目标，学习预测性观测潜在变量
  • 在多个基准（LIBERO、LIBERO-Plus、CALVIN）和真实世界机器人操作上，以更少参数、更低延迟和更少 GPU 内存，达到或超越代表性 VLA 和世界-动作模型基线
Card 04 方法描述

方法描述

  • 两阶段训练：第一阶段通过掩码轨迹预测学习动作驱动的观测潜在变量；第二阶段使用流匹配训练最终的动作生成策略
  • 模型架构：采用紧凑的 Mixture-of-Transformers (MoT) 骨干，包含观测流和动作流，通过联合注意力机制交互，语言条件通过交叉注意力注入
  • 视觉编码器基于 DINOv2 初始化，语言编码器使用 T5-small；动作生成采用流匹配，推理时无需未来观测输入
  • 创新点：将反向和正向动力学目标统一在同一个潜在空间中，使得策略在推理时隐式地利用未来预测结构，无需显式生成未来帧或额外世界模型
Card 05 数据集与资源

数据集与资源

  • 仿真数据集：LIBERO（10、Object、Spatial、Goal 四个任务套件）、LIBERO-Plus（七种扰动零样本泛化）、CALVIN ABC→D（长视界组合任务）
  • 真实世界数据集：5 个任务（胡萝卜入碗、叠盘子、取土司、叠积木、擦白板），每个任务 150 个演示，共 750 个演示
  • 模型规模：0.5B 参数（实际 0.47B），视觉编码器基于 DINOv2，语言编码器 T5-small
  • 训练资源：未明确列出训练 GPU，但推理评估使用 NVIDIA H100 80GB
Card 06 评估与结果

评估与结果

  • 评估环境：LIBERO 和 LIBERO-Plus 采用成功率，CALVIN 采用平均完成序列长度，真实世界采用进度分
  • 主要指标：成功率（%）、平均序列长度、推理延迟（ms）、峰值显存（GiB）、GFLOPS
  • 关键结果：

- LIBERO 总体成功率 97.5%，LIBERO-Plus 零样本成功率 77.45%，均优于多数基线

- CALVIN ABC→D 平均序列长度 4.556（满分 5），与最佳基线持平

- 真实世界多任务中，名义、光照、干扰物条件下平均进度最高，背景变化下与 π0.5 接近

- 推理延迟 60.6 ms，比 π0.5 快 3.19 倍，比 Fast-WAM 快 5.95 倍；峰值显存仅 4.26 GiB，GFLOPS 仅为 π0.5 的 1/9.6
