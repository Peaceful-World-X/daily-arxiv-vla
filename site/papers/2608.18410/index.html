Card 02 论文概述

论文概述

  • 论文提出 Role-Conditioned Sub-Token Routing (RoleSub) 方法，旨在解决 Vision-Language-Action (VLA) 模型处理长多模态 token 序列导致推理成本高昂的问题
  • 通过结合 token 级减少（控制保留哪些 token 状态）和子 token 路由（控制保留 token 内保留多少 value 信息），在不移除额外 token 的情况下压缩 transformer 的 KV 状态
  • 在 OpenVLA-OFT-7B 和四个 LIBERO 套件上评估，在匹配的视觉 KV 预算下，RoleSub 在 36 个设置中的 33 个优于训练过的 token-only 控制，在长 horizon 任务和激进压缩下增益最大
Card 03 核心贡献

核心贡献

  • 引入 RoleSub，结合正交值空间分解、学习到的潜在角色表示和 token 类型相关预算，将子 token 路由适配到 VLA 控制任务，且不需要预定义的语义角色
  • 在匹配的视觉 KV 预算下，RoleSub 在 33/36 个 LIBERO 设置中优于训练过的 token-only 控制，在激进压缩和长 horizon 任务上增益最大
  • 揭示 token 保留和 value-width 保留在 VLA 策略中的不同行为：语言 token 对 token 移除高度敏感，但其 value 表示可被压缩高达 16 倍而几乎无损失
  • 结合视觉和语言路由可将完整多模态前缀 KV 减少到原始大小的 9.2–11.3%，同时在大多数任务上保持强控制性能
Card 04 方法描述

方法描述

  • Token 级减少：使用 QK-based 选择机制（如 VLA-ADP）对视觉 token 进行重要性评分，保留评分最高的 token，不同 token 类型（视觉、语言、本体感觉、动作）可独立控制保留比例
  • 正交值空间分解：将每个保留 token 的 value 向量通过固定的正交矩阵 $R^{(\ell)}$（从随机 Stiefel 矩阵初始化并冻结）转换到正交路由空间，然后均分为 $S=16$ 个非重叠组，每组 256 维
  • 学习到的潜在角色表示：通过轻量级角色估计器 $f_{\text{role}}^{(\ell)}$ 为每个 token 产生 $C=6$ 维的 soft 潜在角色表示 $\mathbf{a}_i^{(\ell)}$，这些组件通过控制目标联合学习，不预定义语义含义
  • 角色条件值路由：结合三个路由信号计算路由分数：token 状态评分 $f_v^{(\ell)}(\mathbf{h}_i^{(\ell)})$、潜在角色评分 $W_{\text{role}}^{(\ell)}\mathbf{a}_i^{(\ell)}$、语言上下文评分 $f_{\text{lang}}^{(\ell)}(\overline{\mathbf{h}}_{\text{lang}}^{(\ell)})$，使用 straight-through estimator 进行 Top-K 选择的离散路由
  • Token 类型相关值预算：不同 token 类型具有不同的平均保留组数 $K_m$，使用潜在角色表示作为优先级信号，将总预算 $B_m = K_m \|\mathcal{I}_m^{\text{keep}}\|$ 在保留 token 间灵活分配
  • 训练策略：保持预训练 VLA backbone 冻结，联合训练 LoRA 适配器（秩 32，缩放 16）、路由函数和潜在角色估计器，使用 $\ell_1$ 回归损失进行动作预测
Card 05 数据集与资源

数据集与资源

  • 基础模型：OpenVLA-OFT-7B（基于 Llama-2-7B，总参数量 7.65B）
  • 数据集：LIBERO 套件（Spatial、Object、Goal、LIBERO-10），每个套件包含 10 个任务，使用 no-op-filtered LIBERO RLDS 数据训练
  • 模型规模：LoRA 适配器约 110.8M 可训练参数，路由头约 4.20M 参数，潜在角色估计器约 0.55M 参数
  • 训练配置：使用 AdamW 优化器，学习率 $2 \times 10^{-4}$，有效 batch size 为 8，启用了图像增强
  • 评估指标：每个 checkpoint 在每个任务上运行 50 次试验，评估闭环任务成功率（success rate）
  • 计算资源：使用 Futurewei Technologies 的计算资源进行实验
