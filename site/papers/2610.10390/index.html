论文概述

  • 提出 GeoCoTDrive，一种面向 VLA 自动驾驶的显式几何思维链框架，遵循“先 2D 推理，再基于 3D 先验驱动”范式，桥接语义推理与几何规划。

Card 03 核心贡献

核心贡献

  • 提出 GeoCoTDrive 框架，通过显式几何思维链将 2D 规划相关区域定位与局部 3D 几何特征检索相结合，用于端到端规划。
  • 定义新任务 planning-relevant grounding，关注直接影响 ego 规划的局部决策关键区域，并构建包含 146K 标注的 PlanningGrounding 数据集。
  • 设计自回归几何检索机制，根据预测的接地区域从几何基础模型中采样局部 3D 特征，并交错插入自回归上下文以生成未来轨迹。
Card 04 方法描述

方法描述

  • 基于 VLM 首先生成规划相关的 2D 区域（bounding boxes），然后从冻结的几何基础模型（如 DepthAnythingV3 或 VGGT）的密集特征图中采样对应区域的特征。
  • 采样特征通过轻量 MLP 投影头对齐到语言空间，形成几何令牌，交错插入到自回归生成过程中，最终解码输出未来轨迹。
  • 训练分两阶段：第一阶段适应驾驶场景的 VLM 全参数微调；第二阶段冻结视觉编码器，仅优化 LLM 和几何对齐头，使局部几何特征与语言空间对齐。
  • 关键创新在于将几何融入从全局隐式变为显式且规划导向的思维链，在 2D 推理后针对性地检索 3D 先验。
Card 05 数据集与资源

数据集与资源

  • 规划数据集：nuScenes、NAVSIM、Bench2Drive 的标准分割。
  • 自建数据集：PlanningGrounding，包含 146K 规划导向的接地标注，覆盖 critical-object、road-boundary、conflict-area、occluded-unknown-area、dense-object-area 五类。
  • 模型规模：基础 VLM 采用 LLaVA-1.5-7B 或 Qwen2.5-VL-3B；几何基础模型采用 DepthAnythingV3 或 VGGT（冻结）。
  • 训练资源：未明确说明具体 GPU 类型，采用两阶段训练，监督训练使用 teacher forcing 的交叉熵损失。
Card 06 评估与结果

评估与结果

  • 评估环境和基准：nuScenes 验证集（开放环规划）、NAVSIM navtest 分割（闭环绕 PDMS）、Bench2Drive（闭环绕 DS/SR）；接地性能在 PlanningGrounding 测试集（0.6K 人工精标样本）上评估。
  • 主要评估指标：L2 距离误差、碰撞率、交叉率、PDMS 及其子分数（NC, DAC, TTC, Comf., EP）、驾驶分数与成功率；接地指标包括 Recall@0.3/0.5/0.7、AP、mIoU。
  • 关键实验结果：

- nuScenes 上 GeoCoTDrive 达到平均 L2 0.32，平均碰撞率 0.11，平均交叉率 2.02，多项指标位列 VLA 方法前列。

- NAVSIM 上 PDMS 达到 87.6，超过 AutoVLA（80.5）、ReCogDrive（86.8）等对比方法。

- Bench2Drive 上 DS 78.68，SR 55.42，优于 ORION 和 SpaceDrive。

- PlanningGrounding 接地评估中，R@0.3 56.82，R@0.5 42.73，显著优于 OmniDrive 等基线。

- 消融实验表明显式几何思维链优于全局几何注入，且 PlanningGrounding 监督优于普通感知标注。
