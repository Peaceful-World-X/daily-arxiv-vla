  • 核心思路是将分层精度分配与工作负载相关的 GPU 频率/功率上限选择协同优化，在保证成功率且推理延迟增加不超过 10% 的条件下最大化每成功任务能量节省。
Card 03 核心贡献

核心贡献

  • 实证表征：首次系统刻画了量化敏感性随动作类别、Transformer 层数以及权重 vs. 激活精度的变化规律，并证明不同数值精度会改变 GPU 的有利操作点。
  • 动作感知的自适应框架：提出 ActTune，通过轻量级决策树和共享量化权重库实现动作条件下的分层精度在线选择，每次策略调用仅需一次推理，并结合异步 GPU 操作点调整。
  • 端到端系统实现与评估：在 LIBERO 基准上对 OpenVLA-OFT 和 π0.5 模型进行完整闭环评测，相比 SOTA 量化方法提升任务成功率最高达 2.3%，推理延迟最多加速 2.02×，能量每成功任务降低最高 76.8%。
  • 整体能耗优化：量化、内核/运行时优化以及 GPU 操作点自适应三者联合贡献，使能量节省超过单独量化或静态硬件设置。
Card 04 方法描述

方法描述

  • 动作感知精度选择：离线校准构建决策树，根据当前本体感知和前序预测动作块选择分层权重/激活精度配置，树的划分和叶节点配置直接从 BF16 参考策略的动作误差学习，不依赖预定义动作阶段。
  • 共享量化权重库：在平均精度与存储预算下，通过灵敏度引导的逐层校准生成多个权重/激活精度选项，叶节点可共享配置，切换时无需重建权重，支撑单次推理调用。
  • GPU 操作点自适应：针对每种精度配置离线扫描频率和功率上限，选择满足延迟预算（≤10% 相对参考点）的最低能耗组合，在线利用预测工作负载异步调整 GPU 频率和功率上限。
  • 高效整数内核执行：采用 INT4×INT4 和 INT8×INT8 Tensor Core 内核，包含融合量化与 GEMM 的 epilogue 优化，减少 kernel 启动次数和中间显存流量。
Card 05 数据集与资源

数据集与资源

  • 数据集：LIBERO（含 Spatial、Object、Goal、Long 四个套件，共 40 个任务，每个任务 50 个初始状态）
  • 模型：OpenVLA-OFT（约 4.5 GB 精度配置）和 π0.5（约 3.4 GB 精度配置）
  • 训练与评估规模：每模型每精度设置使用 2000 个评测回合；校准使用 512 条离线轨迹
  • 硬件：NVIDIA RTX A6000 GPU（Ampere 架构），CUDA 同步计时，NVML 功率采样
  • 精度设置：W4A16、W4A8、W4A4 等混合精度方案，所有权重和激活量化均在 RTX A6000 上实测
Card 06 评估与结果

评估与结果

  • 对比基线包括 QVLA、ActQuant、SmoothQuant、GPTQ、AWQ 以及 BF16 原始实现。
  • 任务成功率：OFT W4A8 达 97.0%，π0.5 W4A4 达 98.4%，超过最佳对比基线最多 5.1 个百分点。
  • 推理加速：OFT W4A8/ W4A4 分别达 1.50× 和 1.53×；π0.5 分别达 2.02× 和 1.81× 推理速度提升。
  • 能量节省（固定 GPU 参考点）：OFT W4A8/W4A4 分别降低 59.5%/59.9%，π0.5 分别降低 70.9%/46.1%。
  • 结合 GPU 操作点自适应：能量每成功任务进一步降至最多 76.8% 节省，推理延迟增加均在 7.79–8.63%，符合 10% 预算。
  • 消融实验：验证决策树叶数（3 叶最佳）、GPU 操作点选择策略（区域+配置联合控制优于固定或仅配置控制）以及能量节省来源（量化、内核优化、DVFS 三者贡献分解）。
