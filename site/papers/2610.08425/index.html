Card 02 论文概述

论文概述

  • 提出 MIM-VLA，一种基于抓手电机反馈的架构，从抓手电流、位置、速度等遥测数据中学习物理交互表示
  • 解决当前视觉-语言-动作（VLA）模型主要依赖视觉和机器人状态，缺乏对接触后物理响应的显式建模问题
  • 通过时序编码将电机遥测转换为交互令牌，在维持原有位置控制接口的前提下，赋予机器人接触状态感知和基于物理证据的候选比较能力
Card 03 核心贡献

核心贡献

  • 设计并预训练了 Motor Interaction Module (MIM)：仅利用时序抓手遥测（电流、位置、速度等）与人工标注的接触/相位监督，获得128维交互令牌，无需校准力传感器
  • 提出 抓手特定集成：将交互令牌通过轻量投影仅注入到 SmolVLA 的抓手动作通路，冻结预训练的视觉-语言骨干与手臂通路，保留原始位置控制接口
  • 构建 Material Explain Module (MEM)：共享交互令牌不仅用于闭环抓手控制，还支持基于物理证据的候选对象比较、选择与自然语言解释
Card 04 方法描述

方法描述

  • Motor Interaction Module (MIM)：使用 GRU 编码推定的因果遥测窗口（位置、速度、电流、有效性掩码等），输出交互令牌 \(\boldsymbol{\tau}\)；预训练时用接触二分类和五类交互相分类（idle、closing、squeeze、hold、opening）作为辅助损失，人为排除视觉信号以防止外观捷径
  • SmolVLA 集成：保留 SmolVLA 的流匹配动作生成框架，增设抓手专用专家；交互令牌经可学习投影与令牌类型嵌入后注入该专家，手臂路径与输出接口不变；微调时更新抓手专家、投影、MIM 编码器等，主干冻结
  • Interaction Memory 与 MEM：为每个候选对象独立存储交互历史，通过双向时序编码器和多种池化得到 \(K=4\) 个摘要令牌；选择器 VLM 接收两个候选的摘要及任务指令，预测更具阻力的候选，并输出相对位移和电流响应及解释文本
Card 05 数据集与资源

数据集与资源

  • 预训练数据：360 个交互片段，涵盖 18 种对象（每对象 20 片段），由示教收集并人工标注接触与相位标签
  • 策略数据：197 个策略片段，加上 43 个无接触基线和 3 个高力诊断样本，共 243 个片段，65,512 个因果样本（30 Hz，2 秒历史窗口）
  • 模型基础：SmolVLA 紧凑流匹配架构；MIM 为轻量 GRU；MEM 使用预训练 VLM（具体参数规模未详述）
  • 训练资源：一张 NVIDIA RTX 5090，批量大小 64
Card 06 评估与结果

评估与结果

  • 硬件平台：6-DoF OMY F3M 随动臂，Dynamixel 两指抓手，Intel RealSense D405 腕部相机，ROS 2 / Zenoh 通信
  • 实验任务：

- 实验1：跨外观硬度比较（7 对已见 + 3 对未见的视觉差异物体对）

- 实验2：外观匹配物理消歧（3 对实物与软复制品）

- 实验3：易碎物体轻柔抓取（8 个已见 + 3 个未见的可变形/易碎物体）

  • 主要指标：

- 候选选择准确率（选择更具阻力对象）

- 变形程度（SAM 2 掩码面积减少百分比）

- 无损抓取成功率

  • 关键结果：

- 13 对物体整体选择准确率：MIM-VLA 75.0% vs. 原始 SmolVLA 48.8% vs. 原始电流基线 29.2%

- 实验3 已见可变形物体平均掩码面积减少：MIM-VLA 14.2%（SmolVLA-flow 31.4%，TA-VLA-inspired 24.0%）

- 实验3 已见易碎物体无损抓取成功率：MIM-VLA 50.0%（SmolVLA-flow 15.0%），未见生鸡蛋 6/20 次成功

- 消融实验表明每候选 4 个摘要令牌 (\(K=4\)) 在决策、解释一致性和交换一致性上表现最佳
