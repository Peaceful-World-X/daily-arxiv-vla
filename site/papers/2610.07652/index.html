Card 02 论文概述

论文概述

  • 论文提出 SMART 系统，旨在通过大规模合成预训练实现铰接物体（如抽屉、门）的零样本仿真到真实（Sim-to-Real）操作
  • 解决真实世界铰接物体操作演示数据收集成本高、效率低，且现有仿真数据缺乏部件级语义与铰接约束设计的问题
  • 搭建 SMART-Sim 仿真平台与分布式合成系统，构建包含超100万条轨迹的 SMART-Data 数据集，预训练VLA模型并验证其仿真到真实迁移与性能扩展能力
Card 03 核心贡献

核心贡献

  • 提出 SMART-Sim 仿真平台，提供面向铰接物体操作的专用设计，包括资产标注、动作生成、技能定义与领域随机化
  • 开发 智能体任务生成方法 与 分布式合成系统，构建 SMART-Data，覆盖5种机器人构型、23种物体类别、超100万条操作轨迹
  • 通过大量仿真与真实世界实验证明，在 SMART-Data 上预训练可提升VLA模型的下游任务表现，并实现零样本仿真到真实策略迁移
  • 验证合成数据在接触密集型铰接物体操作中作为可扩展监督信号的潜力
Card 04 方法描述

方法描述

  • 构建 SMART-Sim 仿真平台，引入铰接感知设计：对可动部件进行自动标注与动作帧提取，利用 cuRobo 与约束轨迹优化生成符合关节约束的稳定操作动作
  • 设计 智能体任务生成 流水线，通过统一任务规格与大语言模型将语言指令转换为可执行的技能程序与仿真配置
  • 实现 分布式数据合成系统，将轨迹收集、视觉渲染与数据集转换解耦，提升大规模数据生成效率
  • 采用 铰接感知的领域随机化，在空间、物理、视觉三方面对物体的不同部件、关节和材质进行独立随机化，增强数据多样性
Card 05 数据集与资源

数据集与资源

  • 主要数据集：SMART-Data，包含超过100万条轨迹、约5亿帧图像、超4600小时操作数据
  • 数据集覆盖 44 种原子任务类型、23 种操作技能、5 种机器人构型（单臂/双臂）和 2507 个铰接物体
  • 模型架构：基于 Qwen3-VL (4B) 与 扩散Transformer (DiT) 动作专家的VLA模型（SMART-VLA）
  • 训练资源：使用8块NVIDIA RTX 4090 GPU，每日可生成约144小时数据
Card 06 评估与结果

评估与结果

  • 在 LIBERO 与 RoboCasa365 仿真基准上进行行为克隆微调评测
  • 主要评估指标：任务成功率
  • 关键结果：在LIBERO上平均成功率96.8%，超过π₀(94.2%)等基线，并匹敌π₀.₅(96.9%)；在RoboCasa365上平均成功率28.8%，显著优于所有对比基线
  • 真实世界实验实现零样本仿真到真实迁移，并展现出随数据量增加的性能正缩放趋势
