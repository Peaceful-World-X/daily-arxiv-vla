Card 02 论文概述

论文概述

  • 提出 RoboPace，一种在推理时对动作块（Action Chunk）策略进行重定时的方法，旨在解决演示速度与机器人实际执行能力之间的“实施例差距（embodiment gap）”。
  • 核心问题是：机器人执行模仿学习策略时，在接触阶段需要低速保证可靠性，而在自由空间可以高速运行，但统一的全局速度缩放无法平衡这一矛盾。
  • 论文目标是在不改变策略模型和几何路径的前提下，仅通过调整执行时序，实现在预测接触区域减速、自由区域加速，同时满足机器人的运动学和动力学约束。
Card 03 核心贡献

核心贡献

  • 提出了一种接触感知的时间最优路径参数化（Contact-Aware TOPP）方法，将预测的接触信息转化为沿路径变化的速度约束，并与机器人的关节限制联合优化。
  • 设计了双通道接触预测门控机制，结合基于模型的几何邻近性检测和基于学习的腕部相机接触预测，互补地识别接触关键区域。
  • 开发了一套完整的在线执行与块间过渡方案，包括速度投影、路径混合和丢弃处理，确保连续动作块的无停顿衔接和实时性能。
  • 在实际双臂机器人上验证了方法，RoboPace 在保持高速运动的同时，成功率从基线的最佳 44% 提升至 64%，并在五个任务中的四个上将执行时间缩短约一半。
Card 04 方法描述

方法描述

  • 整体流程：将策略预测的动作块（End-Effector Pose Deltas）通过逆运动学转换为关节空间路径，标记接触关键路点，然后使用 TOPP-RA 求解器进行接触感知的时间最优重定时，最后将重定时后的轨迹输出给底层控制器。
  • 接触感知重定时：通过一个随路径变化的速度上限（Contact Speed Limit）来约束手爪速度。该上限在接触区域通过余弦渐变函数激活，将 Cartesian 速度限制转换为关节速度限制，并与机器人固有的关节速度、加速度限制一起纳入 TOPP 优化问题。
  • 接触预测：几何线索基于前向运动学和已知模型（桌子、另一只手）的距离阈值；学习线索使用 EfficientNet-B0 + GRU 从腕部相机和夹爪角度预测到接触的剩余步数（steps-to-contact）。最终路点只要满足任一条件即被标记为接触关键。
  • 在线块过渡：通过将新的重定时块的初始速度与当前块的命令速度进行投影并裁剪，实现无缝连接；新旧路径通过线性、余弦或双曲正切调度进行混合，以避免指令阶跃。
Card 05 数据集与资源

数据集与资源

  • 策略模型: 基于 π0.5 的 VLA 策略，使用 8,434 小时 YUBI 记录进行预训练，并在特定任务数据集上微调（例如 Cup/ Socks 使用 8,736 条，Pyramid 使用 5,288 条）。
  • 接触预测器: 使用 8,601 条从相同人类演示中采集的片段进行训练，模型参数量为 4.69M。
  • 硬件平台: 双臂 7-DoF OpenArm v1.0 机器人，配备 YUBI hands；策略推理和重定时运行在带 NVIDIA GeForce RTX 5070 Ti GPU 的工作站上。
Card 06 评估与结果

评估与结果

  • 评估环境: 在真实的双臂机器人上，针对 Cup（将杯子放在盘子上）、Socks（将袜子放入容器）和 Pyramid（堆叠三个杯子，分三个阶段）三个任务共五个命令进行评估。
  • 对比基线: 包括演示速度（30 Hz）、均匀加速（50 Hz）、均匀减速（10 Hz）以及无接触感知的 RACE-style 重定时。
  • 主要指标: 成功率（Success Rate）和任务完成时间（Task Time）。
  • 关键结果:

- RoboPace 总体成功率为 64%（32/50），显著优于演示速度（18/50）和均匀减速（44%，22/50）。

- 在四个任务上，RoboPace 的执行时间仅为均匀减速方案的 45%–59%，兼顾了可靠性与效率。

- 无接触感知的 RACE-style 重定时几乎全部失败（1/50），证明了接触门控的必要性。

- 接触预测器在接触发生时刻的平均绝对误差仅为 0.80 个源步长（约 0.027 秒），验证了其准确性。
