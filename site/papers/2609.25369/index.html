Card 03 核心贡献

核心贡献

  • 提出能力感知的仲裁策略，联合使用 语义意图置信度（α） 和 VLA 执行能力置信度（β） 来分配控制权限
  • 开发了集成了 VLM 置信度校准、贝叶斯意图滤波和在线 VLA 能力估计的 人-VLM-VLA 共享控制框架
  • 在 ID 和 OOD 条件下系统评估了 VLM/VLA 置信度及共享控制性能，并通过 12 名参与者 的人类受试者研究验证了方法的有效性
Card 04 方法描述

方法描述

  • VLM 语义意图推断与置信度校准：使用经过温度缩放的 VLM 计算候选指令的校准置信度，并通过 贝叶斯递归滤波 抑制意图预测的抖动，减少错误切换
  • VLA 在线能力置信度估计：从 VLA 生成的 多条随机动作轨迹 中计算轨迹离散度（D_t）和局部不稳定性（A_t），并映射为统一的能力置信度 β
  • 能力感知仲裁策略：将 α 与 β 的乘积通过 Sigmoid 函数 映射，并减去人-机命令不一致性（余弦相异度），实现平滑的非线性权限分配，缓解乘法衰减效应
Card 05 数据集与资源

数据集与资源

  • 训练数据：400 个分布内（ID）演示，包含拾放（pick-and-place）和双向堆叠（stacking）任务，按 episode 划分训练/验证/测试集
  • 模型：

- VLM：Moondream3，使用 rank-8 LoRA 微调

- VLA：SmolVLA，在相同数据集上微调（10k、20k、60k 步）

  • 硬件平台：6 关节 LeRobot SO-101 机械臂，顶视和腕视 RGB 相机，两个 Nintendo Switch Joy-Con 控制器
  • 训练资源：未明确说明 GPU 型号，但涉及 VLM 和 VLA 微调，异步能力采样的最小间隔为 0.3 秒
Card 06 评估与结果

评估与结果

  • 评估环境：包含 ID（方块）和 OOD（LEGO）的拾放与堆叠任务；12 名参与者的受试者内研究，共 192 次正式试验；每个试验限时 120 秒
  • 基线方法：Manual Teleoperation（无辅助）、Fixed 50/50（恒定均分控制权）、Semantic-Intent Only（仅用 α 进行自适应仲裁）
  • 评估指标：

- 任务性能：成功率、完成任务耗时

- 控制质量：轨迹平滑度（RMS 加加速度）、控制友好度（F）、权限加权不一致性（AWD）

- 主观评价：8 项改进的 USE 问卷（Q1-Q8）及 2 项 AI 理解能力评分（Q9-Q10）

  • 关键实验结果：

- 任务成功率：Sem-Cap 达到 92%（总体），显著高于 Manual (83%)、Semantic-Intent Only (44%) 和 Fixed 50/50 (10%)，在 OOD 条件下优势尤为明显（83% vs. 71%/25%/0%）

- 控制友好度：Sem-Cap (0.714) 显著优于 Semantic-Intent Only (0.462) 和 Fixed 50/50 (0.086)

- 权限加权不一致性：Sem-Cap (0.035) 显著低于 Semantic-Intent Only (0.274) 和 Fixed 50/50 (0.420)，表明其有效降低了人机意见相左时的机器人干预强度

- 主观评价：Sem-Cap 在仅用意图置信度的共享控制基线上有显著提升，但在部分体验项上仍低于纯粹的手动操作，显示出运动风格偏好匹配的改进空间
