Card 02 论文概述

论文概述

  • 将大语言模型中的线性表示假设（LRH）扩展到视觉-语言-动作（VLA）模型，解决VLA表示与物理系统动态耦合的核心挑战
  • 提出基于控制理论和路径签名（path signature）的数学框架，统一VLA的表示与策略，使得物理量的未来演化可以通过线性探针（linear probing）从表示中恢复
  • 证明通过线性转向（linear steering）可以在表示空间中沿线性路径单调改变期望的未来物理量，无需重新训练策略
Card 03 核心贡献

核心贡献

  • 提出VLA模型的控制论表述，将VLA定义为受控动态系统，并形式化其特有的探针与转向问题
  • 证明存在共享的线性表示，使得多个物理感兴趣量（QoI）在候选动作轨迹下的传播值均可通过表示空间的线性探针恢复
  • 引入签名广义线性模型（Signature GLM），将随机动作块策略参数化为签名指数族，利用其对偶平坦几何结构实现线性转向
  • 在平面控制仿形导航实验中构造显式 oracle 表示，并通过数值实验验证理论预测的线性探针与转向机制
Card 04 方法描述

方法描述

  • 将VLA建模为非线性控制仿形系统：$\dot{x}(t) = f_0(x(t)) + \sum_{i=1}^m f_i(x(t))u^i(t)$，其中物理状态$x$不可直接观测，VLA接收观测$o=h(x)$和语言指令$\ell$，输出内部表示$\lambda(x)$并生成动作轨迹$\mathbf{u}\sim\pi(\cdot\|\lambda(x))$
  • 定义感兴趣量（QoI）$\psi(x)$，通过Chen–Fliess级数展开构造动作轨迹的签名（signature）$S(\mathbf{u})$，并建立测量映射$\gamma_{\psi}(\mathbf{u}) = (L_\psi \circ S)(\mathbf{u})$
  • 证明存在表示$\lambda$和线性映射$L_{\psi}$，使得传播量$\psi(F_{\mathbf{u}}(x)) = \langle \lambda(x), \gamma_{\psi}(\mathbf{u}) \rangle_{\mathcal{H}_S}$，其中$\mathcal{H}_S$为完备化的希尔伯特签名空间
  • 将策略$\pi_\lambda$视为签名指数族，其自然参数空间具有对偶平坦统计流形结构；通过反向KL投影到常QoI超平面，推导出线性转向路径$\lambda_\alpha = \lambda(x) + \alpha \lambda_\psi(x)$
  • 证明在精确线性探针假设下，该路径上的期望传播QoI关于$\alpha$单调非减
Card 05 数据集与资源

数据集与资源

  • 本文为理论工作，主要结果为存在性证明与构造性算法，未使用大规模外部数据集训练模型
  • 数值验证部分采用合成平面控制仿形导航任务：状态空间$\mathbb{R}^3$（位置$p_x,p_y$与航向$\theta$），控制输入为前向速度$v$与角速度$\omega$，动作块在$K=8$个区间上分段常数
  • 实验参数：前向速度$s$在$[0.75, 1.25]$均匀采样，转向率$r$在$[-2.2, 2.2]$均匀采样，生成671个候选动作轨迹
  • 未涉及GPU/TPU训练资源，数值实验在控制系统的 oracle 构造上进行
Card 06 评估与结果

评估与结果

  • 评估环境：平面导航系统，起点$x_0=(0,0,0)$，目标点$p_{\text{goal}}=(1,0)$，设置圆形障碍物（中心$(0.5,0)$，半径$0.08$）以可视化侧向转向效果
  • 评估指标：传播QoI的线性探针精度（最大绝对误差$<\varepsilon$），以及线性转向路径上期望QoI的单调性
  • 关键结果：对于QoI $\psi(x)=p_y$（横向位置），Chen–Fliess展开恰好终止，仅需3个签名坐标（$\{\emptyset, 1, 21\}$）即可构造精确的 oracle 表示$\lambda_\psi(x) = [p_y, \theta, 1]^\top$
  • 通过可逆线性变换$M$构造与QoI不对齐的表示$\lambda(x)=M\lambda_\psi(x)$，验证了框架对坐标选择的鲁棒性
  • 数值实验确认：沿转向方向$\lambda_\psi(x)$的线性干预能够单调地改变策略生成的期望横向位置，验证了理论预测的线性探针与转向机制
