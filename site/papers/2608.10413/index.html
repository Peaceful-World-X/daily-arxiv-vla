Card 02 论文概述

论文概述

  • 提出 DriveVLA-M0，一种面向端到端自动驾驶的失败感知记忆增强 Vision-Language-Action (VLA) 框架，解决现有 VLA 模型在相似场景中重复犯错且无法利用历史失败经验的问题
  • 通过构建潜在记忆池存储失败案例的结构化场景表示（道路拓扑与动态交互）及专家轨迹标签，实现基于结构相似性的检索而非视觉-语言相似性检索
  • 在推理阶段通过轻量级解耦 LoRA 测试时训练 (TTT) 机制将检索到的失败案例知识注入 Action Decoder，实现场景特定的实时规划校正，且无需重新训练主干网络
Card 03 核心贡献

核心贡献

  • 提出面向 VLA 自动驾驶的失败感知记忆增强框架，显式针对基础模型表现不佳的场景进行记忆构建与检索
  • 设计结构 grounded 的检索机制，通过双分支架构解耦静态道路结构特征 (Map) 与动态交通参与者特征 (Agent)，并结合解耦 LoRA 测试时训练策略实现高效、有针对性的在线适应
  • 证明记忆检索与 TTT 的协同作用可在多个基准上显著提升鲁棒性、安全性和可扩展性，且支持通过记忆扩展实现训练无关的性能增益 (training-free scaling)
  • 在 NAVSimv1 (Navtest) 和 NAVSimv2 (Navhard) 上达到 SOTA 性能，且 TTT 反向传播延迟开销仅为 26.44 ms
Card 04 方法描述

方法描述

  • Base Model: 采用 InternVL3 作为 VLM 骨干网络，通过 Q-Former (N=16, D=256) 将 2800×1536 的语言特征压缩至 16×256；Action Decoder 包含 Trajectory Head（压缩自车状态并与语言特征解码生成 M 条轨迹候选）和 Score Head（评估 K 个安全子分数，包括碰撞率、可行驶区域合规性等）
  • Retrieve Model: 基于 DINOv2 + LoRA 构建双分支架构，Map 分支捕获静态道路结构，Agent 分支捕获动态交通上下文，通过二元交叉熵 (BCE) 损失监督占用栅格预测，实现结构解耦的场景表示
  • Memory Generation: 离线阶段使用 PDM oracle 评分器识别失败场景（Q(τ̂) < β），将检索键 (F_map, F_agent)、适应输入 (F_lang, F_ego, T̂) 及监督标签 (专家轨迹 τ, 轨迹簇分数 S) 存入潜在记忆池 M，并采用余弦相似度去重机制防止冗余
  • Inference with TTT: 在线阶段通过 Retrieve Model 提取当前场景的 Map 与 Agent 特征检索 Top-k 相似案例，基于余弦相似度的 Trigger 机制（阈值 λ）决定是否激活 TTT；采用解耦 LoRA 分别调整 Map（静态）与 Agent（动态）分支，实现模块特定的知识注入与路径感知的分数融合

数据集与资源

  • 数据集:

  • 模型规模与特征维度:

Card 06 评估与结果

评估与结果

  • 评估环境:

- Navtest (NAVSIMv1): 测试集包含多样化驾驶场景

- Navhard (NAVSIMv2): 高难度场景测试集

  • 主要评估指标:

- PDMS (Planning Driving Metric Score) 与 EPDMS (Enhanced PDMS): 综合规划指标

- NC (No Collision), DAC (Drivable Area Compliance), EP (Efficiency), TTC (Time to Collision), C (Comfort)

  • 关键实验结果:

- 在 Navtest 上达到 94.1 PDMS (DriveVLA-M0-Scale)，优于 Base 版本的 92.3 及当前 SOTA 方法（DriveSuprim 93.5, ELF-VLA 91.0）

- 在 Navhard 上达到 47.0 EPDMS，在碰撞避免和可行驶区域合规等安全关键指标上表现优异

- 消融实验验证了解耦检索机制、失败感知记忆构建以及 Decoupled LoRA TTT 各组件的有效性

- 框架可随记忆规模扩展持续提升性能，实现无需重新训练的无缝升级
