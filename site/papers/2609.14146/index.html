论文概述

  • 核心研究视觉-语言-动作模型（VLA）部署过程中推理延迟降低与闭环任务行为保留的权衡问题，聚焦SmolVLA模型在PyTorch与ONNX两种部署方案下的性能对比
  • 针对更快的VLA部署是否会导致闭环任务成功率下降、部署精度标志真实性、静态接口约束对任务表现的影响等实际工程问题开展系统性评估
  • 研究目标是证明VLA部署评估不能仅关注推理延迟或开环数值一致性，需要联合报告闭环成功率、导出图检查、接口约束等多维度指标
Card 03 核心贡献

核心贡献

  • 实证证明更快的ONNX Runtime CUDA Execution Provider (CUDA EP)部署配置无需保留LIBERO Spatial闭环任务成功率，但Object任务成功率保持相近（100集/套件主评估，seed 42）
  • 完成控制变量的16/24/32 token静态语言上下文宽度消融实验，证明静态语言上下文宽度是测试栈中Spatial任务成功率差距的重要贡献因素
  • 通过图级审计发现请求的INT8精度标志未实现实际转换：请求的INT8与FP16导出文件字节完全相同，均为无量化算子的FP32图，说明导出图实际精度不能仅依赖请求标志判断
  • 提供开环数值一致不保证闭环任务成功的实证，包括300集/套件配对rollout实验，以及开环余弦相似度~0.98但闭环成功率0%的早期适配器案例
Card 04 方法描述

方法描述

  • 采用HuggingFaceVLA/smolvla_libero checkpoint，结合MuJoCo 3.3.2仿真环境、LeRobot 0.6.1评估框架、tether 0.12.0导出工具开展实验
  • 设置PyTorch+AMP（自动混合精度）基线与ONNX Runtime CUDA EP部署方案两组核心对比，额外测试16/24/32 token静态语言上下文宽度的消融变体，固定检查点、tether版本、CUDA EP、硬件与评估协议
  • 测量指标覆盖系统性能（推理p50/p99延迟、进程级峰值显存）、开环行为（动作块余弦相似度、最大绝对误差）、闭环任务表现（LIBERO episode成功率），同时对ONNX导出图开展字节级审计验证实际精度
  • 创新点在于将部署的多个耦合因素（运行时、图转换、精度、接口宽度）进行部分解耦控制，突破传统仅关注开环数值或延迟的评估范式，聚焦闭环任务行为的保留性
Card 05 数据集与资源

数据集与资源

  • 使用机器人操作基准LIBERO的Spatial和Object两个任务套件，每个套件包含10个独立任务
  • 评估模型为SmolVLA，由SigLIP视觉塔、SmolLM2语言骨干、10步流匹配动作专家组成，输出7-DoF动作，默认静态语言上下文宽度为16 token
  • 评估硬件为NVIDIA RTX 2060 (6 GB, Turing架构)，无物理机器人、无边缘设备，全部在MuJoCo仿真环境下完成，相关代码与结果已开源至https://github.com/rafiqul713/smolvla-libero-onnx
Card 06 评估与结果

评估与结果

  • 评估环境为Linux工作站，搭载NVIDIA RTX 2060 (6 GB)，驱动535.309.01，固定seed为42，MuJoCo使用egl后端，所有ONNX推理使用CUDA Execution Provider
  • 核心评估指标：LIBERO闭环任务成功率（%）、推理p99/p50延迟（ms）、进程级峰值显存（MB，nvidia-smi测量）、开环动作余弦相似度、ONNX导出图字节一致性
  • 关键实验结果：

- PyTorch+AMP基线：Spatial成功率70.0%，Object成功率88.0%，p99延迟1181ms，峰值显存2208MB

- ONNX CUDA EP方案（默认宽度16）：p99延迟降至601ms（请求FP16）/532ms（请求INT8），约为基线的一半，但Spatial成功率骤降至41.0%/40.0%，Object成功率保持89.0%不变，ONNX峰值显存约为3.2GB

- 图审计证实请求的FP16与INT8导出文件字节完全相同，均为包含22514个节点的FP32图，无INT8量化算子，因此延迟差异无法归因于INT8量化

- 静态语言宽度消融实验显示，宽度提升至24时Spatial成功率恢复至75.0%，与PyTorch+AMP基线的70.0% Wilson 95%置信区间重叠；宽度32时Spatial成功率为71.0%，无额外增益，Object成功率与延迟均保持稳定

- 300集配对rollout实验复现了主评估的Spatial/Object差距模式：PyTorch Spatial 56.7% vs ONNX 33.0%，Object 73.3% vs 74.0%

- 开环数值一致性实验显示，即使动作块余弦相似度达到~0.98，早期错误适配器的闭环成功率仍为0%，证明开环一致不保证闭环任务表现一致
