Card 02 论文概述

论文概述

Card 03 核心贡献

核心贡献

  • 开发了基于 GMR（General Motion Retargeting） 的全身遥操作系统，将稀疏人体运动追踪转换为移动底盘和双臂的协调控制命令
  • 收集了一个包含 360度全景观察 的移动双臂操作数据集，涵盖 800个真实世界序列、约 5.5小时 演示，同步记录局部视图、腕部视图、本体感觉和全身动作
  • 提出了 PanoVLA，一种全景感知的VLA策略，通过全景专用编码器和全景专家模块实现任务条件的空间上下文融合，在四个真实世界任务中取得 91.3% 阶段完成率 和 73.4% 端到端成功率
Card 04 方法描述

方法描述

  • 遥操作与数据采集：使用VR头显和身体追踪器捕捉人体运动，通过SMPL重建和GMR优化映射到轮式双臂机器人，同步记录多视角图像和全景图像
  • PanoVLA架构：基于 π₀.₅ 的 Mixture-of-Transformers (MoT) 骨干，插入全景专家模块，采用 MTPano 作为全景编码器提取语义和几何特征，通过轻量级适配器生成全景令牌，并与VLM专家（处理局部视图、语言指令和本体状态）的KV缓存进行融合，最终由动作专家预测连续动作序列
  • 训练目标：使用条件流匹配（Conditional Flow Matching）最小化预测速度场与目标速度场之间的误差，动作专家根据联合上下文生成动作块
Card 05 数据集与资源

数据集与资源

  • 数据集：在四个真实世界任务（Move Pen、Move Block、Open Curtain、Wipe Table）上采集 800个演示序列，约 5.5小时，500K同步帧，包含局部相机、腕部相机、全景相机图像、本体感觉状态和全身动作
  • 模型规模：语言骨干为 Gemma-2B，视觉编码器为 SigLIP，全景专家参数量 100M，全景编码器为 MTPano
  • 训练资源：4块 NVIDIA A100 GPU，batch size 64，bfloat16精度，30K优化步数；推理使用单块 NVIDIA RTX 4090 GPU
Card 06 评估与结果

评估与结果

  • 评估环境：四个真实世界移动操作任务，每个任务15次闭环试验，评估指标为 阶段完成率（SCR） 和 端到端成功率（SR）
  • 主要结果：PanoVLA平均 SCR 91.3%，SR 73.4%，显著优于仅使用局部视图的π₀.₅基线（SCR 58.6%，SR 30.0%）
  • 消融实验：全景专家参数从50M提升至100M带来明显增益，继续增大效果饱和；使用 MTPano 编码器优于使用SigLIP（SCR 95.6% vs 75.6%），说明全景专用编码器对空间结构捕获至关重要
