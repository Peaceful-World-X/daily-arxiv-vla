Card 02 论文概述

论文概述

  • 针对冻结视觉语言动作（VLA）策略在重复操作、计数类任务中缺乏任务进度追踪能力的问题，现有基于操作尝试的记忆更新方式会将瞬时操作错误转化为持久任务状态错误，甚至性能劣于无进度记忆的方案
  • 提出 Achievement-Grounded Memory (AGM) 轻量级闭环框架，将任务表示为带进度指针的子目标序列，仅当前置子目标被物理证据验证通过后才更新进度，解决重复操作的视觉歧义与进度漂移问题
  • 在保持VLA策略完全冻结、无需测试时调用大模型推理的前提下，提升长程重复操作任务的成功率，同时验证框架在真实物理机器人上的可迁移性
Card 03 核心贡献

核心贡献

  • 识别了记忆增强冻结VLA智能体的关键失败模式：基于尝试的进度更新会将瞬时抓取、放置失败转化为持久任务状态错误，是现有记忆方案性能不足的核心原因
  • 提出AGM框架，以可观测的执行证据为依据更新紧凑的进度指针，支持子目标前进、当前状态保留、失败回滚三种状态转移，VLA策略、点追踪器、视觉编码器均保持冻结，仅需训练极小的验证头
  • 在RoboMME Counting基准的抓取相关任务上刷新state-of-the-art，四任务平均成功率达55.96%， surpass 最强记忆基线MemER 7.1个百分点，仅新增231M冻结参数、训练2.43M参数的验证头，参数效率显著优于基于4B外部VLM的基线
  • 在真实物理机器人上无需调整框架本身即可获得和仿真一致的性能增益，证明 Achievement-Grounded 的记忆更新方式是跨场景有效的
Card 04 方法描述

方法描述

  • 将任务指令解析为带类型标签（抓取、可逆放置、不可逆放置等）的有序子目标序列，配合进度指针构成紧凑任务记忆，仅当前置子目标完成才向冻结VLA策略提供对应子目标作为条件
  • 采用夹爪负载状态机检测交互事件（稳定抓取、负载释放、空载释放等），仅当事件与当前子目标类型兼容时触发验证，避免无意义的验证开销
  • 抓取验证采用冻结的CoTracker3点追踪模型，通过追踪抓取区域点的连贯向上运动，验证被操作物体是否随夹爪同步上升，无需额外训练即可提供运动学层面的成功证据
  • 放置验证采用冻结的SigLIP视觉-语言编码器，对比释放前后的前视图、腕部视图嵌入，结合子目标语言查询，验证目标物体-目标位置关系是否成立，提供语义层面的成功证据
  • 仅训练2.43M参数的多层感知机作为验证头，根据验证结果执行进度指针的前进、保留或回滚操作，实现“执行-验证-进度更新”的闭环控制

数据集与资源

Card 06 评估与结果

评估与结果

  • 评估环境与基准：仿真场景基于RoboMME Counting官方测试集，真实机器人场景采用自建物理实验平台；评估指标为任务成功率（单个episode成功需在1300步预算内完成 exactly 指令要求的操作次数，并按下停止按钮）
  • 关键实验结果：

- 仿真场景下AGM四任务平均成功率达55.96%，超过最强记忆基线MemER（48.83%）7.1个百分点，是冻结π₀.₅基线（28.78%）的近2倍；抓取相关的PickXTimes、BinFill任务分别达100.0%和84.0%，刷新该基准的state-of-the-art，且非抓取相关的SwingXTimes、StopCube任务与冻结基线性能完全匹配

- 重复深度分析显示，冻结π₀.₅在计数N=5时成功率跌至0%，AGM下PickXTimes全计数区间保持100%成功率，BinFill在N=5时仍有66.7%成功率，证明AGM完全解决了进度漂移问题

- 消融实验验证了设计合理性：仅用本体感知的抓取验证相比点追踪方案，BinFill成功率从84.0%降至78.0%；统一阈值相比可逆性感知阈值，BinFill成功率从84.0%降至74.0%，证明两种设计均能带来有效增益

- 真实机器人部署中，AGM下PickXTimes全计数区间达100.0%成功率，BinFill在N=2时达100.0%，N=5时达60.0%，性能趋势与仿真一致，证明框架在真实场景的有效性
