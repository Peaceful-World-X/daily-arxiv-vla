Card 03 核心贡献

核心贡献

  • 提出 SA-VLA 空间感知 RL 适应框架，将隐式空间表征与 2D 视觉 token 融合，并采用步骤级密集奖励，提升 flow-matching VLA 策略的鲁棒性
  • 提出 SCAN (空间条件退火噪声) 探索策略，将几何理解注入噪声驱动的策略探索，改善信用分配并保持空间一致性
  • 证明对齐空间表征、步骤级奖励和空间条件探索可实现稳定的 RL 微调，并在空间分布偏移下提升泛化能力
Card 04 方法描述

方法描述

  • 空间 Token 融合 (Spatial Token Fusion)：通过单向交叉注意力将视觉语义 token 与隐式空间 token 融合，使用可学习的通道门控机制调制空间贡献，并经过残差 MLP 细化，生成几何感知嵌入
  • 空间感知步骤级密集奖励 (Spatially-Aware Step-Level Dense Reward)：将操作过程分解为 Reach (接近目标)、Place (放置) 和 Leave (离开) 三个阶段，基于归一化几何距离的变化计算阶段一致的密集奖励信号
  • 空间条件退火噪声 (SCAN)：定义空间自适应随机过程，其中噪声尺度由学习到的空间条件噪声与退火最小下限共同决定，确保训练过程中始终存在探索同时保持几何一致性
Card 05 数据集与资源

数据集与资源

  • 使用 LIBERO 和 LIBERO-PLUS 数据集 (包含相机视角和初始状态系统扰动)
  • 基于预训练的 flow-matching VLA 策略 (π₀.₅)，冻结视觉-语言骨干网络
  • 使用 4 张 H800 GPU 训练，约 38.5 小时，全局批大小 1024，64 个并行环境
Card 06 评估与结果

评估与结果

  • 评估环境：LIBERO-PLUS 空间扰动子集，80 个并行环境，5 个非重复采样 epoch，2 个随机种子
  • 关键指标：零样本和少样本场景下的任务成功率 (Success Rate)
  • 空间 token 融合在零样本评估中实现 +2.25% 整体提升 (相机视角扰动 +3.83%，初始状态扰动 +0.52%)
  • 消融实验证实 SCAN、密集奖励 (DR) 和空间融合 (Fusion) 三者互补，完整模型达到 83.75% 少样本成功率
  • 密集奖励显著稳定 RL 优化动态，SCAN 进一步在有限空间覆盖下提升最终成功率
