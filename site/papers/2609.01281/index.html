Card 02 论文概述

论文概述

  • 提出 EmbodiedSkills，一个统一的框架，将 VLA 模型转化为闭环 VLA 代理，通过可执行技能协调感知、规划、执行、验证和恢复，解决长时程任务中缺乏统一执行检查和验证机制的问题。
  • 将每个技能决策视为一个执行提案，运行时检查其前提条件并验证执行结果，确保决策的物理有效性和可追溯性。
  • 建立共享的可执行技能接口，连接高层技能选择、有界低层 VLA 执行和后动作验证，使低层策略可替换而不影响主干循环。
Card 03 核心贡献

核心贡献

  • 技能导向的闭环 AgentLoop：提出六阶段（观察、规划、预检、执行、验证、恢复）的闭环循环，替代固定流水线，实现状态驱动的柔性决策。
  • 策略–运行时分离：通过共享技能契约，高层策略提出结构化技能决策，运行时强制执行前提条件、数据新鲜度、动作有效性和状态转换，使失败可诊断、轨迹可检查。
  • 模块化适配与跨基准验证：定义独立可训练和可替换的规划、验证、动作生成与环境交互接口，在 RoboTwin 2.0 和 LIBERO 上验证了任务适配的低层 VLA 策略性能。
Card 04 方法描述

方法描述

  • 六阶段 AgentLoop：运行时按顺序维护 Observe、Plan、Preflight、Execute、Verify、Recover 六个阶段，但允许证据驱动的阶段跳转，而非固定流水线。
  • 可执行技能契约：每个技能定义类型化输入/输出、前提条件、执行体、后置更新和失败处理，运行时守卫检查技能提议的合法性，确保只有条件满足的技能才被实际执行。
  • 有界动作执行：低层 VLA 策略接收当前子目标和观测，生成一个有限步长的动作块，执行后收集新证据，由验证器决定是否继续当前子目标或推进计划。
  • 验证与恢复：验证器基于执行后观测判断子目标是否完成，输出六种路由信号（推进、继续、重新观察、重新规划、恢复、完成），恢复阶段利用失败证据生成修正上下文。
  • 训练方式：采用组件级监督微调，高层 Qwen3-VL 调度器在部署一致的决策轨迹上训练，低层 π0.5 策略冻结，确保调度能力提升而不影响连续控制；同时支持可选的在线闭环策略优化。
Card 05 数据集与资源

数据集与资源

  • RoboTwin 2.0：50 个双机械臂操作任务，涵盖多种物体、配置和领域随机化场景。
  • LIBERO：四个套件（LIBERO-Spatial、LIBERO-Object、LIBERO-Goal、LIBERO-Long），评估空间、物体、目标和长时程泛化。
  • RMBench：四个记忆依赖任务，测试依赖历史交互的决策能力。
  • 模型规模：高层 VLM 使用 Qwen3-VL，低层 VLA 策略基于 OpenPI/π0.5（3B 参数量级），各部分均进行任务级微调。
  • 训练资源：论文未明确报告 GPU 类型和数量，仅提及对每个任务单独微调 π0.5 策略。
Card 06 评估与结果

评估与结果

  • 评估环境：RoboTwin 2.0 仿真环境，LIBERO 基准，RMBench 记忆任务。
  • 主要指标：任务成功率（宏平均）。
  • RoboTwin 2.0 结果：任务适配的 π0.5 策略在 50 个任务上平均成功率 86.20%，较 LingBot-VA 报告的 π0.5 基准 82.74% 提升 3.46 个百分点，在 Hanging Mug、Blocks Ranking Size 等任务上提升显著。
  • LIBERO 结果：四套件平均成功率 97.40%，略高于官方 OpenPI 参考的 96.85%。
  • RMBench 结果：相同执行方法在记忆依赖任务上仅达 12.5% 平均成功率，说明当前方案在需要长程记忆的任务上仍有挑战。
  • 消融实验：在 50 个 RoboTwin 2.0 任务上进行 AgentLoop 消融，比较有无语义子任务、中间验证和重复动作块的影响，但具体数值未在摘要中列出。
