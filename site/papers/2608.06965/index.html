Card 02 论文概述

论文概述

  • 研究场景相机视点变化对视觉-语言-动作（VLA）策略的影响，即使任务、物体、语言和机器人状态不变，相机移动也会导致策略失败
  • 目标是在不使用深度、点云、相机标定或几何输入的情况下，仅通过单张 RGB 场景图像、语言指令和本体感知，使基于流的 VLA 策略对相机视点具有鲁棒性
  • 提出跨视图动作一致性训练方法，利用同一物理状态在不同相机视角下的观测对，强制策略的动作流预测保持一致
Card 03 核心贡献

核心贡献

  • 提出跨视图动作流一致性目标，直接在动作流速度场上施加正则化，无需额外传感器、标定或相机特定输入，推理时保持单场景 RGB 接口
  • 设计动作等效视图对构建方法：在仿真中通过重置 MuJoCo 状态并重渲染，在真实机器人上通过同步多相机采集，保证同一状态不同视角共享相同动作标签
  • 通过相同数据的流匹配（FM-only）控制实验和打乱配对（shuffled-pair）控制实验，证明性能提升来自动作等效配对下的跨视图一致性，而非数据多样性或通用正则化
  • 在LIBERO-Plus 相机扰动基准和真实机器人 held-out 相机评估上验证有效性，分别提升+7.4pp 和从 53.3% 到 74.4% 的成功率
Card 04 方法描述

方法描述

  • 基于 flow matching 的 VLA 框架，策略预测动作空间中的速度场 \(v_\theta\)，通过积分生成连续动作块
  • 构建动作等效对：同一物理状态 \(s\) 下，名义相机 \(c_0\) 和扰动相机 \(c_p\) 分别渲染 \(o_0\) 和 \(o_p\)；共享语言 \(l\)、本体感受 \(q\) 和演示动作 \(a\)
  • 训练时对两个视图均进行标准流匹配监督，同时引入跨视图损失 \(\mathcal{L}_{\mathrm{CV}}\)，在相同采样的流坐标 \((t_k, \varepsilon_k)\) 上最小化两个视图预测速度的差异
  • 将目标分解为均值-残差形式，证明跨视图损失仅惩罚视图间不一致的残差分量，不改变对演示动作的拟合
  • 梯度通过两个分支双向传播；打乱配对控制用于验证动作等效的必要性
Card 05 数据集与资源

数据集与资源

  • 仿真训练数据：从 LIBERO 演示中重置 MuJoCo 状态，重渲染生成 338,575 个动作等效对（来自 libero_spatial, libero_object, libero_goal, libero_100），扰动相机分布遵循 LIBERO-Plus C1/C2/C3 类别
  • 仿真评估：使用 LIBERO-Plus 相机扰动基准，包含 1,599 个测试实例，分 C1、C2、C3 三类，每种子运行 4,797 次 rollout
  • 真实机器人数据：针对三个桌面任务（Pick & Place、Contact Rich、Dexterous Operation）采集同步多相机演示，每任务 10 次 rollout，评估 3 个训练相机和 3 个 held-out 相机
  • 模型：基于 \(\pi_{0.5}\) 预训练权重微调，训练 10,000 步，使用 \(K=2\) 流样本、\(\lambda_{\mathrm{CV}}=0.10\)、Beta(2,3) 流时间采样
  • 计算资源：6× NVIDIA RTX PRO 6000 Server Edition GPU；训练和评估均屏蔽腕部相机流
Card 06 评估与结果

评估与结果

  • 仿真主要结果：所提方法在 LIBERO-Plus 相机跟踪上达到 87.2±0.4%，比相同数据的 FM-only 控制（79.8±0.8%）提升 +7.4pp，比 naive mixed-camera SFT 提升 +12.5pp；名义相机 ID 性能保持 95.0±0.8%，且方差更低
  • 消融实验：打乱配对（shuffled-pair）使性能从 87.2% 崩溃至 25.8%，证明增益依赖于动作等效配对；停止梯度（stop-gradient）变体仅达到 84.3% 相机跟踪成功率
  • 真实机器人结果：held-out 相机场景下，所提方法聚合成功率为 74.4%（67/90），FM-only 为 53.3%（48/90），提升显著；尤其在视点变化最大的 Laptop lid 任务上实现几乎无损迁移（30/30）
  • 分析：跨视图一致性在视点变化更剧烈时增益更大；方法专注于动作流速度场，而非中间特征表示，附录中探索的特征级替代方案未能取得可靠提升
