Card 03 核心贡献

核心贡献

  • 提出 FailPatch 框架，在冻结的 VLA 策略的动作隐藏空间中，通过轻量级 Null 门控残差专家库（REB）进行失败驱动补丁
  • 设计统一 Preserve–Redirect–Trust 目标：保留可靠行为、重定向失败表征、限制干预幅度，无需解析失败轨迹的纠正动作
  • 仅使用 0.52% 可训练参数（约 17.3M）和约 3 小时训练，在仿真和真实任务上大幅提升成功率
  • 通过离线 VLM 标注器定位失败起点，构建局部成功原型，实现基于几何的监督
Card 04 方法描述

方法描述

  • 在 π₀.₅ VLA 模型的动作隐藏空间（均值池化后的表示）中插入 Null 门控残差专家库（8 个专家 + Null 路由）
  • 不对称监督：成功演示用于训练每个残差专家的动作候选损失，部署失败轨迹用于监督何时保留原策略或进行补丁（通过 VLM 标注的失败起点划分可靠/失败相关表示）
  • 行动接地学习：所有候选专家的动作损失加权（温度化 softmax）优化残差专家；路由器的演示部分使用停止梯度软目标
  • Preserve 目标：对可靠表示（ℋ⁺），鼓励选择 Null 路由并惩罚残差能量
  • Redirect 目标：对失败相关表示（ℋ⁻），通过计算候选到局部成功原型（k-NN 中位数）的进步与幅度正则化得到软目标，引导路由选择和最小推进边际
  • Trust 目标：约束被选的补丁幅度，防止过大偏移
  • 训练时评估所有路径避免离散路由反向传播；推理时使用 Top‑1 稀疏路由
Card 05 数据集与资源

数据集与资源

  • 仿真：四个长时程 RoboTwin 任务（Blocks Ranking, Stack Bowls, Put Object Cabinet, Place Bread Basket），使用 50 个演示和 100 个部署缓冲区
  • 真实世界：三个双机械臂任务（Blocks Ranking, Stack Bowls, Fold Dishcloth），采用 Intel RealSense D435i 相机，各 100 演示和 100 部署缓冲
  • 基础模型：π₀.₅ VLA（预训练于 50 个任务，697M 参数）
  • 训练硬件：4 块 NVIDIA H20 GPU，FailPatch 训练约 3 小时，其他方法（LoRA SFT、Full SFT 等）约 8–11 小时
Card 06 评估与结果

评估与结果

  • 仿真干净评估：FailPatch 平均成功率 60.50%，较 50-Task Base 提升 11.0 个百分点，优于所有监督和 PPO 基线，且效率优势显著（参数少 40 倍，训练快 6 倍以上）
  • 仿真干净到随机泛化：FailPatch 平均 37.50%，较 Base 提升 9.5 个百分点，在四个任务中均高或并列最高
  • 真实世界：FailPatch 平均 57.8%，较 Three-Task Base 提升 16.7 个百分点，覆盖刚体、接触丰富和可变形物体任务
  • 消融实验表明 Redirect 目标贡献最大，Preserve、Trust 共同作用；专家多样性必要；VLM 标注接近人类标注效果
  • 机理分析验证：动作隐藏空间线性可分离性强（平衡准确率 0.74，AUC 0.83）；路由在失败起点附近激活，补丁明显减小到成功原型的距离；残差专家学习到不同的干预方向
