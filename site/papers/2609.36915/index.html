Card 02 论文概述

论文概述

  • 解决了空中操作领域缺乏大规模、多样化训练数据的问题，以及依赖人工遥操作收集示范成本高、难以扩展的挑战

Card 03 核心贡献

核心贡献

  • 构建了首个结合大规模并行仿真、自动示范生成和轨迹级分析的空中VLA基准测试，支持负载感知飞行和操作控制
  • 通过结合专家规则和强化学习策略，实现了无需人类遥操作的可扩展示范生成，覆盖多种物体、环境和随机初始条件
  • 开发了自动事件标注和轨迹分类方案，用于细粒度分析任务进度、行为结果和安全相关失败，超越简单的成功率评估
  • 评估了多种模仿学习和VLA基线模型，揭示了其在空中操作任务中的性能特征和失败模式，为未来研究提供参考
Card 04 方法描述

方法描述

  • 基于 ManiSkill3 和 ReplicaCAD 构建 GPU 加速仿真框架，支持大规模并行物理模拟和渲染
  • 采用负载感知的级联飞行控制器，在抓取、运输和释放过程中补偿有效载荷变化，确保飞行稳定性
  • 使用特权混合专家自动生成示范，结合几何规划、规则控制和学习组件，利用仿真器提供的特权信息
  • 通过行为克隆和PPO强化学习训练技能策略，并将学习到的技能组合成长时序任务示范
  • 设计了事件驱动的标注协议，评估任务完成情况与空中操作特有的物理约束（如倾斜度、高度违规、载荷丢失等）
Card 05 数据集与资源

数据集与资源

  • 提供了超过 80,000 个示范，涵盖基本操作技能（抓取、放置）和长时序任务（导航+操作），涉及多种物体和环境
  • 模拟平台基于 X500 四旋翼，支持轻量级 1-DoF 夹爪和 3-DoF 机械臂两种配置，配备 UMI 风格指尖
  • 使用 GPU 加速的并行仿真环境进行数据收集和策略训练，具体 GPU 型号未明确提及
Card 06 评估与结果

评估与结果

  • 在四个任务设置上评估：TidyHouse、PrepareGroceries、PackageDelivery 和 LongHorizonRearrangement
  • 比较了四种策略：ACT、Diffusion Policy、π0 和 π0.5，覆盖视觉运动模仿学习和预训练 VLA 模型
  • 主要评估指标为任务成功率，并进行技能级和对象级的细粒度分析
  • 关键结果：π0.5 平均成功率最高（44.6%），其次是 π0（38.9%）、Diffusion Policy（33.9%）和 ACT（29.5%）；行为克隆高效复现专家行为，而 PPO 能发现更多样且更快的成功轨迹
