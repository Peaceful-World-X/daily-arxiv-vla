Card 02 论文概述

论文概述

  • 论文提出了 StairVLA，一种阶段感知的分层动作生成框架，用于视觉-语言-动作（VLA）模型
  • 观察到在扩散/流匹配动作生成过程中，不同去噪阶段自然呈现不同功能：早期阶段同时依赖语言指令和视觉观察建立粗粒度动作轨迹，后期阶段更注重当前视觉观察进行动作对齐
  • 基于这一洞察，将VLA动作生成分解为低频的高层意图轨迹生成和高频的低层观察条件细化，以降低推理成本并保持任务性能
Card 03 核心贡献

核心贡献

  • 揭示了生成式VLA动作形成中的阶段依赖性，表明任务相关动作结构逐步出现，多模态条件作用在去噪过程中不断演变
  • 引入 StairVLA 框架，使用部分去噪动作作为粗粒度长时程动作生成与局部细化之间的自然接口，替代传统外部设计的分层接口
  • 通过在两种VLA骨干网络、仿真基准和真实机器人任务上的验证，证明显著降低推理成本的同时保持了强劲的任务性能
Card 04 方法描述

方法描述

  • 高层意图轨迹生成：使用标准VLA架构进行早期去噪（提前终止，如γ=0.97），输出长时程部分去噪动作轨迹，并缓存供后续多步重用
  • 低层观察条件细化：引入轻量级细化器，使用当前视觉观察（SigLIP-B/16编码）、压缩的高层VLM令牌（自适应平均池化）和部分去噪动作片段作为条件，通过类GR00T的DiT结构完成后续细化
  • 训练时重构去噪路径：因高层输出可能与理想路径有偏差，细化器训练时基于高层输出和真值重构新的流向路径，确保训练与推理条件一致
  • 多频率推理与重用：高层VLA低频调用，生成的轨迹跨多个（M个）低层细化周期重用，摊销高层计算成本，同时保留高频闭环校正能力
Card 05 数据集与资源

数据集与资源

  • LIBERO（Spatial、Object、Goal、Long四个套件）
  • LIBERO-Plus（包含7类扰动的鲁棒性基准）
  • 真实世界数据集：Fruit25（25个水果操作任务）、PushBlock（物体推送任务）
  • 高层VLA骨干模型：Qwen3-VL-4B-Instruct 或 Qwen3-VL-2B-Instruct，采用GR00T风格或π风格动作头
  • 低层细化器参数：约30M，使用独立的 SigLIP-B/16 视觉编码器
  • 训练资源：8块 NVIDIA RTX A6000 GPU，bf16混合精度
  • 推理硬件：单块 NVIDIA A100 GPU（仿真）、NVIDIA RTX A4000（真实机器人）
Card 06 评估与结果

评估与结果

  • LIBERO基准：在GR00T骨干上平均成功率从96.5%提升到97.8%，推理延迟从115.0 ms降低到44.2 ms；在π骨干上成功率从97.8%提升到98.3%，延迟从183.3 ms降低到44.5 ms
  • LIBERO-Plus基准：在零样本迁移和微调设置下均取得竞争性表现，微调后平均成功率达到83.7%
  • 跨骨干泛化：StairVLA在GR00T和π两种VLA骨干上均带来一致的性能与效率增益
  • 消融实验：去除细化器导致性能大幅下降（平均-4.1%），添加观-条件细化器可恢复并提升性能，时间动作上下文进一步贡献增益
  • 真实机器人实验：在Fruit25和PushBlock任务上，同时实现了性能提升（高于基线0.8-7.5个百分点）和推理延迟降低（约3倍），并保持了运动平滑性
