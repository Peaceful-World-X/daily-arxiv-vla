Card 02 论文概述

论文概述

  • 聚焦自动驾驶领域Vision-Language-Action（VLA）模型的跨不同传感器配置（embodiments）零样本迁移问题，针对现有驾驶VLA多为单数据集训练、缺乏跨相机 rig 的几何迁移能力，且单纯增加训练数据不一定能提升性能的痛点展开研究
  • 提出BEV-Forcing辅助任务，通过引入专用BEV模型的占用图监督信号，引导VLA骨干网络学习统一的空间表征，在不增加推理成本的前提下提升模型的跨embodiment迁移能力
  • 系统研究了多数据集训练下驾驶VLA的性能变化规律，评估BEV-Forcing在不同训练数据规模下的效果，验证其作为几何感知正则项的有效性，为后续驾驶VLA技术评估提供参考
Card 03 核心贡献

核心贡献

  • 提出BEV-Forcing辅助任务：通过轻量级BEV头将专用BEV模型（SimpleBEV）输出的地面平面物体占用图作为监督信号，引导VLA骨干的图像特征编码空间信息，推理时可直接移除BEV头无额外开销，在训练embodiment较少时能同时提升同分布性能和零样本迁移性能
  • 提供多embodiment训练的系统性研究：在多个公开自动驾驶数据集上开展多数据集训练实验，揭示随着训练embodiment数量增加，BEV-Forcing的收益逐步降低的现象，证明数据多样性与BEV监督存在部分重叠的收益，指出现有技术的有效性评估需考虑数据规模的影响
  • 通过消融实验验证关键设计：证明低容量BEV头（仅交叉注意力层）比高容量BEV头效果更好，且BEV-Forcing可与数据增强、相机参数输入等鲁棒性技术互补，进一步提升零样本迁移性能
Card 04 方法描述

方法描述

  • 基础方案：基于开源Qwen 3.5 2B VLM作为骨干，采用LoRA（秩16）微调避免灾难性遗忘，动作表示采用1Hz的2D轨迹航点文本形式，贴近VLM原始预训练任务，减少语言能力退化
  • 核心创新BEV-Forcing：在VLM指定中间层提取图像特征，经MLP投影后，通过仅包含交叉注意力层的低容量BEV头生成BEV占用图预测，以SimpleBEV输出的占用图作为监督标签，将BEV二元交叉熵损失与下一 token 预测（NTP）损失加权求和作为总损失
  • 设计逻辑：通过限制BEV头的容量，强制VLM的图像特征本身编码足够的空间信息以支撑BEV预测，从而将空间感知能力迁移到规划任务中，推理时无需保留BEV头，无额外计算成本
  • 多任务适配：统一不同数据集的输入输出格式，支持规划任务与VQA任务的联合训练，通过 linguistic 监督保持模型的语义推理能力
Card 05 数据集与资源

数据集与资源

  • 使用数据集：规划任务采用WOD-E2E、NAVSIM、nuScenes、Physical AI（取6000个片段，5k训练1k验证，用于零样本评估）；VQA任务采用nuScenes-QA；零样本额外评估采用KIT LongTail Dataset
  • 模型规模：基于Qwen 3.5 2B VLM，仅微调LoRA参数（秩16），BEV头为轻量级交叉注意力结构，参数量极小
  • 训练资源：使用4张A100 GPU，全局batch size为64，训练1个epoch，学习率为1e-4，采用余弦衰减策略
Card 06 评估与结果

评估与结果

  • 评估场景：涵盖同分布评估（WOD-E2E验证/测试集）和跨embodiment零样本迁移评估（Physical AI-1k验证集、KITScenes LongTail测试集）
  • 评估指标：规划任务采用ADE（平均位移误差，越低越好）、FDE（最终位移误差，越低越好）、RFS（人工评分反馈分数，越高越好）、MMS（多 maneuver 分数，越高越好）；VQA任务采用准确率
  • 关键实验结果：

- 少embodiment训练时BEV-Forcing收益显著：仅用WOD-E2E训练时，BEV-Forcing使ADE降低10.1%，KITScenes LongTail的MMS从3.90提升至4.64；加入NAVSIM、nuScenes-QA后，BEV-Forcing的收益逐步降低，证明数据多样性与BEV监督存在收益重叠

- 零样本迁移性能超越强基线：仅用WOD-E2E+NAVSIM训练并加入BEV-Forcing的模型，在KITScenes LongTail测试集上MMS达5.15，超过Gemini 3 Pro（4.61）、Alpamayo 1.5（4.31）等现有方法

- 与鲁棒性技术互补：BEV-Forcing与数据增强、相机参数输入等技术结合时，能进一步提升零样本迁移性能，而单独使用这些技术无显著收益

- 低容量BEV头设计更优：仅用交叉注意力的BEV头比全Transformer BEV头的同分布和零样本性能都更好，证明强制图像特征编码空间信息比提升BEV头容量更有效
