Card 02 论文概述

论文概述

  • 论文提出名为INSPO的推理时安全策略引导框架，解决预训练单步生成式机器人策略在部署时适配未见约束（如避障、末端执行器姿态保持）的难题：现有推理时引导方法（如梯度引导）计算成本高、无法保证约束满足，且不适用于无中间生成过程的单步策略。
  • 核心思路是将单步生成策略的推理时引导转化为噪声空间的轨迹优化问题，通过优化策略的输入噪声生成满足约束的动作，同时保持策略学习到的行为分布，实现实时控制下的安全适配。
  • 研究目标是让预训练单步生成策略无需重新训练，即可在部署时满足新的安全与物理约束，同时保持较低推理延迟，适配高频闭环控制需求。
Card 03 核心贡献

核心贡献

  • 首次将单步生成策略的推理时 steering 形式化为噪声空间轨迹优化问题，通过优化输入噪声而非直接修改动作，在满足部署时约束的同时，保证生成动作仍处于策略学习的行为分布内。
  • 设计包含约束惩罚项与噪声正则项的无约束优化目标，其中噪声正则项基于高斯环形定理，鼓励优化后的噪声符合策略原始输入分布，避免偏离预训练策略的可行行为空间。
  • 提出基于粒子优化的在线求解算法，结合滚动时域执行框架与粒子热启动机制，利用单步策略的单次前向传播特性，实现低延迟的在线重规划。
  • 在接触丰富的 Push-T 避障、Can 抓取放置、通用 VLA 策略引导、真实世界 lifting 任务上验证方法有效性，证明其优于 best-of-N 采样、动作投影、梯度引导等基线方法。
Card 04 方法描述

方法描述

  • 技术路径：固定机器人观测历史，将单步生成策略的输入噪声作为优化变量，每个噪声样本经单步策略前向传播生成动作块，再通过机器人动力学 rollout 得到状态序列，基于状态序列评估任务约束与目标，通过反向传播计算优化目标对噪声的梯度，更新噪声样本。
  • 创新点与关键技术：

- 噪声空间优化的特性：无需修改预训练策略权重，避免直接修改动作导致的接触行为破坏，保证生成动作的合理性；

- 噪声正则化设计：基于高斯环形定理设计的正则项，约束优化后的噪声位于原始高斯分布的典型区域，避免生成离群动作；

- 高效求解机制：采用粒子优化支持并行评估，结合滚动时域框架可在执行动作块满足约束时提前终止优化，再配合跨控制步的粒子热启动机制，进一步提升在线规划效率。

Card 05 数据集与资源

数据集与资源

  • 使用的任务环境与数据集：Push-T 2D推方块任务、Robomimic Can 抓取放置任务、LIBERO-Spatial 视觉语言动作基准、真实世界lifting任务。
  • 模型规模：底层采用Drifting单步生成策略（适配任意可微的单步生成策略），通用VLA实验使用π₀.₅视觉语言动作模型。
  • 训练与评估资源：实验设备搭载 AMD Ryzen Threadripper PRO 5965WX CPU 与 NVIDIA RTX 4090 GPU，实现基于公开的 Drifting Policy 与 Drift-VLA 代码库开发。
Card 06 评估与结果

评估与结果

  • 评估环境：覆盖仿真交互环境（Push-T、Can、LIBERO-Spatial）与真实 Franka Panda 机器人平台。
  • 主要评估指标：任务成功率（SR）/任务得分、约束违反率（CR%）、单步控制平均耗时、每回合平均约束违反步数。
  • 关键实验结果：

- Push-T 避障任务中，INSPO 在状态与图像观测模态下均取得最高任务得分，约束违反率降至0，推理耗时低于 NFE=10 的梯度引导方法；

- Can 抓取放置任务中，INSPO 在任务成功率、约束满足率与推理效率上取得最佳平衡，约束违反率接近0，优于需要100步扩散的梯度引导基线；

- LIBERO-Spatial 任务中，INSPO 在通用VLA策略上同样表现出色，证明方法可扩展到大规模预训练通用策略；

- 真实世界 lifting 任务验证了方法在实际机器人部署中的可行性。
