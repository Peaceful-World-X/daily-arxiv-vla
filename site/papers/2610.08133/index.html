Card 02 论文概述

论文概述

  • 提出 VLA-ACL（动作一致性学习），一种面向 Vision-Language-Action（VLA）模型的视觉 Token 剪枝框架，旨在降低计算开销并加速推理。
  • 核心思想是通过训练一个轻量级 Patch 打分网络，使从剪枝后的视觉上下文产生的动作与完整上下文产生的教师动作保持一致，从而直接优化剪枝对下游控制的影响。
  • 解决现有方法依赖间接启发式或需要昂贵微调的问题，在保持基础 VLA 模型完全冻结的情况下实现高效剪枝。
Card 03 核心贡献

核心贡献

  • 提出基于动作一致性的视觉 Token 选择学习范式，将 Token 剪枝直接与下游控制输出联系起来，优于基于注意力等间接启发式方法。
  • 设计了一种可微分的软 Top-K 剪枝门控机制，结合黑图嵌入和分数退火，使训练时的软剪枝能够逼近推理时的硬剪枝，确保梯度有效传播。
  • 实现仅需数小时的单 GPU 训练即可获得剪枝策略，无需微调基础 VLA 模型，与现有推理加速技术（如 FlashAttention）完全兼容。
  • 在 LIBERO 仿真和真实世界操作任务上取得优异结果，可剪枝 87.5% 的视觉 Token，降低 75% FLOPs 和 ～1.5× 推理加速，同时保持竞争性成功率。
Card 04 方法描述

方法描述

  • 训练一个 5 层双向 Transformer 作为 Patch 打分器，从视觉编码器输出的每个视觉 Token 产生重要性分数。
  • 训练阶段：使用可微分的软 Top-K 算子将 logits 映射为软选择分数，并通过黑图嵌入门控（原始嵌入与黑图嵌入按分数混合）产生软剪枝视觉嵌入；保持 VLA 模型冻结，计算软剪枝动作与全上下文教师动作以及真实动作之间的 L1 损失，梯度反向传播以更新打分器。
  • 推理阶段：直接根据硬 Top-K 保留每个相机视图的最高分 K 个 Token，并将其送入语言 Backbone 预测动作，被丢弃的 Token 不参与计算。
  • 关键创新：动作级别的监督信号、软硬剪枝之间的有效桥接、以及保持模型冻结的低成本训练。
Card 05 数据集与资源

数据集与资源

  • 数据集：LIBERO 仿真基准（Spatial, Object, Goal, Long 四个套件）；真实世界 ALOHA 式双臂操作任务（4 个任务，每个任务 50-100 个演示）。
  • 模型 Backbone：OpenVLA-OFT 和 π₀.₅。
  • 训练资源：单张 NVIDIA A100 GPU，训练约 5000 步，仅需数小时。
  • Patch 打分器参数量很小，主干模型完全冻结。
Card 06 评估与结果

评估与结果

  • 评估环境：LIBERO 各套件成功率（1500 集/套件），真实世界任务成功率（每任务 40 或 20 次试验）；计算量（TFLOPs）和延迟（ms）采用 VLA-Cache 的测量协议。
  • 主要指标：任务成功率、LLM 部分的 TFLOPs 和推理延迟。
  • 关键结果：

- K=32（剪枝 87.5%）时，LIBERO 平均成功率仅下降 1.4%（96.8%→95.4%），FLOPs 降低 75%，延迟从 63.49ms 降至 42.30ms（1.5× 加速）。

- K=64（剪枝 75%）时，LIBERO 平均成功率略高于基线（97.0% vs 96.8%），FLOPs 降低 65%，延迟降至 46.82ms。

- 真实世界任务中，VLA-ACL（K=64）平均成功率接近基线（72.5% vs 73.75%），FLOPs 降低 52.8%，延迟从 91.5ms 降至 62.1ms（约 1.5× 加速）。

- 在 π₀.₅ 骨干上同样有效，平均成功率 96.1%（仅降 0.8%），FLOPs 减少 67%，展现出跨模型的通用性。
