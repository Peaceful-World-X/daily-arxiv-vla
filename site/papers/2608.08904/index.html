Card 02 论文概述

论文概述

  • 研究视觉-语言模型（VLM）在进行动作后训练成为视觉-语言-动作模型（VLA）后，其空间理解能力（尤其是深度感知）的可解码性损失程度与位置
  • 通过层间深度探测比较权重匹配的 Molmo2-ER (VLM) 与 MolmoAct2-LIBERO (VLA)，发现 VLA 在所有层深度解码能力均低于 VLM（“地板”），且在最后几层 VLM 恢复而 VLA 崩溃（“悬崖”）
  • 旨在定位并解释动作后训练引起的后期层深度解码能力下降的具体机制
Card 03 核心贡献

核心贡献

  • 首次对权重匹配的 VLM/VLA 对进行逐层深度感知探测，揭示持久性差距（floor）和后期层崩溃（cliff）现象
  • 通过因果消融实验，将后期层深度解码能力崩溃定位到 VLA 的后期 MLP 写入，删除这些写入可以恢复大部分下降
  • 通过模块级分解，发现基础 VLM 的深度信息主要存储在累积的 MLP 写入中，而动作后训练在后期层破坏该通路
  • 为 VLA 表示退化提供了机制性解释，区分了持续层间差距与局部后期层崩溃，并给出了因果证据
Card 04 方法描述

方法描述

  • 使用 Dense Prediction Transformer (DPT) 探针，在每一解码层读出视觉 token 的隐藏状态，以 Depth-Anything-3 为教师进行深度预测训练
  • 采用因果消融，逐窗口删除 MLP 或注意力模块的写入，测量最终层深度解码变化，对比两个模型
  • 分解分析：分别探测残差流和累积 MLP 写入，并用线性脊回归验证，揭示深度信息存储位置及动作训练的影响
Card 05 数据集与资源

数据集与资源

  • 数据集：LIBERO 机器人操作帧，采样步长 5，图像尺寸 256，包含主视图和腕部视图
  • 模型：Molmo2-ER（基础 VLM）和 MolmoAct2-LIBERO（VLA），共享 36 层解码器，隐藏维度 2560，视觉编码器为 SigLIP2
  • 探针：DPT 头，参数量 41.8M，训练使用 AdamW，学习率 5e-4，批量大小 8，训练 20 轮
  • 训练资源：未明确说明 GPU 类型，但基于开源模型和探针规模，一般可在单 GPU 或多 GPU 上完成
Card 06 评估与结果

评估与结果

  • 评估环境：在 LIBERO 帧上，按 rollout 划分训练/验证集（25% 验证），使用最佳验证集指标
  • 主要指标：深度预测准确度 d1（阈值 1.25 的像素比例），同时报告 RMSE 和线性脊回归的 SNR
  • 关键结果：

- VLA 在所有 36 层 d1 均低于 VLM，平均差距 0.04–0.25，形成“地板”现象

- 在最后 7 层，VLM 的 d1 从 0.712 升至 0.752，而 VLA 从 0.629 降至 0.506，形成“悬崖”

- 消融 VLA 最后三层 MLP 写入后，d1 从 0.506 恢复至 0.584，恢复大部分晚期下降，而注意力消融或 VLM 相同操作无此效果

- 基础 VLM 的累积 MLP 写入 d1 高达 0.80–0.84，远高于残差流，VLA 的后期 MLP 写入 d1 从 0.68 崩溃至 0.38，线性 SNR 也趋近于零
