Card 02 论文概述

论文概述

  • 提出 GigaBrain-0.7，一个面向通用具身智能体的基础模型系统，旨在解决当前VLA模型在架构设计、大规模异构数据扩展及跨任务/跨具身泛化方面的核心挑战
  • 采用三系统架构（System 1动作控制、System 2理解规划、System 3预测评估）统一视觉语言理解、世界预测与连续动作生成
  • 在超过37,000小时的异构具身轨迹数据与约2.7亿视觉语言样本上进行预训练，覆盖16种机器人形态，实现跨家庭与工业场景的强泛化能力
Card 03 核心贡献

核心贡献

  • 提出单阶段多具身VLA预训练框架，在统一阶段联合优化视觉语言理解、层次化任务预测、离散动作表示与连续动作生成，消除多阶段训练的优化碎片化
  • 设计System 3（预测与评估）：基于世界模型预测未来子目标图像并估计任务进度价值，为策略学习提供前瞻性条件信号与评估反馈
  • 引入软知识绝缘（Soft Knowledge Insulation, Soft KI）机制，通过衰减而非完全阻断动作梯度回传，在保持VLM通用视觉语言能力的同时促进具身控制适配
  • 建立统一具身轨迹处理流程，实现多源异构机器人数据的格式转换、跨具身状态动作归一化、LLM辅助语言指令重写与多阶段质量控制
  • 构建经验增强强化学习 pipeline，结合离线人类干预数据学习、离线经验强化与在线人类纠正强化，实现策略的持续闭环改进
Card 04 方法描述

方法描述

  • System 1（动作与控制）：以 PaliGemma2 (3B) 为视觉语言骨干，搭配 Action Expert (0.5B)，采用混合专家Transformer（MoT）架构；视觉语言流使用因果自注意力，动作专家流通过联合注意力双向访问视觉语言上下文；支持离散（NTP）与连续（流匹配）双动作路径；引入时序空间块（Temporal-Spatial Blocks）编码短期视觉记忆
  • System 2（理解与规划）：基于PaliGemma2 (3B)，通过链式思维（CoT）推理当前场景语义，将长程语言指令分解为可执行的子任务指令
  • System 3（预测与评估）：基于 GigaWorld-1 构建世界价值模型（5B），在接收当前观测、本体感受状态与子任务描述后，预测与子任务时间跨度对齐的未来视频序列（提取最后一帧作为子目标图像），并估计任务进度价值；价值信号被二值化为优势条件注入System 1
  • 四阶段训练流程：(1) Systems 1&2联合预训练；(2) System 3世界模型预训练（机器人中心视频预训练→价值学习）；(3) 世界模型驱动的VLA后训练（子目标图像条件+价值派生条件+条件dropout）；(4) 经验驱动强化学习（离线优势加权回归→在线Actor-Critic微调）
Card 05 数据集与资源

数据集与资源

  • 具身轨迹数据：清洗后共 37,256.98小时，包括真实机器人数据（20,535.65小时，16种形态，1,810,101集）、UMI演示数据（8,251.83小时）、EGO人类第一视角数据（2,862.36小时）、物理仿真数据（1,453.92小时）与世界模型生成数据（4,153.22小时）
  • 视觉语言数据：271,976,674个图像-文本/问答样本，覆盖图像描述、通用VQA、空间关系推理、区域定位、 affordance理解与机器人任务理解
  • 代表性机器人平台：Maker H01、Maker M01、Agibot-G1/G2、AgileX PiPER/PiPER-X、Galaxea R1 Lite、Franka、UR5、Realman RMC-AIDA-L等
  • 模型规模：System 1/2合计约3.5B参数（PaliGemma2 3B + Action Expert 0.5B），System 3世界价值模型约5B参数
  • 训练数据格式：统一转换为 LeRobot v3.0 格式，支持episode/frame/observation/action/语言指令标准化字段
Card 06 评估与结果

评估与结果

  • 评估环境：真实机器人平台（AgileX PiPER/PiPER-X、自研Maker H01）；仿真基准（RoboTwin 2.0、EBench、RoboColiseum）；多模态理解基准
  • 对比基线：前代GigaBrain-0、GigaBrain-0.5M\*，以及π₀.₅等主流VLA模型（经任务特定后训练）
  • 评估维度：基础零样本能力、语言条件指令遵循、后训练任务成功率、分布外泛化、长程操作、System 3预测与评估消融
  • 关键结果：在基础零样本能力、语言条件指令遵循与后训练任务成功率上较GigaBrain-0系列与π₀.₅取得显著提升；数据规模扩展实验显示预训练数据增大持续降低验证损失并提升真实机器人行为可靠性；System 3消融验证了未来状态预测与价值评估信号对策略的互补作用；在家庭与工业场景中表现出强任务适应性与跨具身泛化能力
