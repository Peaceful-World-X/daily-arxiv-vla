Card 02 论文概述

论文概述

  • 提出 World Action Planner (WAP)，一个结合视觉语言模型（VLM）推理能力与动作条件世界模型物理 grounding 的机器人规划系统
  • 解决端到端模仿学习策略（如 VLA、WAM）在新场景、新任务上泛化失败的问题：组合长程任务中停滞、过拟合训练集物体坐标等
  • 核心思路：VLM agent 提出初始动作方案，通过世界模型的想象 rollout 进行迭代优化与搜索，实现测试时对新任务的泛化
Card 03 核心贡献

核心贡献

  • 提出 pose-image conditioned（位姿图像条件） 机器人世界模型：通过前向动力学预计算机器人关节位置并渲染为骨架图像作为条件，在新动作、新场景及跨机器人泛化上显著优于低维动作向量条件方法
  • 提供 理论分析：在 tabular 设置与线性函数逼近下证明基于模型的规划在多任务泛化上优于模仿学习（模型方法达到 Õ(1/√K) 次优差距，而模仿学习存在 Ω(\|C\|/K) 下界）
  • 提出 World Action Planner 系统：编排 VLM agent 与世界模型，实现系统化的动作提议、全局优化与局部搜索
  • 在组合任务、新布局、零样本泛化场景中大幅超越 π0.5、cosmos-policy、SAILOR、GPC-RANK 等 SOTA 基线
Card 04 方法描述

方法描述

  • 位姿图像条件世界模型：将动作经前向动力学转为关节位置并渲染为位姿骨架图像，用视频模型的 VAE 编码后与视频 token 拼接；采用第三人称+腕部视角的 2×2 多视角网格；基于 diffusion-forcing 与 flow-matching 目标训练，历史帧加独立噪声、未来帧加统一噪声、位姿图像不加噪
  • Agent Action Proposal：VLM 生成 MOVE、ROTATE、GRASP、RELEASE 等原子动作，通过多视角 2D 像素坐标三角化得到 3D 目标位置，由低层控制器转为机器人动作
  • Global Optimization：想象动作轨迹后由 VLM 评估安全性与目标对齐性，并给出语义反馈（如抬高避免碰撞）迭代修正动作
  • Local Search with Agent Ranking：网格搜索候选动作，利用世界模型想象各候选 rollout，由 VLM 排序选出最优；结合扩散策略完成精细抓取
  • Policies as Tools：将扩散策略、VLA、WAM 等模仿学习策略作为模块化工具，在分布内任务直接调用，OOD 场景用完整规划系统合成新动作
Card 05 数据集与资源

数据集与资源

  • 数据集：LIBERO（LIBERO-90、LIBERO-Long、LIBERO-Spatial、LIBERO-Object）、Robocasa、MimicGen、DexMimicGen、Robosuite
  • 世界模型骨干：Wan-T2V-1.3B，微调 10K 步，全局 batch size 64（基线训练 20K 步以保证公平对比）
  • 输入设置：21 帧历史（7 FPS）预测 20 帧未来（20 FPS），4 相机视角拼接 2×2 网格（每视角 224px），推理使用 20 步扩散采样
  • VLM agent：Gemini 3.0 Flash
  • 训练数据：每任务 100 条轨迹（含 MPPI 高斯噪声扰动版本）；新布局实验中每任务仅用 5 条专家演示（基线用 40+ 条）
Card 06 评估与结果

评估与结果

  • 世界模型评估指标：PSNR↑ / LPIPS↓，在 LIBERO-90、DexMimicGen 等数据集上与 WPE、IRA-Sim、Ctrl-World 对比
  • 世界模型性能：分布内预测平均提升 11.4%，泛化设置平均提升 16.8%；跨形态训练（动作维度 7/12/14/24）优于统一动作空间、形态感知编码器、软提示方法
  • 规划评估：12 个任务，每任务 50 次试验测量成功率
  • 组合任务泛化（LIBERO-Long）：WAP 成功率 68–78%，而 π0.5 仅 0–4%、cosmos-policy 为 0%；VLA 模型在首个子任务完成后停滞
  • 新布局泛化（LIBERO-Object 改变物体位置）：WAP 成功率 66–90%，显著优于 vision-language planner（16–64%）及各模仿学习基线（多为 0%），且仅用 5 条演示训练
  • 零样本泛化：在 LIBERO-10、LIBERO-Spatial 零样本及 Sawyer/IIWA/UR5e 少样本迁移中均展现优越泛化能力
