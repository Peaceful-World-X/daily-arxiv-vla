Card 02 论文概述

论文概述

  • 针对现有长期机器人操作系统中任务记忆归属模糊、多工具系统性能归因困难、语言接口不精确导致动作模型能力被低估的问题，提出2AM框架，通过 deliberately constrained 的设计（更少的工具宽度、更高的接口带宽）隔离上述变量
  • 框架将持久任务记忆完全保留在多模态Agent侧，仅使用单一RGB输入、无 episode 状态的动作模型执行所有任务相关运动，明确两者的职责边界
  • 设计组合式 steer 接口，将Agent记忆中的物理意图转化为子任务语言配合可选的2D抓取、放置、移动提示，在不传递完整交互历史的前提下指导动作模型完成长期操作任务
Card 03 核心贡献

核心贡献

  • 提出仅RGB输入的智能体系统设定，将任务记忆完全保留在Agent侧，所有任务相关运动由单一无 episode 状态的动作模型执行，实现记忆与控制的清晰边界隔离
  • 设计组合式 steer 接口，将Agent的记忆意图转化为带2D grounding的抓取、放置、移动提示，分别绑定不同时间尺度的物理参数，支持字段的独立缺失而不影响整体指令有效性
  • 提出无需教师模型的演示监督恢复方法，通过结构化提示丢弃、空间噪声、时间抖动对动作模型进行训练，使其能容忍Agent输出的遗漏、定位误差和时间偏差
  • 在LIBERO-Mem基准上验证了该设计的有效性，证明任务记忆可以完全保留在Agent侧，通过精确的 steer 接口即可驱动动作模型完成长期操作
Card 04 方法描述

方法描述

  • 采用双模型分解架构：Agent模型整合交互历史H_k、当前任务指令g和 agent 视角RGB，输出组合式 steer 指令c_k；动作模型仅接收当前 agent 视角RGB、手腕RGB、机器人状态和c_k，预测16步绝对末端执行器动作，无任务历史输入，实现 episode 级无状态
  • 训练阶段从演示数据中自动恢复监督标签，无需额外教师模型：通过演示的阶段标签、物体框/掩码、接触点、物体运动和投影机器人轨迹，生成子任务语言、抓取/放置目标的归一化2D坐标、移动目标的10-20步未来窗口坐标
  • 引入三类训练增强提升接口鲁棒性：约束式提示丢弃（保证至少保留一个指令字段，各字段可独立缺失）、坐标高斯噪声、移动提示的未来时间窗口采样，使用流匹配目标训练基于Qwen3-VL-4B骨干的动作模型
  • 推理阶段采用闭环执行：每执行完一个动作块，Agent观察新的RGB更新交互历史，重新生成 steer 指令，无需额外的 benchmark 状态或完成判断模块

数据集与资源

Card 06 评估与结果

评估与结果

  • 评估环境：LIBERO-Mem模拟基准，对比基线包括已发布的π₀、SlotVLA、SlotSSM，以及自研对齐复现的π₀（同骨干、同输入、同16步动作块长度，无 steer 接口），同时设置仅保留子任务语言的语言-only消融实验
  • 评估指标：严格成功率（Strict SR，要求完整按顺序完成任务且无多余重复）、宽松成功率（Relaxed SR，忽略任务超出的重复）、子目标完成率（Completion，衡量有序子目标的完成比例）
  • 关键实验结果：2AM平均完成率达76.3%，比最强已报告基线SlotSSM的14.8%提升61.5个百分点；比对齐复现的π₀（70.79%完成率）提升5.5个百分点，宽松成功率提升25.58个百分点（37.42%→63.0%），严格成功率与复现π₀接近（11.83% vs 12.25%）；语言-only消融的完成率仅为53.72%，证明组合式2D提示的显著增益；在涉及关系和遮挡的T7-T10任务上2AM表现优于复现π₀，简单序列任务T1-T6的严格成功率略低于复现π₀
