Card 02 论文概述

论文概述

  • 提出GloVLA混合操作框架，将面向物体的机器人操作分解为几何传输和局部VLA交互两个互补阶段，解决非结构化环境下端到端VLA策略鲁棒性差、推理成本高、数据效率低的核心问题
  • 核心思路是将可重复的自由空间传输任务交给几何控制器，让VLA仅负责需要语义感知和接触推理的局部短程交互，避免VLA处理分布外状态导致的失效
  • 同时构建LIBERO-Challenge鲁棒性基准，系统性评估杂乱、干扰物、光照变化、遮挡、视觉偏移等非结构化扰动对VLA操作性能的影响
Card 03 核心贡献

核心贡献

  • 提出GloVLA：一种模型无关的混合操作框架，可兼容任意现有VLA骨架，无需修改VLA架构、无需额外演示数据，即可将操作分解为几何传输和局部VLA交互两个阶段
  • 构建LIBERO-Challenge基准：作为LIBERO和LIBERO-Plus的补充，提供50个包含单/多组合扰动的非结构化场景，分easy/medium/hard三个难度等级，用于系统性评估VLA的鲁棒性
  • 实验验证GloVLA的有效性：在标准LIBERO任务、LIBERO-Plus任务、LIBERO-Challenge基准以及真实UR10e机器人上，均实现任务成功率提升、鲁棒性增强、数据效率提高，同时大幅降低VLA推理成本
Card 04 方法描述

方法描述

  • 任务分解与混合切换策略：将pick-and-place任务拆分为4个确定性切换模式：物体接近（app）、局部抓取（grasp）、篮子传输（trans）、局部放置（place），通过预设的几何阈值和步数预算完成模式切换，避免VLA处理长距离传输任务
  • 几何传输控制器：采用轻量级闭环笛卡尔比例控制器，基于估计的物体/篮子中心计算handoff位置，仅控制末端执行器的位置（姿态保持模式进入时的状态），生成符合LIBERO 7D OSC-pose动作空间的传输命令，无需额外碰撞检测或轨迹优化
  • 局部VLA策略训练：通过球面约束演示提取（Sphere-Conditioned Demonstration Extraction）方法，从原始全轨迹演示中自动提取抓取和放置两个局部片段，分别微调两个独立的局部VLA策略，仅处理短程接触丰富的交互任务，保留原有VLA的观察-动作接口和成功判定标准
  • 位置覆盖保证：通过几何约束证明，只要定位误差、控制器容差和偏移量满足设定条件，传输控制器交接的末端位置必然落在局部VLA策略的训练提取区域内，保证VLA的输入处于训练分布内
Card 05 数据集与资源

数据集与资源

  • 使用的数据集：标准LIBERO Object任务集、LIBERO-Plus Object任务集，以及新提出的LIBERO-Challenge基准（50个评估场景，包含clutter、distractor、illumination shift、obstruction、visual shift五类扰动，easy/medium/hard三个难度分别对应1种、2-3种、4-5种扰动组合）
  • 模型规模：适配多类主流VLA骨架，包括π₀、π₀.₅、GR00T N1.6、GR00T N1.7，无需修改VLA架构即可集成
  • 训练资源：8块NVIDIA A100 80GB GPU，采用Adam优化器，学习率为1×10⁻⁴；评估使用NVIDIA RTX 5090 32GB GPU
  • 真实机器人平台：UR10e机械臂，采用SAM 3实现开放词汇分割的3D物体定位
Card 06 评估与结果

评估与结果

  • 评估环境与基准：标准LIBERO Object 10项任务、LIBERO-Plus Object任务集、LIBERO-Challenge基准，以及真实UR10e非结构化场景
  • 主要评估指标：任务成功率、VLA推理时间、数据效率（演示数量）
  • 关键实验结果：

- 标准LIBERO任务上，GloVLA在π₀、π₀.₅、GR00T N1.6、GR00T N1.7骨架上均实现成功率提升或持平，例如π₀在Alphabet Soup任务上成功率从94.0%提升至100.0%，GR00T N1.7在Butter任务上从98.0%提升至100.0%

- 非结构化鲁棒性测试中，端到端GR00T N1.6在LIBERO-Challenge上的平均成功率降至20.9%，而GloVLA可保持88.5%的成功率

- 真实UR10e机器人上，GloVLA将任务成功率从35.6%提升至90.0%，同时平均推理时间缩短超过一半

- 数据效率上，GloVLA仅需原始全轨迹演示即可训练，无需额外人工标注，在匹配演示预算的情况下性能显著优于端到端VLA
