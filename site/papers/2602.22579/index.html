Card 02 论文概述

论文概述

  • 针对视觉-语言-动作（VLA）使能机器人的测试神谕问题：现有符号神谕需针对每个指令定制、泛化性差，且仅能评估任务是否完成，无法衡量执行质量，开展相关研究。

  • 通过大规模实证研究验证所提方法的有效性，并构建首个VLA故障分类法，证明符号神谕与MT的互补性。
Card 03 核心贡献

核心贡献

  • 首次将蜕变测试（MT）引入VLA使能机器人的测试领域，解决该领域长期存在的测试神谕泛化性差、无法评估执行质量的问题。
  • 提出两个任务无关的通用蜕变关系模式：轨迹一致性（TC）模式和轨迹变化（TV）模式，并衍生出5个可跨模型、跨机器人、跨任务复用的具体 metamorphic relations。
  • 开展覆盖5个SOTA VLA模型、2个机器人平台、4类操作任务的大规模实证研究，总计使用1864个源测试用例和9320个后续测试用例，验证MT的有效性。
  • 提出首个VLA故障分类法，明确对比了符号神谕与MT检测到的故障类型差异，证明二者互补可实现更全面的故障覆盖。
  • 公开完整复现包（含代码、配置文件、操作说明），保障研究可复现性。
Card 04 方法描述

方法描述

  • 核心方法基于蜕变测试（MT）范式，通过定义 metamorphic relations（MR）约束不同输入下的机器人轨迹关系，采用弗雷歇距离（Fréchet distance）度量源测试用例与后续测试用例的轨迹差异，设置严格（0.1m）、中等（0.2m）、宽松（0.3m）三个容忍阈值判断MR是否被违反。
  • 创新点1：提出轨迹驱动的蜕变关系模式，TC模式捕捉不应改变机器人轨迹的输入变化（如指令同义词替换、环境添加非干扰物体、光照微调），TV模式捕捉应引起可预测轨迹变化的输入变化（如指令取反、目标物体重定位）。
  • 创新点2：所提MR完全任务无关，无需针对每个任务定制神谕，可自动生成测试用例并执行，解决了符号神谕泛化性差、定制成本高的痛点。
  • 创新点3：MR同时覆盖指令侧和环境侧的输入变换，可检测VLA模型的语义理解、视觉 grounding、运动规划等多维度的潜在故障。
Card 05 数据集与资源

数据集与资源

  • 仿真环境与任务：基于SimplerEnv仿真基准，覆盖2个机器人平台（Google Everyday Robot、WidowX机器人），4类标准操作任务（Pick Up、Move Near、Put On、Put In），模型训练采用Fractal数据集和Bridge V2数据集。
  • 评估模型：共评估5个SOTA VLA模型，分别为 OpenVLA-7B、π₀、SpatialVLA-4B、GR00T-N1.5、EO-1，全部采用官方公开或对应数据集微调的checkpoint。
  • 计算资源：实验分布在两台计算平台，分别配备AMD EPYC 7773X CPU + NVIDIA RTX A6000 48GB GPU、AMD Ryzen 9 7900X CPU + NVIDIA GeForce RTX 4080 SUPER 16GB GPU；总实验耗时约219168秒（约61 GPU小时），单次测试平均耗时7.5~35秒。
Card 06 评估与结果

评估与结果

  • 评估环境与基准：在SimplerEnv仿真环境中开展实验，以传统符号神谕为对比基线，总计完成11000余次测试执行。
  • 主要评估指标：MR违规率、故障检测覆盖率、故障类型分布匹配度。
  • 关键实验结果：

- MT可有效检测VLA故障，且检测效果与阈值严格度正相关：高严格度阈值下，总计检测到7822个故障，其中640个仅被符号神谕检测到，3527个仅被MT（MR违规）检测到，3655个被二者同时检测到，证明MT可有效补充符号神谕的检测覆盖范围；中等严格度阈值下，总计检测到6286个故障，其中1776个仅被符号神谕检测到，1991个仅被MT检测到，2519个被二者同时检测到，该阈值是兼顾检测覆盖率与检测结果相关性的最优选择；低严格度阈值下，总计检测到5177个故障，其中2877个仅被符号神谕检测到，888个仅被MT检测到，1418个被二者同时检测到，此时MT主要起到强化符号神谕检测结果的作用，额外发现的故障较少。

- 不同MR的故障检测能力存在差异：环境类MR（MR2：非干扰物体添加）和语义类MR（MR4：任务否定）在绝大多数场景下故障检测率最高，鲁棒性类MR（MR1同义词替换、MR3光照变化）的检测效果受阈值影响较大，需组合多个MR实现全面评估。

- MT与符号神谕互补：符号神谕主要捕获“规划与推理”类的任务级故障（如任务未完成、动作序列错误），MT则能捕获“运动”“操作”类的执行级故障（如轨迹次优、控制不稳定、碰撞），二者结合可覆盖任务完成度和执行质量两个维度的故障。
