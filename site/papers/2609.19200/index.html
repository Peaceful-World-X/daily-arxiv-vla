Card 02 论文概述

论文概述

  • 针对水下双手操作机器人学习领域现有研究主要集中在单机械臂或空中双臂操作的空白，提出了 ULOHA 这一水下双臂机器人学习平台
  • 平台整合了自定义的主-从臂硬件（干式leader控制水下follower）与基于 LeRobot 的软件扩展，支持遥操作采集、多视角感知、策略训练与自主部署全流程
  • 在真实水环境中评估了 ACT、Diffusion Policy 和 SmolVLA 等现有学习方法，研究了气泡扰动、浮力驱动、动作执行时序及实时分块（RTC）对策略部署的影响，并开展了单臂空-水迁移实验
Card 03 核心贡献

核心贡献

  • 首个集成化的水下双臂机器人学习平台，结合了适配防水线缆的自定义主从硬件、多视角视觉系统以及LeRobot扩展软件栈
  • 在9项真实水下双臂任务上系统评估了现有学习方法，验证了ACT、Diffusion Policy与SmolVLA在该平台上的可部署性
  • 实证研究了水下策略部署的敏感性：气泡干扰导致顺序传递任务成功率从10/10降至3/10；30步执行时序在释放-接应任务上取得6/10的最优结果；实时分块（RTC）使SmolVLA成功率从4/10提升至6/10
  • 通过单臂空-水迁移实验证明：混合介质（空气5集+水下5集）训练的单一策略可在两种介质中均达到10/10成功率，而单介质训练策略跨介质迁移时均失败（0/10）
Card 04 方法描述

方法描述

  • 硬件架构：采用2个干式leader臂（Dynamixel XM430-W350）控制2个水下follower臂（防水Dynamixel XW430-T333），每臂6个关节+自定义夹爪，针对防水线缆约束重新设计从臂结构以避免关节运动干涉
  • 感知系统：3个TIER IV C1-120 GMSL2相机（顶部全局相机+左右手相机），分辨率1920×1280采集后缩放至480×320，以30fps编码
  • 软件栈：基于 LeRobot 扩展ULOHA专用硬件适配器，支持30Hz遥操作记录（归一化leader目标、follower状态、多相机流）、策略推理与自主执行
  • 策略部署：ACT采用单ResNet-18骨干网络（共享多视角）+ Transformer（宽度512，8头）；Diffusion Policy使用2步观测；SmolVLA在公开基座 checkpoint 上微调并保持视觉编码器开放
Card 05 数据集与资源

数据集与资源

  • 水下双臂任务数据集：9项任务中，表面传递与释放接应各50集演示，其余7项任务各10集演示；单臂数据集每介质10集，混合介质为5集+5集
  • 模型规模：ACT使用ResNet-18骨干+Transformer（宽度512，8注意力头）；SmolVLA基于公开VLA基座微调；Diffusion Policy采用条件扩散过程
  • 训练配置：ACT训练50k步（batch size 8），Diffusion Policy训练50k步（batch size 32），SmolVLA训练200k步（有效batch size 32）；控制频率30Hz
  • 硬件成本：每套leader臂约2600美元，每套follower臂约7000美元；实验水箱尺寸1.2m×0.6m×0.6m，水深不超过1米以符合IP68防护要求
Card 06 评估与结果

评估与结果

  • 评估环境：铝制框架+黑色面板围蔽的水箱实验环境，在透明水与气泡扰动两种条件下进行，每项条件10次试验，成功需在时限内（双臂60秒/单臂45秒）达到任务目标状态
  • 主要指标：任务成功率（10次试验中的成功次数）
  • 关键实验结果：

- ACT在9项双臂任务上总成功率68/90，其中块传递、顺序传递、双臂提升达到10/10；表面传递4/10、释放接应3/10（受浮力与精确抓取限制）

- 气泡扰动下顺序传递成功率骤降至3/10，而双臂提升保持10/10（视觉干扰影响不对称）

- ACT执行时序优化：释放接应任务中30步前缀执行达到6/10（优于100步基线的3/10），15步时回落至3/10（非单调关系）

- SmolVLA实时分块（RTC）在释放接应上达6/10，优于同步执行的4/10

- 单臂迁移：仅在水下训练的ACT在水下10/10、空中0/10；仅在空中训练的ACT在空中10/10、水下0/10；混合训练策略在两种介质均达10/10，并对未见过的黑色橡胶块展现7/10的迁移能力
