Card 02 论文概述

论文概述

  • 针对移动操作任务中的演示数据稀缺问题，提出一种低成本、无需机器人接入的便携式演示采集与学习框架 VOMMI（Visual-Odometry-Conditioned Mobile Manipulation Interface）
  • 利用两个独立的鱼眼 RGB 相机分别记录身体（导航）和手部（操作）视图，仅凭 RGB 与时间戳恢复运动信息，无需昂贵的专用硬件或人-机器人运动学校准
  • 旨在从纯 RGB 演示中构建可供视觉-语言-动作（VLA）模型使用的训练数据，并引入视觉里程计条件以提升长时序移动操作策略的精度和鲁棒性
Card 03 核心贡献

核心贡献

  • 提出一种便携式双视图移动操作演示采集协议，无需接触目标机器人，也无需进行人-机器人运动学对应校准，显著降低采集成本
  • 设计 R2-VO 模块：包含因果局部运动估计（在线产生多尺度身体运动 Token）和离线锚点精化（结合 VGGT 稀疏几何锚点抑制漂移），用于提升轨迹重建质量
  • 定义统一的跨体现动作表示与动作组残差适配器，将身体运动信息仅注入基础动作分支，保持操作动作分支独立，确保策略在仅有 RGB 输入时仍可稳健运行
  • 开源完整的便携数据采集与学习管线，在实际移动操作机器人上验证了所提方法的有效性
Card 04 方法描述

方法描述

  • 双视图采集与时间对齐：演示者佩戴胸部鱼眼相机（身体视图）和手持 UMI 式夹爪上的第二鱼眼相机（手部视图），通过时间戳对齐两路视频，生成同步的观测-动作片段
  • 本地跨体现动作表示：身体运动表示为当前身体坐标系下的平面速度指令 [v_x, v_y, ω]；末端执行器目标表示为当前 TCP 坐标系下的 SE(3) 增量，消除对全局坐标系的依赖
  • 身体-手部对齐与平面补偿：将重建的身体轨迹与手部时间戳对齐，利用身体平移和偏航对手部姿态进行平面补偿，得到身体相对化的 TCP 轨迹，用于构造训练监督
  • R2‑VO 运动重建：

- 在线分支利用光流与几何特征预测多尺度的身体运动增量，编码为 29 维运动 Token

- 离线分支结合因果 VO 轨迹与稀疏 VGGT 锚点，通过 Ridge 映射与漂移补偿获得高精度身体轨迹

  • VO 条件的动作组适配：在预训练 VLA 基础上添加蒸馏式残差分支，仅将运动 Token 输入到身体动作的残差网络，经门控与基础流预测融合，保持预训练模型初始无损
Card 05 数据集与资源

数据集与资源

  • 数据集：每个任务采集 500 条便携演示，其中 75 条固定为视觉里程计评估测试集，另外参考 200 条机器人采集的演示
  • 任务：三个移动操作任务，包括跨越障碍物抓取水果、进出房间操纵瓶子、开门放置折叠盒
  • 模型规模：基于预训练的 VLA 模型（如 OpenPI 0.5），添加轻量适配器（LayerNorm-MLP、残差 MLP 等），新增参数量较小
  • 训练资源：未明确说明，推断使用消费级 GPU 进行适配器微调，离线轨迹精化使用 VGGT-1B 模型
  • 硬件成本：双鱼眼 RGB 相机方案成本约 100–200 美元，远低于现有 UMI/iPhUMI 等方法
Card 06 评估与结果

评估与结果

  • 评估环境：实体 DeepRobotics M20S 轮腿机器人（配 CM1 机械臂），每个条件独立测试 20 次
  • 评估指标：视觉里程计精度（局部/累积平移与旋转误差）、任务成功率、动作偏离参考命令误差
  • VO 精度对比：R2‑VO 离线重建在身体和手部流上的绝对轨迹误差比最佳基线平均降低 24.6%；在线分支也保持较低的局部平移和偏航误差
  • 主要结果：

- 仅用便携演示训练的 VOMMI 策略，其基础速度误差比使用机器人演示训练的策略降低 18.2%，而末端执行器平移精度基本持平

- 在真实机器人任务上，完整 VOMMI 系统的平均成功率比 OpenPI 0.5 提高 8.3 个百分点，比 GR00T N1.6 和 X-VLA 也有明显提升

  • 消融实验：验证了运动 Token、残差门控、离线精化等组件对数据质量和策略性能的贡献，缺省组件会导致成功率显著下降
