Card 02 论文概述

论文概述

  • 传统可供性表示（2D掩码、3D区域、接触点等）仅能说明交互的“位置”，无法描述交互几何的动态演化过程，也无法直接用于跨人机 embodiment 的控制知识迁移
  • 本文提出动作导向的4D可供性（action-oriented 4D affordances），定义为语言条件的交互相关3D点的未来轨迹，用于描述交互几何如何随时间展开，提供可迁移的操作先验
  • 研究目标是构建大规模4D可供性数据集，设计A4A跨embodiment迁移框架，将人类演示中的操作知识有效转移到机器人控制，提升不同VLA策略的 manipulation 性能
Card 03 核心贡献

核心贡献

  • 引入动作导向的4D可供性表示，作为任务条件的交互相关3D几何的未来轨迹，相比静态可供性，不仅说明“在哪交互”，还说明“交互如何展开”，提供跨embodiment的可迁移监督信号
  • 提出A4A跨embodiment可供性到动作迁移框架，以4D点轨迹作为VLA预训练的预测空间，通过预测空间替换的方式适配不同VLA的原生动作生成范式，无需引入额外的时序网络
  • 在5类VLA策略家族、LIBERO-Object、RLBench仿真基准以及真实世界操作任务上验证，A4A一致提升下游策略性能，相比通用场景级4D预训练更有效，即使仅用RGB输入也能超过使用显式3D/4D输入的方法
Card 04 方法描述

方法描述

  • 几何前提：短时序内交互相关的4D点运动与机器人末端执行器运动共享局部SE(3)刚性变换结构，是同一操作转换的两种几何描述，为跨embodiment迁移提供依据
  • 4D可供性数据集构建：从现有HOI4D、EPIC-Kitchens等人机交互视频及自采集RGB-D演示中提取交互片段，用GroundingDINO定位交互物体，SAM 2生成交互区域掩码，CoTracker3跟踪 query 点，结合深度图反投影得到身份保持的3D点轨迹，最终整理为统一格式的4D可供性样本
  • 两阶段训练策略：第一阶段4D可供性预训练，复用VLA的视觉语言前端，将 query 点投影到VLA的输入空间后输入共享隐层模块，预测未来4D点运动，使用VLA原生的损失函数；第二阶段机器人微调，将点投影器替换为本体感知投影器，将4D预测头替换为机器人动作头，恢复VLA的原生状态和动作接口，联合微调共享隐层参数
  • 创新点：1. 将可供性表示从静态空间定位扩展到动态几何演化描述，更贴合操作的控制需求；2. 基于预测空间替换的迁移框架，仅替换状态和动作接口，保留共享隐层和原生训练目标，避免预训练和微调的目标不匹配；3. 框架可适配不同VLA的原生动作生成范式，无需修改核心架构，泛化性强
Card 05 数据集与资源

数据集与资源

  • 数据集：动作导向的4D可供性数据集，包含超过80K交互片段，其中约30K为自采集，覆盖开、关、拿、放、推、拉、倒、切、挂、扫、开盖等常见及小众操作
  • 模型规模：RLBench实验使用Qwen3.5-4B作为骨干网络；LIBERO实验适配5类主流VLA策略：Octo、OpenVLA、OpenVLA-OFT、π0、π0.5
  • 训练资源：单主机 equipped with 8块NVIDIA A800 GPU
Card 06 评估与结果

评估与结果

  • 评估环境和基准：仿真环境包括LIBERO-Object（10个物体交互任务）、RLBench（meat off grill、sweep to dustpan、turn tap、slide block to target 4个任务）；真实世界环境使用AgileX Piper机械臂，6个操作技能（放杯子到马克杯、开微波炉、切桃、开锅、倒米、倒水）
  • 主要评估指标：任务成功率（%）
  • 关键实验结果：

- LIBERO-Object上，5类VLA策略的平均成功率分别提升29.0（Octo）、10.0（OpenVLA）、0.6（OpenVLA-OFT）、10.0（π0）、2.0（π0.5）个百分点，性能增益在不同动作生成范式上保持一致

- RLBench上，仅用RGB输入的A4A策略平均成功率从39.0%提升到61.0%，超过Image-BC (ViT)、C2FARM-BC、ManiGaussian、ARM4R等基线，在需要精确空间推理和接触依赖运动的任务上增益更显著

- 架构控制的消融实验中，相比通用场景级4D点轨迹预训练，动作导向的4D可供性预训练平均成功率从41.0%提升到60.0%，验证了4D可供性监督的有效性

- 真实世界上，4类VLA策略的平均成功率从56.7%提升到72.5%，在需要大范围 orientation 变化的倒米、倒水任务上增益突出，验证了框架在物理机器人上的有效性
