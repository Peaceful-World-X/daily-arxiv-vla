Card 02 论文概述

论文概述

  • 本文系统性地研究了强化学习 (RL) 在视觉-语言-动作 (VLA) 模型后训练中的参数更新结构，发现 RL 诱导的参数更新呈现低秩特性
  • 研究揭示了 RL 学习信号如何重塑 VLA 策略，特别是集中在动作专家的 时间步模块 (Timestep Modules) 这一先前被忽视的小型组件上
  • 旨在填补对 VLA 强化学习参数空间理解的空间，为更高效和可解释的 VLA 后训练方法提供基础
Card 03 核心贡献

核心贡献

  • 发现 RL 在多种流匹配 VLA 模型（如 π₀.₅、GR00T N1.5/N1.6）和基准（如 LIBERO, ManiSkill, MetaWorld, CALVIN）上一致地产生低秩的参数更新，且这些更新高度集中于动作专家的 时间步模块
  • 通过模块替换实验证明，时间步模块参数更新承载了 RL 性能增益中的绝大部分，即使这些模块只占总参数的一小部分
  • 揭示 RL 将时间步模块专门化到 rollout 时使用的离散去噪时间步，这种离散时间步训练是导致低秩更新的原因
  • 发现时间步模块产出的 位移向量 (shift vector) 在 RL 中变化最显著，并证明其更新方向能高度预测任务成功（ROC-AUC 最高达 99.6%），且其几何结构反映了任务间的关系
  • 通过在位移更新方向上进行引导 (steering)，成功在不额外训练的情况下进一步提升了 RL 训练后策略的性能
Card 04 方法描述

方法描述

  • 分析 RL 参数更新的密度和有效秩，并通过 SVD 提取更新矩阵的主要奇异方向
  • 对 RL 训练后的检查点进行受控模块替换实验，比较仅保留时间步模块更新与仅保留其他模块更新的效果
  • 研究时间步模块对离散去噪时间步的专门化模式，分析其输入奇异方向与不同时间步调节向量的余弦相似度
  • 对时间步模块产出的尺度 (scale)、位移 (shift) 和门控 (gate) 向量进行解耦分析，量化 RL 带来的方向性变化
  • 使用线性探测 (linear probing) 方法，将位移更新方向作为分类方向，预测情节的成功/失败结局
  • 实施自适应激活引导 (adaptive activation steering) 技术，在推理时沿位移更新方向调整隐藏层表示，以提升策略性能
Card 05 数据集与资源

数据集与资源

  • 使用的验证基准包括 LIBERO (Spatial, Object, Goal)、ManiSkill、MetaWorld 和 CALVIN
  • 分析了多个公开及内部训练的 VLA 模型，包括 π₀.₅、GR00T N1.5、GR00T N1.6 和 SmolVLA
  • 模型规模方面，时间步模块在 π₀.₅ 动作专家中占总参数的 27.58%，其中 AdaRMS 占了绝大部分 (98.23%)
  • 训练算法使用近端策略优化 (PPO)
Card 06 评估与结果

评估与结果

  • 评估环境为上述的多个机器人操作模拟基准环境
  • 主要评估指标包括：更新密度、有效更新秩、任务成功率、线性探测的 F1 分数和 ROC-AUC，以及任务向量的余弦相似度和斯皮尔曼相关系数
  • 关键实验结果：

- RL 对时间步模块的更新紧凑（有效秩低至 6–30，而行为克隆为 250–650），且模块替换实验中 “仅保留时间步模块更新” 的平均成功率为 80.9%，远高于 “仅保留其他模块” 的 66.6%

- 对位移更新方向的线性探测能高度预测任务成功，ROC-AUC 在 LIBERO-Spatial 上达到 99.6%

- 位移更新的配对余弦相似度与跨任务迁移模式的斯皮尔曼相关系数高达 0.794，表明其几何结构编码了任务关系

- 通过沿位移方向进行引导，RL 训练后策略的成功率得到进一步提升（在 LIBERO-Goal 上从 90.7% 提升至 94.7%）
