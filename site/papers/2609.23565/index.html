Card 02 论文概述

论文概述

  • 现有Vision-Language-Action（VLA）模型在有限数据集上微调时会出现严重的轨迹过拟合问题，过度依赖主相机视角的局部纹理特征，忽略腕部相机的细粒度操作信息，导致泛化能力差、执行行为 brittle
  • 本文提出MaskVLA，一种基于随机掩码的VLA微调策略，通过训练时随机掩码部分主相机输入，引导模型学习更均衡、鲁棒的多视角视觉特征，提升复杂操作任务的泛化性能
  • 该方法在仿真和真实机器人平台上均验证了有效性，解决了VLA微调阶段多视角信息利用不足、过拟合的核心问题
Card 03 核心贡献

核心贡献

  • 识别了当前SOTA VLA微调方法存在的严重过拟合问题，并通过Grad-CAM可视化手段验证了模型过度依赖主相机局部特征、忽略多视角信息的现象
  • 提出MaskVLA微调框架，通过针对性设计的随机掩码策略，引导模型有效利用多视角视觉线索，实现更鲁棒的表征学习和更精确的动作生成
  • 在仿真和真实机器人平台上开展大量实验，验证了该方法能够有效缓解VLA的轨迹过拟合问题，显著提升操作任务的成功率
Card 04 方法描述

方法描述

  • 基于OpenVLA-OFT框架设计即插即用的微调模块，无需修改模型主干架构，可直接应用于多视角VLA模型的微调流程
  • 训练阶段以预设概率ρ（本文最优设置为10%）随机将主相机（头顶视角）的完整输入像素置零（掩码），推理阶段使用完整的多视角图像输入，不影响推理效率
  • 通过强制模型在训练时无法依赖主相机信息，引导其主动学习整合腕部相机的细粒度操作特征，缓解单视角预训练与多视角微调带来的域gap
  • 创新点是将大语言模型（LLM）和视觉语言模型（VLM）领域的掩码机制引入VLA微调场景，针对多视角VLA的主相机过拟合问题设计轻量、高效的优化策略
Card 05 数据集与资源

数据集与资源

  • 仿真数据集：RoboTwin 2.0 双臂操作仿真基准，包含easy（demo_clean，白背景无杂乱干扰，测试任务执行上限）和hard（demo_randomized，随机桌面/背景纹理、随机光照，模拟真实环境分布偏移）两种评估模式，每任务使用50条演示轨迹微调，评估时每任务测试100次 trial
  • 真实实验平台：ALOHA 双臂 teleoperation 机器人，搭载1个主相机、2个腕部相机，以及14维关节角度 proprioceptive 传感器，每任务使用50条演示轨迹微调，评估时每任务测试20次 trial
  • 基础模型：基于开源预训练的OpenVLA-OFT VLA模型进行微调
  • 训练资源：2块NVIDIA A100 GPU（单卡batch size为4），每任务训练30000步（约12小时）；评估使用RTX 3090 GPU，推理使用A100 GPU
Card 06 评估与结果

评估与结果

  • 评估环境：仿真场景覆盖4类双臂操作任务（Adjust bottle、Open laptop、Put object cabinet、Stack bowls three），真实场景覆盖4类操作任务（Feed carrot、Adjust cups、Place orange、Stack bowls）
  • 评估指标：任务成功率（success rate）
  • 关键实验结果：

- 仿真hard模式下，MaskVLA平均成功率达75.0%，超过基线OpenVLA-OFT 20.0%，超过π₀ 16.8%；easy模式下平均成功率达84.5%，超过OpenVLA-OFT 7.0%

- 在8个easy+hard子任务中，MaskVLA在6个子任务中取得最优性能，剩余2个子任务取得第二优性能

- 真实世界实验中，MaskVLA在所有4个任务上均优于OpenVLA-OFT，其中Feed carrot和Place orange任务成功率达85.0%，显著提升了复杂长程操作任务的表现

- 消融实验表明，10%概率的完整主相机掩码策略效果最优，优于patch级掩码和随机相机视角掩码策略，验证了设计的合理性
