论文概述

  • 通过 条件退火机制 将流匹配的粗到细去噪过程映射为 token 序列的因果顺序，使 token 与自回归生成自然对齐
Card 03 核心贡献

核心贡献

  • 提出 条件退火因果动作分词：将动作分词形式化为序列生成过程，使 token 具有粗到细的因果结构，与自回归建模天然兼容
  • 设计 基于 MMDiT 的 Token 条件流匹配解码器：从紧凑离散 token 重建连续动作块，兼具扩散模型的控制精度与纯自回归 VLA 的训练兼容性
  • 在多个仿真基准和真实机器人任务上验证 优异性能：在任务成功率、训练效率（训练步骤减少约 50%）、推理速度（快 1.7 倍）和保真度-压缩平衡（强 3.6 倍）方面均超越 FAST 和 OAT 等方法
Card 04 方法描述

方法描述

  • 双流动作编码器：使用 2D CNN 和 MMDiT 风格的共同注意力机制，从原始动作块中提取紧凑的潜在查询 token
  • 瓶颈向量量化器：采用因式分解码本设计，将潜在向量映射到离散码本并重新投影，提高码本利用率
  • 条件退火流匹配解码器：训练过程中根据流匹配时间步逐步掩码前部 token，仅向后部 token 提供条件信息，强制不同的 token 在不同去噪阶段发挥作用，从而学习到层次化的生成语义
  • VLA 集成：冻结训练好的 CATok 分词器和解码器，仅微调自回归 VLM 骨干，通过离散 token 接口实现知识隔离，保护预训练语义
Card 05 数据集与资源

数据集与资源

  • 仿真基准：LIBERO、SimplerEnv、RoboTwin 2.0
  • 真实世界基准：Franka 机器人上的 Pick-Spatial、Pick-Color、Stack-Long 任务
  • VLA 骨干：Qwen3-VL-4B-Instruct，以及针对 LIBERO 的 π₀-FAST-base
  • 训练数据：仿真使用各基准官方数据集；真实机器人收集 362 条 Pick 轨迹和 220 条 Stack 轨迹，并结合 InternA1 关节数据预训练分词器
  • 分词器配置：token 数 \(K=16\)，码本大小 4096，VQ 维度 \(d_{vq}=16\)
Card 06 评估与结果

评估与结果

  • 任务成功率：在 LIBERO、SimplerEnv、RoboTwin 2.0 三大基准上均取得最高平均成功率，尤其在长时域任务（如 LIBERO-Long 和 SimplerEnv 叠块任务）上提升显著（相对最强基线提升 16.7%）
  • 训练效率：仅需 FAST 约 50% 的训练步数即可达到匹配的成功率，收敛更快，学习更稳定
  • 推理效率：端到端 VLA 推理延迟接近最优，综合自回归生成和解码开销后比 FAST 快约 1.7 倍
  • 保真度-压缩平衡：VRR×CR 指标达 16.85，显著优于 Binning、FAST 和 OAT，在相同压缩水平下重建精度更高
  • 真实世界表现：在 Franka 机器人三个任务套件上，成功率均比 FAST 高 20 个百分点
  • 因果语义验证：前向预测熵逐位递减，反向预测熵递增；token 嵌入几何呈 slot 依赖分布；前缀重建展示连贯的粗到细轨迹更新
