Card 02 论文概述

论文概述

  • 论文提出了 VisForce 框架，旨在解决灵巧手操作中力觉信息与视觉空间位置难以显式对齐的问题。
  • 当前 Vision-Language-Action (VLA) 模型多将接触力作为独立的状态向量处理，缺乏力与指尖位置的空间对应关系，且难以同时指定“如何抓取”和“用多大力抓取”。
  • VisForce 将当前执行器力与期望力在视觉空间中进行指尖对齐的可视化呈现，使现有 VLA 模型能通过视觉通路理解力觉条件。
Card 03 核心贡献

核心贡献

  • 提出力接地的当前视觉表示，将每个手指的执行器力在手腕相机图像对应的指尖位置渲染为视觉力线索。
  • 提出力接地的目标表示，在参考目标图像上叠加任务特定的期望力视觉线索，并将图像前景（手与物体）与背景分离。
  • 设计目标条件交叉注意力机制，使当前力接地手部图像 token 显式地关注目标前景 token，实现力感知的动作生成。
  • 在真实机器人平台上验证了方法在力敏感抓取与多阶段力感知操作任务中的有效性，包括鸡蛋抓取、杯子插入、滑移调控轴孔装配等。
Card 04 方法描述

方法描述

  • 基础模型：基于 VLA 模型 π₀.₅ 构建。
  • 力可视化：在 MuJoCo 仿真中复现真实机器人构型，将指尖执行器力渲染为 3D 箭头；通过优化 Hand-mask IoU 和 Chamfer 损失对齐仿真与真实手腕相机位姿，将力线索叠加到真实图像上。
  • 目标图像构建：从演示中选取参考帧，分割出手与物体的前景，在对应指尖位置渲染期望力箭头。
  • 融合机制：当前力接地手腕图、力接地目标图与外部相机图经共享 SigLIP 编码器编码后，在目标条件交叉注意力块中，以当前手腕 token 为 query，前景目标 token 为 key/value 进行注意力计算，更新后的表示送入 VLM 骨干生成动作。
  • 训练：冻结 VLM 骨干参数，仅更新 SigLIP 编码器与交叉注意力模块，并使用 LoRA 微调骨干网络。
Card 05 数据集与资源

数据集与资源

  • 数据收集：在真实机器人平台上收集演示数据，全部为真实世界轨迹。
  • 任务数据量：T1（力调节抓取）30 条；T2（杯子插入/倒水）25 条；T3（夹子传递面包）30 条；T4（滑移轴孔装配）30 条
  • 机器人硬件：UR10 机械臂，RH56F1 六指灵巧手，双 Intel RealSense D405 相机（腕部与外部）。
  • 训练资源：策略推理与训练在配备 NVIDIA RTX A6000 GPU 的工作站上进行。
Card 06 评估与结果

评估与结果

  • 评估基准：与 π₀.₅、State Force + Text Force Goal、Visual Force + Text Force Goal 等方法进行对比。
  • 评估任务：包含力调节抓取（T1，含鸡蛋与牙膏）、杯子插入/浇注（T2）、夹子传递面包（T3）、滑移轴孔装配（T4）四类真实操作任务。
  • 主要指标：任务成功率（T2-T4 为阶段累积成功率），力调节能力以聚合执行器力衡量。
  • 关键实验结果：

- 在 T1 中，VisForce 的执行器力随期望力等级提升呈稳定递增趋势；在鸡蛋与牙膏任务上的抓取成功率分别达 70% 和 80%。

- 在多阶段任务中，VisForce 最终成功率：T2 70%（杯子插入/浇注），T3 55%（夹子传递面包），T4 40%（滑移轴孔装配）。

- 消融实验表明，目标条件交叉注意力相比简单的视觉 token 拼接，在三项任务上均带来显著提升（T2：10% → 70%，T3：5% → 55%，T4：15% → 40%）。
