Card 02 论文概述

论文概述

  • 针对生物实验室自动化中，现有视觉-语言-动作（VLA）模型对环境变化鲁棒性差、部署需针对每个实验室收集遥操作数据并训练专属策略的问题，提出可跨实验室转移的机器人套件WetRobo
  • 该套件结合代码策略（code-as-policy）的coding agent，让生物实验人员仅需提供自然语言任务描述，无需自行收集本地遥操作数据或训练神经网络，即可完成实验室机器人操作
  • 研究在真实实验室的三个基础湿实验任务（培养皿盖提起、试剂瓶盖移除、培养箱门开启）上验证方案有效性，证明其跨实验室迁移性能优于传统VLA方案
Card 03 核心贡献

核心贡献

  • 开发了开源的WetRobo机器人套件，包含硬件规格、基础驱动代码、15个/任务的遥操作演示、领域特定的AGENTS.md技能文件，让生物实验人员无需机器人或AI专业知识即可快速部署
  • 首次证明coding agent能够自主演化程序并适配真实实验室环境，通过自主调用外部工具完成培养皿盖提起、试剂瓶盖移除、培养箱门开启三个真实湿实验任务
  • 通过跨实验室对比实验证明，WetRobo结合coding agent的瓶盖任务迁移成功率显著优于在单实验室微调的$\pi_{0.5}$ VLA模型，为实验室机器人部署提供了低成本、高灵活性的实用路线
  • 验证了代码复用机制：前序任务演化出的代码可被后续任务直接调用，大幅缩短后续任务在相同实验室的适配时间
Card 04 方法描述

方法描述

  • WetRobo套件由硬件、基础软件栈和AGENTS.md技能文件三部分组成：硬件包含AgileX Piper六自由度机械臂、多视角RGB-D相机系统、指定的实验室设备（EYELA LTI-300培养箱、500mL D-PBS试剂瓶、TPP培养皿），以及用于录制遥操作演示的Meta Quest设备；基础软件栈包含机械臂驱动、相机采集、演示回放、安全层（工作区限制、运动限速、碰撞预警）代码
  • AGENTS.md技能文件定义了生物实验室操作的通用规则（如水平夹爪抓取、验证优先于速度、本地测量基准位姿等）、基线工作流（带实时偏差的演示回放），同时鼓励agent自主调用外部Python工具、模型完成适配
  • 实验采用OpenAI Codex CLI（gpt-5.6-sol模型，中等推理强度，审批策略为never）作为coding agent，agent通过观察机器人关节状态、相机RGB-D数据，自主编写可执行代码控制机械臂，执行过程会生成演化后的程序代码和完整的动作记录
  • 核心创新点：将code-as-policy思路引入湿实验室自动化场景，无需为每个实验室训练专属VLA策略；通过领域规则约束保证操作安全性，同时保留agent自主适配环境的灵活性；套件化分发模式大幅降低生物实验人员的部署门槛
Card 05 数据集与资源

数据集与资源

  • 硬件资源：AgileX Piper六自由度机械臂（单实验室部署2台，实验均使用右臂）、RGB-D相机系统（Lab X配置为头戴+腕部2台，Lab Y配置为头戴+左臂+实验台3台，采用iPhone搭配Record3D采集数据）、实验设备（EYELA LTI-300培养箱、Nacalai Tesque D-PBS试剂瓶、TPP 93100培养皿）、Meta Quest遥操作设备

  • 调用工具与模型：OpenAI Codex（gpt-5.6-sol）、SAM 3分割模型、MuJoCo物理引擎、OpenCV、NumPy

Card 06 评估与结果

评估与结果

  • 评估环境：两个独立真实实验室，Lab X（纽约大学）配置NYU String-driven Dynamixel夹爪、2台相机，环境亮度130.10；Lab Y（东京大学）配置Piper原生夹爪、3台相机，环境亮度106.84，两个实验室的工作台颜色、光照、机械臂位姿等条件存在明显差异
  • 评估基准：对比WetRobo + coding agent与微调后的$\pi_{0.5}$ VLA模型在瓶盖任务上的跨实验室迁移性能，VLA在Lab X的25个演示视频上微调10万步
  • 主要评估指标：任务成功率、首次抓取耗时、token消耗、跨实验室迁移成功率、重复执行耗时
  • 关键实验结果：

- Coding agent成功完成了全部三个真实湿实验任务：培养皿盖提起、试剂瓶盖移除、培养箱门开启

- 瓶盖任务中，WetRobo + coding agent在Lab X和Lab Y均实现成功迁移；而$\pi_{0.5}$ VLA仅在Lab X成功，迁移到Lab Y后完全失败

- 瓶盖任务首次抓取耗时：Lab X为1小时2分钟，Lab Y为48分43秒，token消耗分别为41.4M和23.0M

- 两个实验室演化出的适配代码存在明显差异：Lab Y通过夹爪扭矩和开口变化判断抓取成功，Lab X通过MuJoCo碰撞检测和视觉评估判断抓取成功

- 培养箱门开启任务在Lab X首次适配完成后，重复执行仅需3分27秒（含解析器修复和重启），前序任务的演化代码被后续任务复用，大幅缩短适配时间
