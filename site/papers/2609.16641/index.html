Card 02 论文概述

论文概述

  • 标准Vision-Language-Action (VLA) 模型缺乏旋转等变的架构先验，仅能泛化到训练演示覆盖的场景姿态范围，对场景旋转、视角变化敏感，操作策略的鲁棒性和数据效率不足
  • 本文提出SAVLA，一种端到端的对称感知VLA，通过冻结预训练VLM骨干、结合等变flow-matching动作头与可学习的canonicalization模块，实现鲁棒且数据高效的语言条件机器人操作策略学习
  • 核心目标是解决标准VLA的泛化性瓶颈，在不修改预训练骨干的前提下，引入对称性先验，提升模型对场景旋转的鲁棒性，同时降低对演示数据量的需求
Card 03 核心贡献

核心贡献

  • 提出等变flow-matching动作头，将状态、动作、条件输入分解为type-0（标量，旋转不变）与type-1（向量，旋转等变）两类通道，全程采用对称性保持操作，保证动作生成的旋转等变性
  • 设计类型化条件接口，将VLM骨干输出的近似不变特征作为不变条件，将预投影的几何参考点乘以场景旋转估计作为等变条件，适配非等变的冻结VLM骨干，实现骨干与等变头的高效结合
  • 构建完整的端到端对称感知VLA，引入可学习的canonicalization头，将斜视第三人称图像转换为canonical视角并同步旋转几何条件，实现近似的全流程旋转等变性
Card 04 方法描述

方法描述

  • SAVLA基于GR00T N1.5架构构建，完全冻结预训练的VLM骨干（SigLIP2视觉编码器 + Qwen3-1.7B语言模型），仅训练新增的等变动作头与canonicalization模块
  • 等变动作头采用flow-matching范式生成动作块，全程将特征分为type-0（标量，不变）与type-1（向量，等变）两类通道：type-0通道采用普通MLP与LayerNorm处理，type-1通道采用Vector Neuron（仅操作通道维度，保留空间分量）处理，注意力机制通过标量与向量的内积计算权重（旋转保持内积不变，因此注意力权重不变，输出等变），FFN的向量通道采用方向分解的GELU激活（仅激活平行于learnable方向的分量，垂直分量保留），保证所有操作的对称性
  • 对称感知条件接口提供两类条件：不变条件为canonicalized的第三人称图像、手腕图像与语言指令经VLM编码后的特征；等变条件为预投影到桌面的固定视觉参考点，乘以canonicalizer估计的场景绕重力轴的旋转角度
  • Canonicalization头采用3层CNN（总参数量0.09M）估计场景旋转角度，通过预定义的桌面对应单应性矩阵将斜视第三人称图像warp到canonical视角，同步旋转几何参考点，采用自监督方式训练：将演示帧视为canonical帧，合成随机旋转帧作为训练样本，通过旋转一致性损失优化
Card 05 数据集与资源

数据集与资源

  • 主要仿真数据集为LIBERO基准，包含Spatial、Object、Goal、Long四个语言条件机器人操作任务suite；真实机器人实验采用SO-101机器人的3个操作任务（pick-and-place、block stacking、block sorting）
  • 模型规模：SAVLA总可训练参数量为103.3M，匹配参数的GR00T N1.5基线可训练参数量为100.8M，VLM骨干全部冻结，canonicalization头参数量仅0.09M
  • 训练资源：论文未明确说明具体使用的GPU/TPU型号，优化配置为AdamW优化器、学习率1e-4、动作头训练batch size 16、canonicalizer单独训练3000步、batch size 32
Card 06 评估与结果

评估与结果

  • 评估环境：仿真场景采用LIBERO四个suite，每个suite评估500集、3次随机种子取平均；真实机器人场景采用SO-101机器人，每个任务评估20集
  • 主要评估指标：任务成功率（%）
  • 关键实验结果：1. 标准任务性能：SAVLA在LIBERO四个suite的平均成功率达到91.6%，较GR00T N1.5基线的86.5%提升5.1个点，Goal与Long场景分别提升5.9与12.6个点 2. 旋转泛化性能：在绕重力轴-30°到+30°的13个场景旋转角度下，平均成功率从基线的40.5%提升至81.8%，LIBERO-Goal场景从41.5%提升至90.4%，显著优于旋转数据增强的基线（warped增强69.1%、re-rendered增强74.5%） 3. 消融实验结果：等变动作头与canonicalization模块缺一不可，完整SAVLA为90.4%，移除canonicalization后降至46.0%，基线上添加canonicalization后为63.5%；替换估计旋转为真实旋转后提升至90.9%，替换warp为真实canonical视角后提升至97.3%，剩余误差主要来自图像几何变形 4. 数据效率：在10%低演示数据场景下，SAVLA平均成功率为57.1%，较基线的48.3%提升8.8个点，数据量越少优势越明显 5. 真实机器人性能：三个真实任务的平均成功率达71.7%，较基线的61.7%提升10个点，所有单任务成功率均有提升
