Card 02 论文概述

论文概述

  • 针对密集视觉标记输入的视觉-语言-动作（VLA）策略缺乏显式机制调节视觉标记对策略计算影响力的局限，提出DIVA模块，用于在不丢失场景上下文的前提下衰减弱相关的视觉证据
  • DIVA采用“锚定-衰减”设计，结合高层任务意图与低层局部视觉证据估计标记级相关性锚点，并在输入空间和backbone潜空间同步应用衰减，无需外部grounding监督
  • 论文旨在解决任务无关视觉内容干扰VLA策略动作预测的问题，提升策略在标准任务、扰动场景及真实机器人环境下的鲁棒性
Card 03 核心贡献

核心贡献

  • 识别了密集标记VLA策略的核心局限：未提供根据任务相关性控制视觉标记影响力的显式机制，易受任务无关物体干扰
  • 提出DIVA双空间意图感知视觉衰减框架，创新性地结合高层任务意图与低层视觉证据构建patch-wise相关性锚点，实现输入空间与潜空间的互补衰减
  • 在LIBERO、零样本LIBERO-Plus及真实机器人操作任务上验证了DIVA的有效性，消融实验证明了各组件设计的必要性
Card 04 方法描述

方法描述

  • 核心方法包含三个模块：①Grounded Text Pooling（GTP）：计算指令token与投影视觉token的局部兼容度，减去全局平均兼容度得到grounded分数，通过softmax池化生成融合局部视觉证据的紧凑任务意图表示；②意图感知视觉相关性锚定：将每个视觉token与任务意图表示拼接，经轻量自注意力上下文化后输出标量logit，经sigmoid映射为[0,1]区间的相关性锚点；③双空间视觉衰减：显式输入空间衰减直接将投影视觉token乘以对应锚点，隐式潜空间衰减在backbone每一层对低相关性锚点对应的潜状态做加权插值，持续维持衰减效果
  • 训练目标结合动作预测的L1回归损失与相关性预算损失，约束所有视觉token的平均锚点接近预设值，避免所有标记被判定为高相关
  • 创新点在于“锚定-衰减”的双空间设计，无需外部grounding标签即可实现任务相关的视觉证据调节，同时保留完整视觉标记序列
Card 05 数据集与资源

数据集与资源

  • 使用仿真数据集：LIBERO（包含Spatial、Object、Goal、Long四个操作任务套件，共40个任务）、LIBERO-Plus（包含7类可控扰动：相机视角、机器人状态、语言、光照、背景、传感器噪声、物体布局，共10030个评估变体）
  • 真实世界数据集：UFACTORY UF850机器人平台上的VR遥操作演示数据，包含简单拾取放置、长程操作、视觉grounding操作三类任务套件，额外包含未知物体干扰、未知背景两种分布外场景
  • 模型基于OpenVLA-OFT构建，使用LoRA rank 32进行轻量微调
  • 训练资源：仿真训练使用8张NVIDIA L20 GPU，真实机器人训练使用4张NVIDIA L20 GPU
Card 06 评估与结果

评估与结果

  • 评估环境：LIBERO标准基准（每个任务50轮评估，共2000轮试验，以稀疏任务完成谓词判定成功）、LIBERO-Plus零样本基准（仅在标准LIBERO上训练，无扰动数据微调，按变体数量加权计算总分）、真实物理机器人环境（每个任务-条件组合25轮试验）
  • 主要评估指标：任务成功率、LIBERO-Plus加权总分
  • 关键实验结果：①LIBERO标准任务上平均成功率从OpenVLA-OFT的96.6%提升至98.0%，在所有四个任务套件上均优于基线；②LIBERO-Plus零样本得分从69.6提升至72.6，在相机、光照、噪声、背景、布局等视觉相关扰动上提升显著，5个随机种子下的得分波动为72.60±0.43%；③真实世界任务在所有测试条件下（标准场景、未知物体干扰、未知背景）均优于OpenVLA-OFT，在需要区分相似视觉候选的操作任务上增益最大；④消融实验验证了Grounded Text Pooling与双空间衰减设计的互补作用，预算-阈值组合0.4/0.3为最优配置
