Card 02 论文概述

论文概述

  • 提出 ProtoAct 框架，将自由形式的生物湿实验协议转化为结构化的、状态感知的、可被机器人执行的动作序列，解决协议中隐含操作、状态依赖和参数上下文难以被机器直接理解的问题。
  • 构建 BioP2E 数据集，手动标注 22 个细胞培养协议，包含监控条件、可执行子任务和接地动作调用，用于评估协议解析和机器人任务生成。
  • 建立多级基准，验证 ProtoAct 在协议解析、动作序列生成以及仿真和真实机器人执行中的有效性。
Card 03 核心贡献

核心贡献

  • 首次提出面向湿实验具身执行的协议接地（protocol-grounding）形式化，将自由文本实验指令与状态感知任务表示和参数化机器人动作相连接。
  • 构建 BioP2E 数据集，将 22 个细胞培养协议手工标注为 258 个监控条件、910 个可执行子任务和 962 个接地动作调用，为评估和机器人任务构建提供资源。
  • 建立多级生物协议接地基准，并通过 VLA 模型训练和仿真/真实机器人执行验证了接地表示的有效性。
Card 04 方法描述

方法描述

  • 使用 ProtoRAG 检索增强生成，从手工标注的示例知识库中检索相似协议片段，辅助大语言模型进行上下文敏感的协议解析，生成监控条件和子任务序列。
  • 采用 RefineChecker 后验检查与修正，通过用户提供的实验特定信息对初始解析结果进行验证和修订，解决缺失动作、参数、顺序错误和解析粒度不当四类缺陷。
  • 通过 ActSchema 将修正后的自然语言中间表示映射为受约束的 JSON 动作函数序列，定义监控条件类型、动作原语名称和参数模式，确保输出格式统一且可自动评估。
  • 整体流程先产生可人读的监控条件与子任务，再转换为机器可执行的动作序列，形成从语义解析到动作映射的中间表示，支持人工检查与下游任务学习。
Card 05 数据集与资源

数据集与资源

  • 数据集：BioP2E，包含 22 个细胞培养协议，其中 2 个用于 ProtoRAG 知识库，20 个用于评估；标注包括 4 类监控条件、30 种动作原语，共计 258 个监控条件、910 个子任务、962 个动作函数。
  • 模型：评估了 Qwen3-max、Qwen-max、GPT-5.3、DeepSeek-v3.2、DeepSeek-r1、Kimi-k2、GLM-4.5 等 7 个大语言模型，未明确给出参数规模。
  • 训练资源：在仿真和真实机器人验证中，使用 SmolVLA 和 π₀ 模型，基于 LeRobot 框架进行训练，未详细说明 GPU 资源。
Card 06 评估与结果

评估与结果

  • 评估基准：BioP2E 的 20 个协议，使用自动指标（F1、BLEU、SciBERTScore、归一化编辑距离）和 GPT-5.3 语义评估。
  • 主要指标：监控条件类型和动作原语 F1，参数字段 F1，参数值 BLEU 和 SciBERTScore，动作序列顺序一致性（归一化编辑距离）。
  • 关键结果：

- GPT-5.3 在动作原语 F1（0.95）、参数字段 F1（0.96）和序列一致性（0.09）上表现最佳，Qwen3-max 在参数值相似度（BLEU 0.87，SciBERT 0.98）上最优。

- 消融实验表明 ProtoRAG、RefineChecker 和 ActSchema 对监控条件识别、动作生成和序列一致性均有互补贡献。

- 仿真任务中，SmolVLA 成功率达到 59%–98%，π₀ 达到 34%–96%；真实机器人任务中两者均完成动作序列，验证了 ProtoAct 输出的子任务可支持示教收集、VLA 训练和实体执行。
