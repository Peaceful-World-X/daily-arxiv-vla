Card 02 论文概述

论文概述

  • 提出 CHASE-VLA，一个针对扩散型视觉-语言-动作（VLA）模型的后训练量化（PTQ）框架，重点解决动作专家（AE）模块的低比特量化难题
  • 核心问题是扩散型 AE 在迭代去噪和策略查询过程中，激活值范围随去噪步和动作上下文剧烈变化，导致静态校准尺度严重失配
  • 通过利用先前生成的动作块（包括未执行的后缀）和去噪步分组信息，动态估计激活量化尺度，在不修改预训练策略的前提下实现 W4A4 量化
Card 03 核心贡献

核心贡献

  • 识别并分析了扩散型 VLA AE 中跨去噪步和动作上下文的激活尺度不匹配是低比特 PTQ 的核心障碍
  • 提出 Chunk-Aware Scale Estimation，使用上一轮策略查询生成的动作块（含未执行后缀）作为因果信号，结合去噪步组预测自适应尺度因子
  • 首次在 VLA PTQ 中将 W4A4 量化目标从 MLP 层扩展到 MLP 与注意力投影层，覆盖更广泛的 AE 线性计算
  • 在 LIBERO 基准的多个 VLA 模型（π₀.₅、GR00T N1.6、CogACT）上验证，W4A4 精度下任务成功率接近或达到 FP16 水平，并显著降低存储和内存流量
Card 04 方法描述

方法描述

  • 基于静态 PTQ 的基础，为每个 AE 线性层和去噪步组计算初始尺度（calibration-derived base scale）
  • 引入轻量级预测器（f_φl），输入为标准化后的上一个动作块向量，输出每组去噪步的 log-scale 调整值和不确定性估计
  • 通过不确定性感知的指数变换将调整值转换为乘性因子（γ_{t,l,m}），与初始尺度相乘得到最终的自适应激活尺度
  • 训练预测器时，利用标定轨迹中前一块与当前块激活统计的 log-ratio 作为回归目标，结合 pinball 损失和高斯负对数似然进行离线学习
  • 在推理时，每次策略查询后立即用新生成的动作块更新尺度，供下一轮 AE 去噪迭代使用，形成 recurrent scale update 机制
Card 05 数据集与资源

数据集与资源

  • 评估数据集：LIBERO 四个任务套件 — Spatial, Object, Goal, Long，每个任务运行 20 个 episode
  • 测试模型：π₀.₅（π0.5）、GR00T N1.6、CogACT，覆盖不同 AE 架构和规模
  • 校准数据：从非评估套件收集少量轨迹（默认 6 条轨迹）
  • 硬件环境：在 NVIDIA A100 GPU 上测量 AE 延迟（batch size = 1）
Card 06 评估与结果

评估与结果

  • 主要指标：任务成功率（LIBERO 平均成功率），95% 置信区间，AE 延迟和内存/存储开销
  • 在 π₀.₅ 上，CHASE-VLA（W4A4）平均成功率达到 97.3%，与 FP16 的 97.1% 相当，显著优于 QuantVLA (expanded) 的 95.3% 及 Q-DiT、PTQ4DiT
  • 在 GR00T N1.6 上达到 91.5%，而 QuantVLA (expanded)、Q-DiT、PTQ4DiT 仅 49.4%、22.9%、20.0%
  • 在 CogACT 上达到 90.5%，比静态 PTQ 方法提高 10% 以上
  • 效率提升：AE 线性层权重存储减少 73.4%，单块内存流量降低约 71%（π₀.₅ 和 GR00T N1.6），AE 推理延迟相对 FP16 降低 21.8%（π₀.₅）和 12.7%（GR00T N1.6），预测器存储开销仅占节省存储的约 1.26%
