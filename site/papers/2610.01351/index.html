Card 02 论文概述

论文概述

  • 提出了一种基准无关的行为鲁棒性评估框架，通过表征输入扰动下成功轨迹的执行方式来衡量VLA模型的行为鲁棒性，而非仅依赖任务成功率（TSR）
  • 在广泛使用的 LIBERO 和 LIBERO-Plus 基准上实施该框架，评估了3个SOTA VLA模型在4个任务套件和7种扰动条件下的表现
  • 核心发现：扰动会改变成功轨迹的行为（包括运动平滑度、效率和夹爪行为），这种现象无法仅通过TSR推断；两个策略可能保持相同的成功率，但在成功轨迹上的行为质量存在显著差异
Card 03 核心贡献

核心贡献

  • 提出了基准无关的行为评估方法论，补充TSR与轨迹级行为指标（持续时间、总夹爪移动量、笛卡尔急动度、关节急动度、笛卡尔路径长度、关节路径长度）
  • 从典型行为变化和行为变异性两个维度系统地表征扰动效应
  • 证明了对SOTA VLA模型而言，任务成功的鲁棒性并不等同于成功执行行为的鲁棒性；即使任务成功得以保持，成功轨迹也可能发生实质性变化
  • 扩展了LIBERO和LIBERO-Plus基准以支持行为鲁棒性分析，并公开了评估代码以促进可重复研究
Card 04 方法描述

方法描述

  • 轨迹级行为评估指标：采用RoboEval中的Cartesian jerk、joint jerk、Cartesian path length、joint path length，并补充total gripper movement；所有导数使用10 Hz模拟器控制频率计算
  • 量化典型行为变化：计算每个任务在扰动条件下相对于无扰动基线的平均轨迹指标的中位数百分比变化（Δ），并使用Mann-Whitney U检验和Benjamini-Hochberg FDR校正（α=0.05）评估统计显著性
  • 量化行为变异性：使用中位数绝对偏差（MAD）描述行为分布的变化，计算MAD的百分比变化以评估扰动是否改变了成功轨迹的行为一致性
  • 仅评估成功轨迹，以揭示TSR单独报告时所掩盖的问题；基线为原始无扰动任务，条件为扰动任务
Card 05 数据集与资源

数据集与资源

  • 数据集：LIBERO基准的4个任务套件（LIBERO-Spatial、LIBERO-Long、LIBERO-Goal、LIBERO-Object）及LIBERO-Plus的7种扰动条件
  • 扰动类型：背景纹理(Back.)、相机视角(Cam.)、语言指令(Lan.)、光照(Light)、物体属性(Obj.)、机器人初始状态(Rob.)、传感器噪声(Sen.)
  • 评估模型：π₀.₅、VLANeXt、OpenVLA-OFT（仅在Spatial套件上评估，因其他套件TSR大幅下降）
  • 训练与评估资源：使用vla-eval评估工具包；代码开源于GitHub；所有模型均在所有LIBERO套件上联合微调
  • 实验规模：基线每个任务50次rollout，每个扰动变体2次rollout（物体扰动为1次）
Card 06 评估与结果

评估与结果

  • 评估环境：基于LIBERO/LIBERO-Plus仿真器，使用10 Hz控制频率
  • 主要指标：任务成功率(TSR)、持续时间、笛卡尔/关节路径长度、平均笛卡尔/关节急动度、P95笛卡尔急动度、总夹爪移动量、MAD变异性
  • 关键实验结果：

- π₀.₅在LIBERO-Spatial上原始TSR为98.8%，扰动下平均TSR为90.3%；相机扰动导致持续时间增加+22.5%、Cartesian Jerk +24.1%、Gripper movement +37.8%、P95 Cartesian Jerk +48.7%（多数任务显著）

- VLANeXt在LIBERO-Spatial上原始TSR为99.2%，扰动下平均TSR为81.9%；相机扰动下P95 Cartesian Jerk增加+12.8%，鲁棒性扰动下P95 Cartesian Jerk增加+15.5%

- OpenVLA-OFT在LIBERO-Spatial上原始TSR为97.8%，扰动下平均TSR降至67.9%；相机扰动下Cartesian Jerk +35.3%、Gripper movement +37.7%、P95 Cartesian Jerk +68.7%；鲁棒性扰动下Gripper movement +79.5%、P95 Cartesian Jerk +54.7%

- 相同扰动条件下，不同模型可能表现出可比的TSR，但在成功轨迹上的行为却存在实质性差异，证明仅靠TSR不足以全面评估模型部署就绪性
