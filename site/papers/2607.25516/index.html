Card 02 论文概述

论文概述

  • 针对视觉-语言-动作（VLA）模型中多模态融合的动态性问题，提出一种模型无关的测试时框架 IDR（Infer-diagnose-refine），无需重新训练即可在推理阶段动态调整视觉观测的重要性
  • 通过因果推断方法，在事实场景和反事实场景下推断动作，诊断视觉观测的因果效应，并据此精细化动作预测
  • 解决的核心问题是：VLA模型在不同执行阶段、不同架构和不同环境中对视觉信息的依赖程度动态变化，而现有方法难以在测试时自适应地调整这种依赖关系
Card 03 核心贡献

核心贡献

  • 提出 IDR 框架，一种训练免费的模型无关测试时模态适配框架，通过"推断-诊断-细化"三阶段流程，在每个时间步估计视觉重要性并动态精细化动作
  • 设计 因果感知动作细化器（Causality-Aware Action Refiner），通过零填充干预（zero-padding interventions）推断反事实动作，基于范数量化（norm-based quantification）诊断模态特定的因果效应
  • 提出 门控残差融合（gated residual fusion）机制，根据诊断的因果效应自适应地注入视觉校正，同时限制对低级控制的过度扰动
  • 在四个VLA主干网络、多个仿真基准（LIBERO、SIMPLER、CALVIN）和真实世界操作任务上验证了框架的普适性和有效性
Card 04 方法描述

方法描述

  • 推断阶段（Infer）：对视觉观测和本体感觉状态分别进行零填充干预（do(V=0ᵥ) 和 do(S=0ₛ)），将原始输入替换为同维度的全零张量，从而在冻结的VLA模型上推断反事实动作 a_no_img,t 和 a_no_prop,t
  • 诊断阶段（Diagnose）：计算事实动作与反事实动作之间的偏差向量 Δ_img,t 和 Δ_prop,t，通过L₂范数量化各自的因果效应 E_img,t 和 E_prop,t，作为当前时间步视觉重要性的诊断信号
  • 细化阶段（Refine）：设计门控机制 gₜ = 𝕀[E_img,t < τ]，当视觉效应低于阈值 τ 时激活门控，通过公式 a_final,t = a_base,t + gₜ·(αΔ_img,t + w_prop,t·u_prop,t) 进行残差融合，其中 w_prop,t 动态缩放本体感觉校正，u_prop,t 经裁剪限制高频抖动
  • 关键参数设置：α=0.08（视觉细化强度），β=0.05（正则化强度），λ=0.1（裁剪边界）
Card 05 数据集与资源

数据集与资源

  • 仿真基准数据集：

- LIBERO：包含Spatial、Object、Goal、Long四个任务套件

- SIMPLER：评估Google Robot和WidowX两种机械臂，包含Visual Matching (VM) 和Variant Aggregation (VA) 设置

  • 真实世界任务：Fold Clothes（叠衣服）和 Organize Table（整理桌面）长程序列任务
  • 评估的VLA主干网络：

- Large (≥4B)：UniVLA, UnifiedVLA, OpenVLA, DD-VLA, PD-VLA, MolmoAct, ThinkAct, CoT-VLA, WorldVLA

- Small (<4B)：π₀, SmolVLA, GR00T-N1

- Tiny (<1B)：GraspVLA, VLA-OS, UniAct

- 重点评估：π₀.₅, X-VLA, VLA-Adapter, OpenVLA-OFT

Card 06 评估与结果

评估与结果

  • 评估环境：仿真环境在LIBERO、SIMPLER、CALVIN官方评估协议下测试；真实世界在真实机器人平台上验证
  • 主要评估指标：任务成功率（%）、平均完成子任务数（Avg Len）、5/5完成率、效率-成功权衡（完成时间与成功率）
  • 关键实验结果：

- LIBERO基准：IDR在全部四个主干上均有提升，VLA-Adapter提升+1.40%，π₀.₅提升+1.25%，OpenVLA-OFT提升+0.90%，X-VLA提升+0.45%

- SIMPLER基准：在Variant Aggregation (VA) 设置下实现最大提升+6.33%，证明视觉适应性在分布偏移下的关键作用

- CALVIN基准：平均完成长度从4.22提升至4.44，5/5完成率从70.5%提升至77.3%

- 真实世界：基线模型在执行Fold Clothes和Organize Table任务时提前停滞失败，而IDR通过测试时适配成功完成完整操作序列

- 诊断发现：视觉重要性模式随环境、模型架构和操作阶段动态变化（如X-VLA在LIBERO中本体感觉主导，在SIMPLER中视觉主导）
