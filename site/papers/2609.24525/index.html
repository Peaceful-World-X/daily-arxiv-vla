Card 02 论文概述

论文概述

  • 针对现有视觉-语言-动作（VLA）模型主要依赖2D观测、导致空间感知能力不足与精确动作生成困难的问题，提出 Bridge3D 分层3D增强框架
  • 通过 Implicit Fusion（隐式融合）与 Explicit Conditioning（显式条件生成）两种协同策略，使预训练2D VLA模型同时获得高层3D空间理解与低层精确动作控制能力
  • 在仿真基准 RoboTwin 2.0 与真实双臂机器人平台上验证了方法在高精度、空间敏感操作任务中的有效性，显著提升数据效率与空间泛化能力
Card 03 核心贡献

核心贡献

  • 提出 Bridge3D 框架，通过结合隐式空间先验融合与显式3D几何引导，弥合预训练2D VLA模型中的3D感知-动作差距
  • 设计 Implicit Fusion 策略，采用轻量级残差适配器将3D基础模型（VGGT）的几何特征融入VLM视觉token，实现高效的高层空间理解
  • 设计 Explicit Conditioning 策略，构建3D语义点场并在动作去噪过程中通过空间交叉注意力引入显式度量空间引导，实现精确的低层动作控制
  • 提出基于逐层线性探针的分析方法，识别空间信息退化的关键层（#7–11），仅在这些瓶颈层引入显式条件模块，显著提升学习效率
Card 04 方法描述

方法描述

  • 双流Token编码与残差融合：采用双流架构，语义流由预训练VLM提取视觉特征，几何流由VGGT提取多视角几何特征；通过两层MLP残差适配器将几何token映射至VLM隐层空间后与视觉token残差相加，在不破坏预训练表示空间的前提下增强3D感知
  • 3D语义场构建：利用Grounded-SAM生成实例掩码、DINOv3提取密集语义特征，将2D特征依据深度信息提升至3D空间，构建保留原始点云结构的3D语义点场（操作相关点1,536个，背景点256个），桥接低层几何与高层语义
  • 3D条件动作生成：对动作隐状态应用FiLM调制与3D RoPE位置编码后，通过空间交叉注意力机制查询3D语义场中的点云特征，使动作生成过程在共享机器人坐标系下获得显式几何约束
  • 逐层线性探针分析：冻结VLA主干，训练线性岭回归模型预测各扩散块的末端执行器3D坐标，定位空间感知能力退化的层区间，实现显式条件模块的层选择性插入，避免冗余计算与语义破坏
Card 05 数据集与资源

数据集与资源

  • 仿真基准：RoboTwin 2.0（大规模双臂操作仿真基准，选取10项代表性任务，每任务50条演示）
  • 真实机器人平台：KEENON XMAN-R1 双足人形机器人、AgileX PiPER 机械臂
  • 真实任务：6项桌面操作任务（Insert Flower、Hang Mug、Put Object Cabinet、Sweep Trash、Place Cup Rack、Clear Trash），每任务100条演示
  • 模型基座：RDT-1B、GR00T-N1.5（Bridge3D仅添加轻量级残差适配器与空间交叉注意力模块，不改变主干规模）
  • 训练资源：仿真实验使用4块 NVIDIA RTX 4090 GPU；真实世界推理使用配备 NVIDIA RTX 4090 GPU 的工作站
  • 优化配置：AdamW优化器，学习率 1×10⁻⁴，冻结VLM主干，仅优化残差适配器与动作专家
Card 06 评估与结果

评估与结果

  • 评估环境：RoboTwin 2.0 仿真（干净场景与随机化场景）、真实桌面操作环境、未见高度偏移的零样本空间泛化测试（1cm、3cm、5cm）
  • 评估指标：任务成功率（Success Rate, SR）
  • 关键实验结果：

- 仿真：RDT-Bridge3D 在RoboTwin 2.0干净场景中平均成功率达 84.8%，相对 RDT 与 GR00T-N1.5 分别提升26.1%与34.6%，超过 π₀ 14.0个百分点，优于 Spatial Forcing（77.1%）与 PointVLA（76.0%）

- 真实世界：RDT-Bridge3D平均成功率达 49.0%，相对RDT基线提升42.9%，超过Spatial Forcing 11.7个百分点；在需要厘米级精度的Insert Flower任务中成功率接近基线两倍

- 数据效率：在Grab Roller任务上仅需约 6.1倍 fewer训练样本即可达到与基线相当的性能（74%成功率），且在所有数据规模下均持续优于基线

- 空间泛化：在未见高度偏移的Click Bell任务中，Bridge3D表现出比RDT基线更强的执行稳定性，证明其对3D空间变化的鲁棒适应性
