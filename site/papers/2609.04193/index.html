Card 02 论文概述

论文概述

  • 提出 GIFT（Guided Intermediate Feature Training），一种架构灵活的框架，通过几何、可供性和目标三类控制相关结构引导中间特征训练，以弥合视觉丰富性与控制效用之间的“动作充分性差距”。
  • 该框架可应用于视觉-语言-动作（VLA）策略和世界-动作模型（WAM），在不改变各自动作生成机制的前提下，通过辅助监督增强中间特征的任务相关性。
  • 主要解决现有VLA和WAM中，端到端动作监督或视觉预测无法保证中间特征保留对机器人控制最有用的物理和任务结构的问题。
Card 03 核心贡献

核心贡献

  • 识别出VLA和WAM共有的动作充分性差距，并提出通过互补的几何、可供性和目标监督来结构化中间特征。
  • 在三种不同的策略范式下实例化同一目标：GIFT-VLA（语义中心直接动作策略）、GIFT-WAM-Fast（从世界模型特征直接动作）和GIFT-WAM-IDM（未来条件逆动力学），保持各自的动作生成方式不变。
  • 广泛的仿真和真实机器人实验表明，在零样本迁移、铰接物体交互和高精度操作上，GIFT变体相比匹配基线均取得一致性提升，且无注入设计（不将辅助预测作为动作输入）表现更优，证明结构化中间特征的内化效果。
Card 04 方法描述

方法描述

  • 几何引导：使用冻结的VGGT几何基础模型作为教师，将中间特征分解为方向和尺度，通过角度对齐损失和尺度回归损失与教师特征对齐，为运动可行性提供空间结构。
  • 可供性引导：定义指令条件化的结构化对象-末端执行器关系，包括实体角色、对象中心末端执行器位姿和闭合状态，利用可学习查询从视觉令牌中回归20维交互目标，编码交互对象和配置。
  • 目标引导：针对每个视图构建指令相关的二值目标掩码，引导中间特征预测任务相关区域，通过二元交叉熵和Dice损失实现图像空间定位。
  • 跨范式实例化：

- GIFT-VLA：基于Qwen3-VL的StarVLA-OFT，增加几何对齐、可供性令牌和目标令牌，通过BridgeAttention动作头输出动作。

- GIFT-WAM-Fast：在Fast-WAM的当前帧视频令牌上附加三个目标，保持视频和动作扩散的混合训练。

- GIFT-WAM-IDM：在逆动力学WAM的当前帧令牌上训练相同目标，保留先想象后行动的未来条件机制。

  • 无注入设计：默认不将可供性和目标特征传入动作生成器，仅通过梯度塑造共享中间特征，几何信息直接融入视觉令牌，无需额外条件。
Card 05 数据集与资源

数据集与资源

  • LIBERO：四个任务套件（Spatial, Object, Goal, Long），每套件10个任务，Franka Emika Panda机器人。
  • LIBERO-Plus：在LIBERO基础上施加七种分布偏移（视角、机器人初始化、语言、光照、背景纹理、传感器噪声、物体布局）。
  • RoboCasa：GR1人形机器人，24个任务（18个抓放、6个铰接物体），1000次演示/任务。
  • 模型规模：GIFT-VLA基于Qwen3-VL-4B-Instruct（4B参数）；WAM变体基于视频扩散Transformer。
  • 训练资源：32块GPU，每GPU批大小8，全局批大小256，训练60000步。
Card 06 评估与结果

评估与结果

  • 评估基准：LIBERO（域内成功率）、LIBERO-Plus（零样本鲁棒性）、RoboCasa（新环境与机器人形态）。
  • 主要指标：任务成功率（%）。
  • 关键结果：

- LIBERO-Plus：GIFT-VLA、GIFT-WAM-Fast和GIFT-WAM-IDM分别达到79.6%、72.6%和87.8%，比对应基线（StarVLA-OFT、Fast-WAM、Fast-WAM-IDM）高出4.6、12.6和5.2个百分点。

- RoboCasa：三个GIFT变体分别达到61.4%、83.6%和82.3%，优于基线12.6、9.0和8.4个百分点，铰接物体任务增益尤为显著。

- 消融实验：单引导信号消融表明几何、可供性和目标监督互补；无注入变体优于注入变体，证实GIFT将任务相关结构内化入中间特征，无需依赖辅助条件。

- 真实世界实验：在未见视觉和空间扰动下，GIFT展现出高精度操作鲁棒性。
