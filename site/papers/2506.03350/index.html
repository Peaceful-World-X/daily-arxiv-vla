Card 02 论文概述

论文概述

  • 首次针对机器人视觉-语言-动作（VLA）模型开展对抗攻击研究，将大语言模型（LLM）越狱攻击 adapted 为对 VLA 的完全控制权获取
  • 核心目标是证明通过在初始输入中添加对抗性文本提示，即可驱动机器人执行任意目标动作或动作序列，且攻击在物理世界 rollout 中具有持久性
  • 区别于传统 LLM 越狱，VLA 攻击无需语义上的“有害”关联，而是聚焦于对机器人底层动作空间的完全控制权（control authority）
Card 03 核心贡献

核心贡献

  • VLA 威胁模型：识别了通过文本提示诱导目标机器人动作的现实威胁模型
  • VLA 攻击算法：提出了一系列 token 级攻击，可从目标 VLA 中诱导固定动作或动作序列
  • 目标动作可达性：在 OpenVLA 的多个微调版本上，攻击成功率普遍达到 90% 以上，证明动作空间几乎完全可达
  • 攻击持久性：攻击可在多个 rollout 步骤中持续生效，即使模型观察新的视觉输入，相比基线提升最多 28 倍
  • 环境无关性：攻击可在仿真与真实世界环境（HYDRA 与 SIMPLER）之间成功迁移
Card 04 方法描述

方法描述

  • 采用 GCG（Greedy Coordinate Gradient） 算法，通过优化对抗性后缀文本，最小化生成目标动作序列的负对数似然损失
  • 单步攻击：在单张图像上优化对抗提示，以生成特定的目标动作（7 维离散动作，每维 256 个 bin）
  • 持久性攻击：将损失函数扩展为对多张图像嵌入的求和，使对抗提示在视觉输入变化时仍能持续诱导目标动作
  • 迁移攻击：在源模型上优化攻击字符串后，转移到目标模型（包括架构迁移与集成迁移）
  • 攻击在文本嵌入空间操作，通过 VLA 模板将对抗 token 插入标准指令后（如 "What action should the robot take to [INSTRUCTION]? Out:"）
Card 05 数据集与资源

数据集与资源

  • 数据集：LIBERO 基准（Libero-Goal、Libero-Object、Libero-Spatial、Libero-10），用于微调 OpenVLA
  • 模型：OpenVLA（7 自由度机械臂，每维度 256 个离散 bin，动作空间规模 $7^{256}$），以及 TraceVLA、CogACT、OpenPi0
  • 评估环境：HYDRA（真实世界）与 SIMPLER（仿真），均来自 Open-X-Embodiment 数据集
  • 训练资源：使用 H100 GPU，单次成功攻击平均需要 30–110 步优化（约 3–10 分钟），远快于聊天机器人越狱（平均超 1 小时）
