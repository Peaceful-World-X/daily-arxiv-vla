Card 02 论文概述

论文概述

  • 针对VLA模型部署时出现的系统性执行偏差问题，现有方法或需重训练基础设施、或无法修正幅度失配，本文提出CorrectVLA框架，无需修改VLA策略权重即可实现推理时的动作修正
  • 通过分析VLA部署失败模式，明确仅「执行偏差」类失败（策略语义正确但动作幅度失配）可被推理时修正，为方法提供适用边界
  • 核心目标是将单次任务级自然语言反馈转化为全 rollout 通用的动作幅度调整，以最小人工成本恢复策略执行成功率
Card 03 核心贡献

核心贡献

  • 提出VLA部署失败的分类 taxonomy，在LIBERO-90上识别出4类跨模型稳定失败模式，明确仅执行偏差类失败 amenable 到推理时修正，为部署适配提供操作边界
  • 设计CorrectVLA三阶段语言-动作 grounding 机制，将稀疏自然语言反馈映射为密集的每时间步、每维度动作调整，无需更新策略权重，单次反馈即可泛化到所有执行 rollout
  • 在仿真和真实机器人场景验证有效性：仿真下恢复分布内/外任务的执行偏差，真实机器人环境偏移下成功率从10%恢复到95%，显著优于自主修正的LLM基线
Card 04 方法描述

方法描述

  • CorrectVLA全程冻结VLA策略权重，仅通过叠加动作偏差实现修正，无需重训练或逐回合人工干预，核心为三阶段反馈处理流程
  • 第一阶段（结构化参数提取）：调用LLM从自然语言反馈中提取4个结构化参数：动作维度（x/y/z/roll/pitch/yaw/夹爪）、调整方向（+1/-1）、幅度术语（slightly/more/much）、修正时间窗口
  • 第二阶段（幅度量化）：将自然语言幅度术语映射到预定义的数值区间（slightly对应[0.3,0.5]、more对应[0.5,0.8]、much对应[0.8,1.0]），结合方向生成带符号的修正幅度
  • 第三阶段（时间分布）：构造分段线性包络线，将修正平滑分布在指定时间窗口内，避免突兀动作跳变，确保修正与策略动态兼容
  • 创新点：首次明确VLA执行偏差的可纠正边界，以极低人工成本（单次任务级反馈）实现跨rollout的通用修正，解决现有方法重训练成本高、无法处理系统性幅度误差的痛点
Card 05 数据集与资源

数据集与资源

  • 仿真测试数据集：LIBERO benchmark，包含LIBERO-90（90个OOD任务）、LIBERO-Spatial、LIBERO-Object、LIBERO-Goal、LIBERO-10四个分布内子集，机器人平台为MuJoCo模拟的Franka Panda 7-DoF
  • 真实机器人数据集：使用DROID数据集微调基础策略π0.5，实验平台为UFactory xArm7 + Robotiq 2F-85夹爪 + 3个Intel RealSense相机
  • 模型规模：基础策略包括7B参数的OpenVLA-OFT（基于Llama 2 7B+ViT，在40个LIBERO任务微调）、π0.5（在LIBERO/DROID数据上微调）；语言模型使用Claude Sonnet 4.5进行反馈结构化，GPT-5 mini作为自主修正基线
  • 训练资源：无需额外训练VLA策略，仅需标准推理资源处理自然语言反馈；真实机器人实验硬件为NVIDIA RTX 4090、AMD Ryzen 7 5700X、64GB RAM
Card 06 评估与结果

评估与结果

  • 评估环境：仿真场景覆盖LIBERO的分布内（40个任务，2000次rollout）和分布外（90个任务，450次rollout）设置；真实机器人场景为机器人底座移位引入的分布偏移，覆盖相同物体相同位置、相同物体不同位置、不同物体不同位置3种泛化条件
  • 评估指标：任务成功率（Success Rate）、失败任务恢复率（Recovery Rate）
  • 关键实验结果：

- 失败 taxonomy 验证：OpenVLA-OFT和π0.5的部署失败模式分布一致，任务误解（~47%-50%）、感知失败（~22%-25%）、执行偏差（~22%-23%）、多步规划失败（~5%-6%），仅执行偏差可被推理时修正

- 仿真分布内场景：基础策略成功率93.0%，CorrectVLA恢复65/139个失败任务，恢复率46.8%，整体成功率提升至96.3%；自主修正的LLM基线无任何恢复效果

- 仿真分布外场景：基础策略成功率27.1%，CorrectVLA恢复33/328个失败任务，恢复率10.1%，整体成功率提升至34.4%

- 真实机器人场景：基础策略在环境偏移后成功率从95%降至10%，CorrectVLA单次任务级修正后整体恢复至95%（19/20），在3种泛化条件下分别达到100%、100%、80%的成功率
