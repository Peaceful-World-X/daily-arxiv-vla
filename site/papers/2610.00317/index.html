Card 02 论文概述

论文概述

  • 针对 VLA 模型中 chunk-level 训练仅优化局部动作似然而忽略长期任务成功的问题，提出 DriftOPD 框架
  • 将序列级反向 KL 散度分解为局部动作块匹配项与未来潜力项，实现无需教师模型、无需在线交互的序列级策略蒸馏
  • 旨在将多步采样的 VLA 动作专家蒸馏为单步策略生成，同时缓解测试时分布偏移和高推理延迟问题
Card 03 核心贡献

核心贡献

  • 形式化序列级 on-policy 蒸馏 (OPD)，通过最小化动作序列分布间的反向 KL 散度，将其分解为局部反向 KL 项和未来潜力项
  • 提出 DriftOPD 方法，利用单步漂移目标 (drifting objective) 实现局部反向 KL 优化，并采用离线演示训练的 Q 函数评判器 (critic) 近似未来项，实现免教师、免 rollouts 的单步蒸馏
  • 在多种 VLA 架构（包括 π₀.5、GR00T N1.5/N1.6 等）的仿真与真实机器人实验中，DriftOPD 普遍优于现有单步蒸馏基线，任务成功率接近多步教师策略，且在数据稀缺场景下训练更稳定
Card 04 方法描述

方法描述

  • 序列级反向 KL 分解为 L_Local（当前动作块分布匹配）和 L_Future（对未来轨迹的长期影响）
  • 局部项采用核密度估计 (KDE) 平滑的样本空间漂移场优化，仅需演示数据中的单个正样本动作块即可计算得分函数差异
  • 未来项采用冻结的离线训练动作价值评判器 Q_φ 作为替代，通过最大化动作价值提供长期视野引导，无需闭环环境交互
  • 整体目标函数结合漂移损失与评判器损失，通过单步生成器 G_θ(z, s_t) 实现端到端优化，支持 LoRA 微调
Card 05 数据集与资源

数据集与资源

  • 仿真基准：RoboCasa365、RoboTwin 2.0、LIBERO、LIBERO-Plus
  • 真实世界机器人操作数据集（包含成对场景回放与安全排除机制）
  • 评估模型涵盖多种 VLA 架构、微调策略和动作专家参数化（如 π₀ 系列、GR00T 系列、ABot、RLDX 等），采用 LoRA 进行参数高效微调
  • 训练仅依赖离线演示数据，无需在线机器人交互；使用 GPU 进行分布式训练（具体硬件配置详见附录）
Card 06 评估与结果

评估与结果

  • 评估环境涵盖多类仿真基准与真实机器人平台，对比基线包括 One-step Teacher、sCD、MFD、Drift 等单步蒸馏方法
  • 主要评估指标为任务成功率、训练稳定性（尤其在数据稀缺条件下）、推理延迟及动作多样性
  • 关键结果：DriftOPD 在任务成功率上普遍优于现有单步蒸馏基线，达到与多步教师策略相当的性能；训练过程更稳定；单步生成显著降低推理延迟，且动作多样性损失可忽略
