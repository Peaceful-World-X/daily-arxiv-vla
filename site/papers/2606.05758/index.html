Card 02 论文概述

论文概述

  • 现代 Vision-Language Models (VLMs) 通常采用基于离散 token 的自回归解码，这种设计难以处理需要精确连续输出的任务（如机器人控制信号生成、视频事件 temporal boundary 定位）
  • 提出 DRIFT 框架，通过结合 base predictor 的粗粒度估计与基于 flow matching 的生成式细化模块，将预训练 VLM 适配到连续解码任务
  • 将生成建模问题从学习全局输出分布转化为建模强先验周围的局部残差分布，显著简化优化并提升学习效率
Card 03 核心贡献

核心贡献

  • 提出 DRIFT 通用框架，用于将具有离散解码接口的预训练 VLMs 适配到精确连续预测任务，同时保持预训练知识的复用
  • 设计残差细化适配器，结合确定性粗预测与 flow matching 生成式细化，并提供理论分析证明其优化优势（更快的收敛速度和更高的精度）
  • 在视觉定位（空间和时序）与机器人操作基准上展示强实证结果，跨越多模态大语言模型 (MLLMs)、视觉-语言-动作模型 (VLAs) 和世界动作模型 (WAMs) 架构
  • 在 Libero 机器人基准上达到 97.9% 平均准确率，在 Charades-STA 时序定位上实现 +2.6% 提升，达到新 state-of-the-art
Card 04 方法描述

方法描述

  • 基础预测器：利用预训练 VLM 的表示提供连续输出的粗估计（g(z)），可使用现有 token decoder 或 MLP 回归头
  • 残差流适配器：学习速度场 v_θ，将中心位于粗预测 ŷ=g(z) 的可学习方差高斯分布 N(ŷ, σI) 运输到目标条件分布 p(y\|z)
  • 桥接状态：定义线性插值 y(t) = (1-t)(σϵ + g(z)) + ty，其中 ϵ~N(0,I)，σ 为可学习缩放向量，目标速度为 v* = y - σϵ - ŷ
  • 参数化设计：y_θ(y(t),t,z) = α·g(z) + (1-α)·h_θ(y(t),t,z)，其中 α 为可学习门控向量，h_θ 为时间依赖的细化模块，通过 skip connection 结合粗预测与细化结果
  • 训练策略：当基础预测器需联合训练时，采用 MSE 损失与 flow matching 损失联合优化，并对基础预测器应用梯度停止（gradient stopping）防止模型 collapse 到忽略粗预测
Card 05 数据集与资源

数据集与资源

  • VLA 任务：Libero 基准（Spatial, Object, Goal, Long 四个子集）、Simpler WidowX 机器人操作基准
  • 时序视频定位 (TVG)：Charades-STA、ActivityNet Captions（测试集），TimeLens-100K（训练集）
  • 空间定位：RefCOCO、RefCOCO+、RefCOCOg
  • 基础 VLM：Qwen3-VL-2B、OpenVLA-7B、ET-Chat、FastWAM
  • 训练资源：使用 LoRA 适配器微调 VLM 骨干网络（包括视觉编码器和 LLM），联合训练基础预测器与流细化器
Card 06 实验结果

实验结果

  • VLA 任务：基于 Qwen3-VL-2B 的 DRIFT-MLP 在 Libero 上达到 97.9% 平均成功率，在 Simpler WidowX 上达到 61.5%；基于 OpenVLA-7B 的 DRIFT 将 Libero 平均从 75.5% 提升至 77.7%，Simpler 从 7.7% 提升至 13.5%
  • 时序视频定位：在 Charades-STA 上 R@0.3 从 65.7% 提升至 67.2%，mIoU 从 42.3% 提升至 43.8%；在 ActivityNet Captions 上 R@0.3 从 24.1% 提升至 57.9%，mIoU 从 18.9% 提升至 37.3%，超越 ED-VTG 等强基线
  • 空间定位：在 RefCOCO 系列上将 Qwen3-VL 的 average 性能从 85.6% 提升至 88.5%
  • 世界动作模型：将 FastWAM 在 Libero 上的平均性能从 96.9% 提升至 98.2%，验证框架的通用性
  • 消融研究：验证了残差流适配器相比直接 MLP、Diffusion、标准 Flow Matching 的优势，以及桥接状态设计和联合训练策略的有效性
