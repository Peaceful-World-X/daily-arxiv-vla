Card 02 论文概述

论文概述

  • 论文提出 RoboBRIDGE：一个模块化编排框架，可将任意动作生成策略（尤其是预训练 VLA 模型）包装为鲁棒的机器人智能体

  • 核心理念类比 LLM 领域的 LangChain/AutoGen：可靠性来自围绕模型的结构化编排，而非单纯扩大动作预测器规模
Card 03 核心贡献

核心贡献

  • 提出 RoboBRIDGE 框架，由五个协同模块组成：Monitor、Perceptor、Planner、Controller、Robot Interface，策略无关（policy-agnostic），无需重训练基座模型
  • 两阶段监控（Two-phase Monitoring）：轻量成功检测 + 失败诊断，配合四级分层恢复策略（retry → regenerate → replan → re-perceive）
  • 反应式规划与异步感知（Reactive Planning with Asynchronous Perception）：感知与执行解耦为并发线程，仅当环境偏离当前计划时触发重规划，避免执行停滞
  • 原始技能微调（Primitive Skill Fine-tuning）：将操作分解为领域不变的原始技能（move、grip、rotate 等），为每个技能训练专用 LoRA 适配器，降低域偏移敏感性
  • 在 LIBERO、RoboCasa 及真实机器人平台上跨多个 VLA 骨干验证，均取得一致提升
Card 04 方法描述

方法描述

  • Monitor：Phase 1 用视觉语言模型做轻量成功检查（约 5Hz，不阻塞控制回路）；Phase 2 在高置信度失败时停机诊断根因，并按代价递增选择分层恢复策略
  • Perceptor + Planner：感知线程持续更新线程安全缓冲区中的物体中心状态（3D 位姿、语义属性）；执行线程在每个原语完成后计算散度度量（物体 3D 位移 + 物体集合对称差），超过阈值则保留高层动作序列、仅重新生成后续原语技能
  • Controller：冻结 VLA 骨干 + 各原语专用 LoRA 适配器；两级解析器优先选用对应适配器，缺失时回退到所有适配器的平均；输出 7-DoF 增量动作，经笛卡尔速度指令或 IK 求解器执行
  • Robot Interface：抽象本体相关 API、时序、安全限制与坐标变换，实现跨机器人/仿真器复用
Card 05 数据集与资源

数据集与资源

  • 仿真基准：LIBERO（Object/Spatial/Goal/Long 四个套件）、RoboCasa（24 个原子任务，每任务 50 条人类遥操作演示，共 1,200 条）
  • VLA 骨干：SmolVLA、π0.5、GR00T-N1.5-3B
  • 组件模型：Perceptor 使用 Florence-2；Planner 与 Phase-2 Monitor 使用 Claude Opus 4.6
  • 训练配置：LoRA（rank 128、alpha 256、dropout 0.1），AdamW + bf16，batch size 64，500 epochs，学习率 5×10⁻⁵
  • 真实平台：Franka Emika Research 3（配 Omron 移动底盘）、UR7e
Card 06 评估与结果

评估与结果

  • 评估指标：成功率（SR），仿真采用官方任务完成判定，真实实验以无人工干预完成任务为准
  • LIBERO 上平均提升：Object +5.3%、Spatial +1.1%、Goal +1.2%、Long +9.4%（长时程任务提升最显著）
  • RoboCasa 上平均提升：SmolVLA +3.5%、π0.5 +2.5%、GR00T-N1.5 +5.6%；排除 PnP 任务后提升更大（GR00T 达 6.2%→14.7%）
  • 真实世界实验在多种机器人平台和任务上验证了框架在本体与环境变化下的鲁棒增益
  • 结果表明：可靠的机器人智能体能力源于围绕动作预测器的结构化编排，而非仅依赖模型扩展
